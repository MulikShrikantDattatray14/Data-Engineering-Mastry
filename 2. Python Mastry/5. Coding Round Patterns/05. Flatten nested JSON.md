# 05. Flatten dictionaries; explode lists of records (P7)

**Source:** [PDF p. 62](<../Source/1793477658005.pdf#page=62>). **Difficulty:** DE Hard.

The store's customer JSON has an `address` object and a `tags` list. A table needs stable column names such as `address.city`. For a list of **records**, a wide set of `items.0.sku`, `items.1.sku`, ... columns is awkward; produce one row per item instead. Decide which shape the consumer needs before writing the recursion.

## Step 1: flatten nested values into dotted keys

At a dictionary, visit every key. At a list, visit each numbered element. At a scalar or empty container, keep the current path and value. Keeping empty containers prevents an empty tag list from disappearing.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=05&snippet=1>)

```python
import json

def flatten(value, parent='', separator='.'):
    result = {}
    if isinstance(value, dict) and value:
        for key, child in value.items():
            path = f'{parent}{separator}{key}' if parent else key
            result.update(flatten(child, path, separator))
    elif isinstance(value, list) and value:
        for index, child in enumerate(value):
            path = f'{parent}{separator}{index}' if parent else str(index)
            result.update(flatten(child, path, separator))
    else:
        result[parent] = value
    return result

with open('python_de_dataset/customers.json', encoding='utf-8') as file:
    customers = json.load(file)
print(flatten(customers[1]))
print(flatten(customers[5]))
```

**Expected:** Diya's row has `address.city: 'Mumbai'` and `tags.0: 'referral'`. Sana's row has `address.city: None` and `tags: []`. Inspect the full printed dictionaries in the playground. The recursion uses O(d) call depth for nesting depth d, plus space for the flattened output. Production code should decide how to escape a literal dot in a source key and limit unexpectedly deep input.

## Step 2: explode an order's item records into rows

The parent order fields repeat on each output row. Each child contributes its own item fields. The source example keeps an order with no items as one parent row by using `[{}]`.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=05&snippet=2>)

```python
def flatten(value, parent=''):
    if isinstance(value, dict) and value:
        out = {}
        for key, child in value.items():
            out.update(flatten(child, f'{parent}.{key}' if parent else key))
        return out
    return {parent: value}

def explode(record, list_key):
    parent = {key: value for key, value in record.items() if key != list_key}
    base = flatten(parent)
    for child in record.get(list_key) or [{}]:
        item = {f'{list_key}.{key}': value for key, value in child.items()}
        yield {**base, **item}

order = {'order_id': 114, 'customer': {'id': 1, 'city': 'Bengaluru'},
         'items': [{'sku': 4, 'qty': 1}, {'sku': 1, 'qty': 1},
                   {'sku': 5, 'qty': 1}]}
for row in explode(order, 'items'):
    print(row)
```

```text
{'order_id': 114, 'customer.id': 1, 'customer.city': 'Bengaluru', 'items.sku': 4, 'items.qty': 1}
{'order_id': 114, 'customer.id': 1, 'customer.city': 'Bengaluru', 'items.sku': 1, 'items.qty': 1}
{'order_id': 114, 'customer.id': 1, 'customer.city': 'Bengaluru', 'items.sku': 5, 'items.qty': 1}
```

This small `flatten` handles nested dictionaries in the parent only; use the first version if children can themselves contain nested lists or dictionaries.

## Pandas shortcut (requires pandas)

The PDF also uses `pd.json_normalize` to turn nested event properties into columns. Pandas is optional and must be installed in the runner's Python environment first; this snippet can show `ModuleNotFoundError` until then.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=05&snippet=3>)

```python
import json
import pandas as pd

with open('python_de_dataset/events.jsonl', encoding='utf-8') as file:
    events = [json.loads(line) for line in file]
frame = pd.json_normalize(events)
print(frame.columns.tolist())
print(frame.head(3).to_string(index=False))
```

**Expected columns:** `user_id`, `ts`, `event`, `props.page`, `props.device`. For an array of records, pandas also supports `record_path`; the plain Python `explode` above makes the row logic easier to see.
