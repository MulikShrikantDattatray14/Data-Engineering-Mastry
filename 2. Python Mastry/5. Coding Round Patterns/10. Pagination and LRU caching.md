## P15. Cursor pagination as a generator

An API returns a page of rows and a cursor for the next page. After yielding the current rows, follow the cursor. Stop when it is absent. The simulated API below returns 15 order IDs in pages of four, so it runs without network access.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=10&snippet=1>)

```python
server_rows = list(range(101, 116))

def fake_api(cursor=None, limit=4):
    start = int(cursor or 0)
    page = server_rows[start:start + limit]
    next_index = start + limit
    return {'data': page,
            'next_cursor': str(next_index) if next_index < len(server_rows) else None}

def extract_all(limit=4):
    cursor = None
    page_number = 0
    while True:
        response = fake_api(cursor, limit)
        page_number += 1
        print(f'page {page_number}: {len(response["data"])} rows, next={response["next_cursor"]}')
        yield from response['data']
        cursor = response['next_cursor']
        if cursor is None:
            break

ids = list(extract_all())
print(len(ids), ids[:3], '...', ids[-1])
```

```text
page 1: 4 rows, next=4
page 2: 4 rows, next=8
page 3: 4 rows, next=12
page 4: 3 rows, next=None
15 [101, 102, 103] ... 115
```

The generator itself stays small; `list(extract_all())` materializes all IDs for the demonstration. For a real large extraction, send each yielded row directly to a file or batch loader. Guard against repeated cursors and empty pages with a nonempty next cursor, or a broken API can loop forever.

### Shape of a real HTTP client (requires `requests`, credentials, and a live API)

This illustrative block is **not run by the PDF**. It defines a function only; the playground needs `requests` installed before it can import the package, and you must supply a real endpoint and token before calling it.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=10&snippet=2>)

```python
import requests

def pages(url, token, params=None):
    session = requests.Session()
    session.headers['Authorization'] = f'Bearer {token}'
    while url:
        response = session.get(url, params=params, timeout=30)
        response.raise_for_status()
        body = response.json()
        yield from body['data']
        url, params = body.get('next'), None
```

## P16. Cache only repeatable lookups

`lru_cache(maxsize=128)` remembers the result for recent inputs. An LRU cache evicts the **least recently used** key when full. Here five lookup requests cause only three real calls: the pincode `560001` is repeated.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=10&snippet=3>)

```python
from collections import OrderedDict
from functools import lru_cache

calls = 0
@lru_cache(maxsize=128)
def city_for_pincode(pin):
    global calls
    calls += 1
    return {'560001': 'Bengaluru', '400001': 'Mumbai'}.get(pin, '?')

for pin in ['560001', '400001', '560001', '560001', '999999']:
    city_for_pincode(pin)
print('real calls:', calls, city_for_pincode.cache_info())

class LRU:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError('capacity must be positive')
        self.capacity = capacity
        self.data = OrderedDict()

    def get(self, key):
        if key not in self.data:
            return None
        self.data.move_to_end(key)
        return self.data[key]

    def put(self, key, value):
        self.data[key] = value
        self.data.move_to_end(key)
        if len(self.data) > self.capacity:
            self.data.popitem(last=False)

cache = LRU(2)
cache.put('a', 1); cache.put('b', 2); cache.get('a'); cache.put('c', 3)
print(list(cache.data))
```

```text
real calls: 3 CacheInfo(hits=2, misses=3, maxsize=128, currsize=3)
['a', 'c']
```

The first result line proves two calls reused cached values. In the hand-built cache, `get('a')` makes `a` recent; adding `c` evicts `b`. A mutable or changing external result can become stale. `lru_cache` has no time-to-live by itself, and `maxsize=None` can grow without bound. Cache only a lookup whose freshness rule you understand.
