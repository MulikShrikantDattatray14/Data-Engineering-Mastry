## P11. Merge overlapping bookings

Sort each room's bookings by start time. If the next booking begins before or at the current interval's end, extend that end to the **maximum** of both ends. Otherwise begin a new interval. The maximum matters: an interval nested inside a longer one must not shorten it.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=08&snippet=1>)

```python
from collections import defaultdict

def merge(intervals):
    result = []
    for start, end in sorted(intervals):
        if result and start <= result[-1][1]:
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])
    return result

bookings = [(10, '05-01', '05-04'), (10, '05-03', '05-06'),
            (10, '05-06', '05-08'), (20, '05-02', '05-05'),
            (20, '05-04', '05-07')]
rooms = defaultdict(list)
for room, start, end in bookings:
    rooms[room].append((start, end))
for room, intervals in rooms.items():
    print(room, merge(intervals))
print(merge([(1, 3), (2, 6), (8, 10), (15, 18)]))
```

```text
10 [['05-01', '05-08']]
20 [['05-02', '05-07']]
[[1, 6], [8, 10], [15, 18]]
```

Sorting dominates at O(n log n); the merge scan is O(n). The code treats touching endpoints as continuous because it uses `<=`. If bookings use half-open intervals and touching should remain separate, use `<`. The month-day strings work here because they are fixed width within one month; use actual date/time objects for real schedules.

## P12. A hash join in Python

Load the smaller customer file into a dictionary keyed by integer ID. Stream the larger order file and look up each customer. Also collect order customer IDs to find customers with no order: this is an **anti join**.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=08&snippet=2>)

```python
import csv
import json

with open('python_de_dataset/customers.json', encoding='utf-8') as file:
    customers = {row['customer_id']: row for row in json.load(file)}
joined, orphans, seen = [], 0, set()
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    for order in csv.DictReader(file):
        customer_id = int(order['customer_id'])
        seen.add(customer_id)
        customer = customers.get(customer_id)
        if customer is None:
            orphans += 1
            continue
        city = (customer['address'] or {}).get('city') or 'Unknown'
        joined.append((order['order_id'], customer['name'], city, order['amount']))
print(len(joined), 'joined,', orphans, 'orphans')
for row in joined[8:11]:
    print(row)
print('anti join:', [row['name'] for cid, row in customers.items() if cid not in seen])
```

```text
15 joined, 0 orphans
('109', 'Kabir', 'Delhi', '747.00')
('110', 'Sana', 'Unknown', '1998.00')
('111', 'Diya', 'Mumbai', '1999.00')
anti join: ['Zoya']
```

A nested loop checks every order against every customer: O(nm). Building a dictionary from the smaller side and probing once costs O(n+m) expected time and O(m) memory. For a much larger build side, partition it or join in SQL/Spark. The `seen` set adds memory for the anti join; omit it when only enrichment is needed.
