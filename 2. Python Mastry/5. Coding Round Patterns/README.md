# Part 5. Coding Round Patterns

**Source:** [Python for Data Engineering Notes, pp. 58–68](<../Source/1793477658005.pdf#page=58>). Follow these eleven lessons in order. The first is a map; each following lesson works through one or two of the PDF's **18 patterns** using the same store data. Every code block has a local **Run and edit** link. Start [practice_runner.py](<../practice_runner.py>) from the parent folder first; edits in the playground do not overwrite the lesson.

The worked file examples use the [companion dataset](<../python_de_dataset/README.md>). The live HTTP client in Lesson 10 and the pandas shortcut in Lesson 05 need optional packages; they are explicitly labeled. The standard-library examples run with the installed Python and the included files.

**Practice rhythm:** Read the question cue, predict the output, run the block, then try its **Your turn** variants. A hard question often stacks patterns: first solve each smaller operation, then connect them.
