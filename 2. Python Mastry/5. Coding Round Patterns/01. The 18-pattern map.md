## One loop you will reuse

The source's skeleton is: iterate once, calculate a key, update one dictionary entry, and format the finished result. Here we count orders per status without a special library.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=01&snippet=1>)

```python
import csv

counts = {}
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    for order in csv.DictReader(file):
        status = order['status']
        counts[status] = counts.get(status, 0) + 1
print(counts)
```

```text
{'delivered': 12, 'cancelled': 2, 'returned': 1}
```

The key is `status`. The update combines the previous count with this one row. For **top three users by session count**, do P8 first to produce sessions, P1 to count them, then P2 to choose three. For **daily error counts in a huge log**, combine P13 (stream), P10 (parse), and P1 (count). Test each inner step before joining them.
