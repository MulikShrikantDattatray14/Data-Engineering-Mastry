# 07. Parse messy logs and keep the skipped lines (P10)

**Source:** [PDF p. 64](<../Source/1793477658005.pdf#page=64>). **Difficulty:** DE Hard.

The store pipeline's `app.log` has fourteen lines. Thirteen follow a known structure; line 7 is a scheduler notice. Parse each line into named fields, put unmatched lines in a separate list, then count errors and find each job's slowest step. Reporting the skipped line makes malformed input visible.

## Step 1: match lines to records

The pattern captures timestamp, severity, job, step and duration. `rows=` and quoted `msg=` are optional. `groupdict()` returns names as dictionary keys and `None` for absent optional fields.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=07&snippet=1>)

```python
import re

line_pattern = re.compile(
    r'(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+'
    r'(?P<level>INFO|WARN|ERROR)\s+'
    r'job=(?P<job>\w+)\s+step=(?P<step>\w+)'
    r'(?:\s+rows=(?P<rows>\d+))?\s+duration_ms=(?P<ms>\d+)'
    r'(?:\s+msg="(?P<msg>[^"]*)")?'
)
parsed, skipped = [], []
with open('python_de_dataset/app.log', encoding='utf-8') as file:
    for line_number, line in enumerate(file, 1):
        match = line_pattern.fullmatch(line.strip())
        if match:
            parsed.append(match.groupdict())
        else:
            skipped.append((line_number, line.strip()))
print(len(parsed), 'parsed; skipped:', skipped)
print(parsed[4])
```

**Expected:** `13 parsed; skipped: [(7, '--- scheduler restarted ---')]`. The fifth parsed row is a `customers_dim` `ERROR` in the `load` step, with `rows` absent and `duration_ms` equal to `5003`. Using `fullmatch` rejects trailing garbage too; the PDF uses `match`, which only anchors the start. Compile once outside the loop. This stage scans lines in O(n) time and keeps O(n) parsed records here; process each parsed row immediately to keep memory bounded on a huge log.

| Regex piece | Meaning |
|---|---|
| `\d{4}-\d{2}-\d{2}` | four-digit year, two-digit month and day shape |
| `\s+` | one or more whitespace characters |
| `(?P<job>...)` | named capture read via `group('job')` or `groupdict()` |
| `(?:...)?` | optional group without its own capture |
| `[^\"]*` | characters up to the next quote |

## Step 2: aggregate parsed records

This code is self-contained so the playground can run it without first clicking Step 1.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=07&snippet=2>)

```python
import re
from collections import Counter, defaultdict

pattern = re.compile(
    r'(?P<ts>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+'
    r'(?P<level>INFO|WARN|ERROR)\s+'
    r'job=(?P<job>\w+)\s+step=(?P<step>\w+)'
    r'(?:\s+rows=(?P<rows>\d+))?\s+duration_ms=(?P<ms>\d+)'
    r'(?:\s+msg="(?P<msg>[^"]*)")?'
)
report = defaultdict(lambda: {'lines': 0, 'errors': 0, 'slowest': ('', 0)})
errors = Counter()
with open('python_de_dataset/app.log', encoding='utf-8') as file:
    for line in file:
        match = pattern.fullmatch(line.strip())
        if not match:
            continue
        row = match.groupdict()
        stats = report[row['job']]
        stats['lines'] += 1
        stats['errors'] += row['level'] == 'ERROR'
        duration = int(row['ms'])
        if duration > stats['slowest'][1]:
            stats['slowest'] = (row['step'], duration)
        if row['level'] == 'ERROR':
            errors[row['msg']] += 1
for job, stats in report.items():
    print(job, stats['lines'], stats['errors'], stats['slowest'])
print(errors.most_common(1))
```

```text
orders_daily 6 0 ('load', 1530)
customers_dim 7 3 ('load', 5003)
[('timeout connecting to warehouse', 3)]
```

The aggregation now holds only one small record per job and per error message. For a 20 GB file, stream lines instead of `read()`; if you need parallelism, partition log lines safely and merge the per-partition counters. The parser's regex shape is not a calendar-date validator; parse the timestamp into a `datetime` if valid dates matter.
