## P1. Frequency count

“How many of each status?” means the status is the key and the update is `+1`. A two-column grouping uses a tuple key such as `(customer_id, status)`. `Counter` packages that loop, while `dict.get(key, 0) + 1` makes it visible.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=02&snippet=1>)

```python
import csv
import json
from collections import Counter

with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    orders = list(csv.DictReader(file))
by_status = Counter(row['status'] for row in orders)
by_pair = Counter((row['customer_id'], row['status']) for row in orders)
with open('python_de_dataset/events.jsonl', encoding='utf-8') as file:
    by_page = Counter(json.loads(line)['props']['page'] for line in file)

manual = {}
for row in orders:
    key = row['status']
    manual[key] = manual.get(key, 0) + 1
print(by_status)
print(by_status.most_common(1), by_pair[('1', 'delivered')])
print(by_page.most_common(2))
print(manual == dict(by_status))
```

```text
Counter({'delivered': 12, 'cancelled': 2, 'returned': 1})
[('delivered', 12)] 3
[('/cart', 3), ('/checkout', 2)]
True
```

**Trace:** The first delivered order makes `by_status['delivered'] = 1`; the second makes it 2. The key `('1', 'delivered')` counts only customer 1's delivered orders. All 15 orders are scanned once: O(n) time and O(k) space for k distinct keys. A giant log can be counted batch by batch and the `Counter` objects added together.

## P2. Top K after aggregation

“Top three customers by delivered spend” has two steps: sum by customer, then choose three. A full sort is easy; a size-K heap only retains K candidates while scanning many groups.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=02&snippet=2>)

```python
import csv
import heapq
from collections import defaultdict

spend = defaultdict(float)
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    for row in csv.DictReader(file):
        if row['status'] == 'delivered':
            spend[row['customer_id']] += float(row['amount'])

# The final key makes smaller customer IDs win when spend ties.
top = heapq.nlargest(3, spend.items(), key=lambda pair: (pair[1], -int(pair[0])))
print(top)

heap = []
for customer_id, amount in spend.items():
    item = (amount, -int(customer_id), customer_id)
    if len(heap) < 3:
        heapq.heappush(heap, item)
    elif item > heap[0]:
        heapq.heapreplace(heap, item)
print([(cid, amount) for amount, _, cid in sorted(heap, reverse=True)])
```

```text
[('5', 5096.0), ('1', 5094.0), ('2', 4143.0)]
[('5', 5096.0), ('1', 5094.0), ('2', 4143.0)]
```

The smallest kept candidate sits at `heap[0]`; replace it only when a better one arrives. With g customer groups, heap selection costs O(g log K) time and O(K) extra space. The dictionary of sums still needs O(g) memory. If the question wants **all** customers tied at the Kth amount, retain the cutoff amount and include every equal candidate; `nlargest(K, ...)` alone returns only K rows.
