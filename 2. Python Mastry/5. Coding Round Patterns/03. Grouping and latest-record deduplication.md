## P3. Group by a key and reconcile

The store has order headers in `orders.csv` and line items in `order_items.csv`. For each `order_id`, add `qty × unit_price`, then compare that basket total with the header amount. This is a real finance check: a mismatch must be investigated.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=03&snippet=1>)

```python
import csv
from collections import defaultdict
from decimal import Decimal

lines = defaultdict(list)
with open('python_de_dataset/order_items.csv', newline='', encoding='utf-8') as file:
    for line in csv.DictReader(file):
        lines[line['order_id']].append(line)

totals = {
    order_id: sum(Decimal(row['qty']) * Decimal(row['unit_price']) for row in rows)
    for order_id, rows in lines.items()
}
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    headers = {row['order_id']: Decimal(row['amount']) for row in csv.DictReader(file)}

mismatches = [order_id for order_id, amount in headers.items()
              if totals.get(order_id) != amount]
biggest = max(lines, key=lambda order_id: len(lines[order_id]))
print(len(headers), 'orders checked, mismatches:', mismatches)
print('biggest basket:', biggest, len(lines[biggest]), 'items')
```

```text
15 orders checked, mismatches: []
biggest basket: 114 3 items
```

`defaultdict(list)` creates an empty basket the first time an order ID appears. `Decimal` reads decimal prices exactly, which matters for money. This version holds all lines in memory; for a huge sorted file, stream one order at a time or aggregate in a database. Also check for orphan item IDs if neither side is guaranteed complete.

## P4. Keep latest by timestamp, not arrival position

The last feed row for order 103 says `placed`, but its timestamp is older than the delivered update. A dictionary keyed by order ID retains the row with the **largest timestamp**.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=5&lesson=03&snippet=2>)

```python
feed = [
    {'order_id': 101, 'status': 'placed', 'ts': '2025-01-10 09:00'},
    {'order_id': 101, 'status': 'delivered', 'ts': '2025-01-12 18:30'},
    {'order_id': 102, 'status': 'placed', 'ts': '2025-01-15 11:00'},
    {'order_id': 103, 'status': 'delivered', 'ts': '2025-02-04 20:00'},
    {'order_id': 103, 'status': 'placed', 'ts': '2025-02-02 08:15'},
]
latest = {}
for record in feed:
    current = latest.get(record['order_id'])
    if current is None or record['ts'] > current['ts']:
        latest[record['order_id']] = record
for record in latest.values():
    print(record['order_id'], record['status'], record['ts'])
print(list(dict.fromkeys([3, 1, 3, 2, 1])))
```

```text
101 delivered 2025-01-12 18:30
102 placed 2025-01-15 11:00
103 delivered 2025-02-04 20:00
[3, 1, 2]
```

The timestamp strings compare correctly because they are normalized, fixed-width ISO-style text. Parse other formats first. For equal timestamps, define a second key such as sequence number; otherwise the winner depends on feed order. Time is O(n), memory O(k) for k IDs. Hundreds of millions of IDs may require hash partitioning, SQL, or Spark.
