## Q39. Latest event and device for each user (Easy)

**Input:** `events.jsonl`, one JSON event per line. **Output:** one latest event for each user, with its device. **Pattern:** [dedupe and keep latest](<../5. Coding Round Patterns/README.md>). A dictionary keyed by `user_id` keeps one current winner per user. ISO timestamps in the dataset can be compared as strings because they use one consistent format and timezone.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=01&snippet=1>)

```python
import json

latest = {}
with open('python_de_dataset/events.jsonl', encoding='utf-8') as file:
    for line in file:
        event = json.loads(line)
        user = event['user_id']
        current = latest.get(user)
        if current is None or event['ts'] > current['ts']:
            latest[user] = event

for user, event in sorted(latest.items()):
    print(user, event['event'], event['props']['device'], event['ts'][11:16])
```

```text
1 view desktop 14:00
2 cart desktop 10:40
3 checkout mobile 11:15
4 view tablet 12:00
```

The dictionary uses memory proportional to the number of users, not the number of event lines. Reading the file is O(events); sorting the final users adds O(users log users). If equal timestamps have a tie rule, add it explicitly instead of relying on input order.

## Q40. Longest gap between consecutive orders (Medium)

**Input:** `orders.csv`. **Output:** the largest number of days between two adjacent orders for each customer with at least two orders. **Pattern:** group, sort within each group, compare neighbours. A customer with one order has no gap and is omitted.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=01&snippet=2>)

```python
import csv
from collections import defaultdict
from datetime import date
from itertools import pairwise

dates = defaultdict(list)
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    for row in csv.DictReader(file):
        dates[row['customer_id']].append(date.fromisoformat(row['order_date']))

gaps = {
    customer: max((later - earlier).days for earlier, later in pairwise(sorted(days)))
    for customer, days in dates.items()
    if len(days) > 1
}
print(dict(sorted(gaps.items(), key=lambda item: -item[1])))
```

```text
{'5': 47, '1': 46, '4': 45, '2': 43, '3': 38}
```

Sorting is essential: CSV row order is not a promise of date order. If customer `5` ordered on two dates 47 days apart, that is their gap. Total time is O(n log n) in the worst case because each customer group is sorted; extra space is O(n).

## Q41. Pairs of orders that total 2847.00 (Medium)

**Input:** order amounts. **Output:** every distinct pair of order IDs whose amounts sum to exactly 2847.00. **Pattern:** two-sum with a hash map. Use `Decimal` from text so money comparisons are exact. Keep a list of IDs per amount because duplicate amounts can produce several valid pairs.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=01&snippet=3>)

```python
import csv
from collections import defaultdict
from decimal import Decimal

TARGET = Decimal('2847.00')
seen = defaultdict(list)
pairs = []
with open('python_de_dataset/orders.csv', newline='', encoding='utf-8') as file:
    for row in csv.DictReader(file):
        amount = Decimal(row['amount'])
        for earlier_id in seen[TARGET - amount]:
            pairs.append((earlier_id, row['order_id']))
        seen[amount].append(row['order_id'])

print(pairs)
```

```text
[('103', '105'), ('105', '113')]
```

Lookup happens before adding the current order, so an order cannot pair with itself. The scan is O(n + number of pairs produced) time and O(n) space; listing every pair can itself be large.

## Q42. Turn dotted keys into nested JSON (Hard)

**Input:** a flat dictionary such as `address.city`. **Output:** nested dictionaries. **Pattern:** reverse [flatten nested JSON](<../5. Coding Round Patterns/README.md>) by walking each dotted path. `setdefault` creates a parent dictionary only when it is missing.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=01&snippet=4>)

```python
def unflatten(flat, separator='.'):
    root = {}
    for key, value in flat.items():
        *parents, leaf = key.split(separator)
        node = root
        for parent in parents:
            node = node.setdefault(parent, {})
        node[leaf] = value
    return root

flat = {
    'address.city': 'Pune',
    'address.pincode': '411001',
    'name': 'Rohan',
}
print(unflatten(flat))
```

```text
{'address': {'city': 'Pune', 'pincode': '411001'}, 'name': 'Rohan'}
```

A production version should define what happens when keys conflict, such as both `address` and `address.city`, or when key names themselves contain dots. This basic version assumes neither happens. Time and memory are proportional to the total number of key segments.
