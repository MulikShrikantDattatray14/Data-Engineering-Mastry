## Q43. Top customer by delivered spend in each month (Medium)

Filter delivered orders, derive a month, sum per `(month, customer)`, then choose the largest customer total in each month. This is SQL `WHERE`, `GROUP BY`, then top row per group. `idxmax()` selects one row; if the interview asks for all ties, use a rank instead.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=02&snippet=1>)

```python
import pandas as pd

orders = pd.read_csv('python_de_dataset/orders.csv', parse_dates=['order_date'])
delivered = orders.loc[orders['status'].eq('delivered')].copy()
delivered['month'] = delivered['order_date'].dt.to_period('M')
spend = delivered.groupby(['month', 'customer_id'], as_index=False)['amount'].sum()
winners = spend.loc[spend.groupby('month')['amount'].idxmax()].sort_values('month')
for row in winners.itertuples(index=False):
    print(row.month, row.customer_id, f'{row.amount:.2f}')
```

```text
2025-01 1 1198.00
2025-02 1 1499.00
2025-03 5 3498.00
2025-04 1 2397.00
```

## Q44. Month-over-month delivered revenue (Easy)

Sum delivered revenue by calendar month. For each month after the first, compute `(this_month / last_month - 1) * 100`. The first month has no prior month, so its percentage is missing.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=02&snippet=2>)

```python
import pandas as pd

orders = pd.read_csv('python_de_dataset/orders.csv', parse_dates=['order_date'])
revenue = (orders.loc[orders['status'].eq('delivered')]
           .set_index('order_date')['amount']
           .resample('MS').sum())
growth = (revenue.pct_change() * 100).round(1)
for month in revenue.index:
    change = 'N/A' if pd.isna(growth.loc[month]) else f'{growth.loc[month]:.1f}%'
    print(month.strftime('%Y-%m'), f'{revenue.loc[month]:.2f}', change)
```

```text
2025-01 1994.00 N/A
2025-02 2847.00 42.8%
2025-03 7291.00 156.1%
2025-04 6840.00 -6.2%
```

`MS` means month start, which gives a predictable label for each monthly bucket. A previous month with zero revenue needs a defined business rule because percentage growth would divide by zero.

## Q45. Daily revenue and a three-day rolling sum (Medium)

The question asks for **every day from 1 to 7 April**, including dates with no delivered order. Build a full date index, reindex onto it with zero for missing days, then roll over three calendar rows. `min_periods=1` allows a result on the first two days.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=02&snippet=3>)

```python
import pandas as pd

orders = pd.read_csv('python_de_dataset/orders.csv', parse_dates=['order_date'])
delivered = orders.loc[orders['status'].eq('delivered')]
all_daily = delivered.groupby('order_date')['amount'].sum()
days = pd.date_range('2025-04-01', '2025-04-07', freq='D')
daily = all_daily.reindex(days, fill_value=0)
rolling = daily.rolling(3, min_periods=1).sum()
for day in days:
    print(day.date(), f'{daily.loc[day]:.2f}', f'{rolling.loc[day]:.2f}')
```

```text
2025-04-01 0.00 0.00
2025-04-02 1999.00 1999.00
2025-04-03 0.00 1999.00
2025-04-04 0.00 1999.00
2025-04-05 846.00 846.00
2025-04-06 0.00 846.00
2025-04-07 0.00 846.00
```

## Q46. Customers whose every order was delivered (Easy)

For each customer who appears in `orders.csv`, check whether all their order statuses are `delivered`. `all()` is true only if every boolean in the group is true. The file has no row for customers who never ordered; they are not in this result.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=02&snippet=4>)

```python
import pandas as pd

orders = pd.read_csv('python_de_dataset/orders.csv')
flags = orders.assign(delivered=orders['status'].eq('delivered'))
all_delivered = flags.groupby('customer_id')['delivered'].all()
print(all_delivered.loc[all_delivered].index.tolist())
```

```text
[2, 5, 6, 7]
```

## Q47. First order, order count, and wait for second order (Medium)

Sort each customer's orders by date, number them from zero with `cumcount()`, then align their first and second dates by `customer_id`. Customers with one order have no second date, so the wait is missing.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=02&snippet=5>)

```python
import pandas as pd

orders = pd.read_csv('python_de_dataset/orders.csv', parse_dates=['order_date'])
orders = orders.sort_values(['customer_id', 'order_date', 'order_id']).copy()
orders['order_number'] = orders.groupby('customer_id').cumcount()
first = orders.loc[orders['order_number'].eq(0)].set_index('customer_id')['order_date']
second = orders.loc[orders['order_number'].eq(1)].set_index('customer_id')['order_date']
counts = orders.groupby('customer_id').size()
wait = (second - first).dt.days
for customer_id in counts.index:
    days = 'N/A' if pd.isna(wait.loc[customer_id]) else str(int(wait.loc[customer_id]))
    print(customer_id, first.loc[customer_id].date(), counts.loc[customer_id], days)
```

```text
1 2025-01-10 4 23
2 2025-01-15 3 34
3 2025-02-10 2 38
4 2025-03-01 2 45
5 2025-03-12 2 47
6 2025-03-22 1 N/A
7 2025-04-05 1 N/A
```

The `order_id` tie break makes equal-date orders deterministic. Its order is a choice for this example; ask the interviewer what counts as first if equal timestamps matter.
