### Count, group, and keep the latest — P1, P3, P4

Use a dictionary for each job: one number per key, one list per key, or one current best row per key. Say how ties in timestamps are resolved.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=06&snippet=1>)

```python
rows = [
    {'customer': 'A', 'amount': 10, 'ts': '09:00'},
    {'customer': 'B', 'amount': 7, 'ts': '09:15'},
    {'customer': 'A', 'amount': 15, 'ts': '10:00'},
]
counts, groups, latest = {}, {}, {}
for row in rows:
    key = row['customer']
    counts[key] = counts.get(key, 0) + 1
    groups.setdefault(key, []).append(row['amount'])
    if key not in latest or row['ts'] > latest[key]['ts']:
        latest[key] = row
print(counts)
print(groups)
print({key: row['amount'] for key, row in latest.items()})
```

```text
{'A': 2, 'B': 1}
{'A': [10, 15], 'B': [7]}
{'A': 15, 'B': 7}
```

### Top-k, fixed window, streak start, merge intervals — P2, P5, P9, P11

A heap helps find a small top-k without sorting all values. A deque supports adding and removing at window ends. A streak starts when the preceding date is absent; intervals must be sorted and merged by taking the maximum end.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=06&snippet=2>)

```python
from collections import deque
from datetime import date, timedelta
from heapq import nlargest

spend = [('A', 100), ('B', 70), ('C', 120)]
print('top 2:', nlargest(2, spend, key=lambda item: item[1]))

window, total, sums = deque(), 0, []
for amount in [10, 20, 30, 40]:
    window.append(amount)
    total += amount
    if len(window) > 2:
        total -= window.popleft()
    sums.append(total)
print('window sums:', sums)

days = {date(2025, 4, 1), date(2025, 4, 2), date(2025, 4, 5)}
starts = sorted(day for day in days if day - timedelta(days=1) not in days)
print('streak starts:', [str(day) for day in starts])

intervals = [(1, 3), (2, 4), (7, 8)]
merged = []
for start, end in sorted(intervals):
    if merged and start <= merged[-1][1]:
        merged[-1][1] = max(merged[-1][1], end)
    else:
        merged.append([start, end])
print('merged:', merged)
```

```text
top 2: [('C', 120), ('A', 100)]
window sums: [10, 30, 50, 70]
streak starts: ['2025-04-01', '2025-04-05']
merged: [[1, 4], [7, 8]]
```

### Stream batches and cap retries — P13, P14

Batches bound memory. Exponential backoff waits longer after repeated failures, with a cap and jitter; in this example we calculate delays without actually sleeping. Real retries also need a maximum attempt count and a decision about which errors are safe to retry.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=7&lesson=06&snippet=3>)

```python
from itertools import islice
from random import Random

rows = iter(range(1, 8))
batches = []
while batch := list(islice(rows, 3)):
    batches.append(batch)
print('batches:', batches)

rng = Random(7)
base, cap = 1, 8
print('retry delay caps:', [min(cap, base * 2 ** attempt) for attempt in range(5)])
print('first jitter sample:', round(rng.uniform(0, min(cap, base)), 3))
```

```text
batches: [[1, 2, 3], [4, 5, 6], [7]]
retry delay caps: [1, 2, 4, 8, 8]
first jitter sample: 0.324
```

## Nine traps to catch before submission

1. A mutable default argument is shared across calls.
2. A shallow copy still shares nested objects.
3. `float` is a poor default for exact money calculations; use `Decimal` from strings.
4. Deleting dictionary keys while iterating the same dictionary raises an error; iterate over a copy of its keys if necessary.
5. `zip()` can silently stop at the shortest input; use `strict=True` when lengths must match.
6. Generators are consumed once; rebuild one if you need another pass.
7. `itertools.groupby()` groups consecutive equal keys, so sort first when you want one group per key.
8. Never insert user values into SQL with an f-string; use parameters.
9. pandas `groupby()` drops missing keys by default; choose `dropna=False` when those rows matter.

## Pick the structure that matches the job

| Need | Start with | Typical cost |
|---|---|---|
| Find a value by key | `dict` | O(1) average lookup |
| Check membership | `set` | O(1) average membership |
| Add and remove at both ends | `collections.deque` | O(1) at ends |
| Keep a small top-k | `heapq` | O(n log k) scan with size-k heap |
| Process a huge input in one pass | Iterator or generator | O(1) input buffering, excluding output/state |

## The six-step approach, compressed

1. Pin down input and output.
2. List edge cases.
3. Give a baseline solution and its cost.
4. Pick the structure or pattern.
5. Write small functions.
6. Test and state time and space.
