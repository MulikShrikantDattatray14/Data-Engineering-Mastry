## Run and change examples

Start [Start Practice.cmd](<../Start Practice.cmd>) from the Python root, then click **Run and edit this example** above a code block. The runner loads a separate editable copy and remembers drafts per part, lesson, and snippet in your browser. The Markdown original remains unchanged. Python coding examples use only the standard library; the pandas set requires the pandas package in the Python environment used by the runner.

The source material, dataset, and earlier lessons are available from the [Python index](<../README.md>). Part 7 uses the same `python_de_dataset` files as the earlier parts.
