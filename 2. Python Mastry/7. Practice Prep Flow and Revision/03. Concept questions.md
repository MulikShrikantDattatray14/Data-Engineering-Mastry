# 3. Concept questions with short answers

## Python values and functions

| Interview question | Short answer | Store example |
|---|---|---|
| List vs tuple? | A list can change; a tuple is intended as a fixed sequence. A tuple of hashable values can be a dictionary key. | Keep mutable order rows in a list; use `(customer_id, month)` as a grouping key. |
| `is` vs `==`? | `==` compares values; `is` checks whether two references point to the same object. Use `is None` for a missing sentinel. | Two separately built order dictionaries may be equal without being the same object. |
| Why is a mutable default argument a bug? | A default list is created when the function is defined and reused on later calls. Use `None`, then create a fresh list inside. | Separate batches should not share one default error list. |
| Shallow vs deep copy? | A shallow copy makes a new outer container but keeps references to nested items. `deepcopy` recursively copies nested values. | Copying a customer row shallowly still shares its nested `address` dictionary. |
| Why are dict and set lookups O(1)? | Hashing locates a bucket without scanning every element on average. Keys must be hashable, and O(1) is an average-case claim. | Look up `customer_id` while joining orders to customers. |
| Generator vs list? | A generator produces values as requested and is usually consumed once. A list stores all values for reuse and indexing. | Stream millions of orders instead of loading them all at once. |
| Iterator vs iterable? | An iterable can create an iterator with `iter()`. An iterator yields values with `next()` until `StopIteration`. | A file is iterable; `for line in file` pulls the next line. |
| What does `yield from` do? | It forwards values from another iterable or generator. It keeps recursive generators compact. | Flatten nested customer JSON by forwarding child values. |
| What is a decorator? | A decorator takes a function and returns a wrapped function. It can add timing, retry, or logging. | Time a CSV transform without changing its core calculation. |
| Why use `functools.wraps`? | It copies the original function's metadata to a wrapper. Logs and introspection then show the useful function name and docstring. | A timed `load_orders` still appears as `load_orders`. |
| What is a context manager? | `with` enters a resource and ensures its exit method runs afterward. It closes a file even if processing raises an error. | `with open('orders.csv') as file:` closes the CSV. |
| `*args` and `**kwargs`? | They collect extra positional arguments as a tuple and keyword arguments as a dictionary. They are useful when forwarding calls through wrappers. | A logging decorator forwards an ETL function's arguments. |
| What is the GIL? | In common CPython builds, it limits Python bytecode execution across threads; details depend on the build and Python version. Threads can still overlap blocking I/O. | Downloading several pages can benefit from threads; a CPU-heavy parse may need processes. |
| Threads vs processes vs `asyncio`? | Threads suit blocking I/O libraries, processes suit CPU parallelism, and `asyncio` suits many cooperative I/O tasks. Choose based on the bottleneck and library support. | Concurrent API fetches versus parallel heavy transformations. |
| Why use `Decimal` for money? | Binary floats cannot exactly represent many decimal fractions. Construct `Decimal` from strings and set a rounding rule. | Sum order amounts such as `1198.00` exactly. |
| What is a dataclass? | It generates routine methods such as `__init__` and `__repr__` from declared fields. `frozen=True` discourages reassignment of fields. | Represent a validated order record with named fields. |
| EAFP vs LBYL? | EAFP tries an operation and handles an exception; LBYL checks first. An earlier check may become stale before the operation. | Catch a missing `customer_id` when parsing a row, or validate it before processing. |

```python
from copy import deepcopy
from decimal import Decimal

customer = {'address': {'city': 'Pune'}}
shallow = customer.copy()
deep = deepcopy(customer)
customer['address']['city'] = 'Mumbai'
print(shallow['address']['city'], deep['address']['city'])
print(Decimal('0.1') + Decimal('0.2'))
```

```text
0.3
```

## Files, data, databases, and pipelines

| Interview question | Short answer | Store example |
|---|---|---|
| How do you read a 50 GB file? | Stream rows or read chunks; do not call `read()` on the whole file. For distributed processing, consider Spark. | Count statuses line by line from an event feed. |
| JSON vs JSON Lines? | JSON is one complete document; JSON Lines has one JSON value per line. JSON Lines supports simple streaming and splitting. | `customers.json` is one document; `events.jsonl` is one event per line. |
| Why parameterized SQL? | Parameters pass values separately from SQL text. They prevent injection and remove manual quoting errors. | `WHERE customer_id = ?` with a separate ID argument. |
| pandas `apply` vs vectorized operations? | A row-wise `apply` calls Python repeatedly; vectorized column operations often use optimized array code. Benchmark the real task. | Compute `amount * 1.18` for an entire column. |
| `.loc` vs `.iloc`? | `.loc` selects by label or boolean mask; `.iloc` selects by integer position. A label `0` is not always the first row. | Pick orders whose status is delivered with `.loc`. |
| `merge` vs `concat`? | `merge` matches rows on keys; `concat` stacks data along an axis. They resemble SQL join and union-style stacking. | Join orders to customers; stack monthly order extracts. |
| Why can `groupby` lose rows? | Missing group keys are dropped by default in pandas. Use `dropna=False` or fill the key if those rows matter. | Keep orders with an unknown city under an explicit group. |
| Parquet vs CSV? | Parquet stores typed, compressed columns and supports reading selected columns efficiently. CSV is plain text without a built-in schema. | Store large curated orders in Parquet, exchange a tiny sample as CSV. |
| What makes a pipeline idempotent? | Repeating the same input run leaves the same final result. Upsert by key or replace a target partition instead of appending duplicates. | Rerun 20 April's daily revenue without creating a second row. |
| Logging vs `print`? | Logging supports levels, structured context, and configurable destinations. `print` is fine for quick local output but weak for production diagnostics. | Log which batch failed and its order ID. |
| What does `if __name__ == '__main__'` do? | That block runs when a file is executed directly, not when imported. It is especially useful for command-line programs and process workers. | Import ETL helpers without launching the job. |
| Unit test vs data quality check? | A unit test checks code with known examples. A data quality check inspects actual data on each run. | Test `parse_amount('5.00')`; check the daily file has no null order IDs. |
| pandas vs PySpark? | pandas works in one Python environment; Spark distributes work across a cluster and evaluates lazily. Use the simpler tool that fits the data size. | Small `orders.csv` in pandas; a very large event history in Spark. |

## Algorithms and complexity

| Interview question | Short answer | Store example |
|---|---|---|
| What does Big-O measure? | How work grows as input size grows, ignoring constant factors. It is not a prediction of seconds on one machine. | One pass over n orders is O(n). |
| What counts as space complexity? | Extra memory created by the algorithm, including collections and recursive call frames. State whether output storage is counted. | A dictionary for k customers uses O(k) extra space. |
| BFS vs DFS? | BFS uses a queue and explores by distance; DFS uses a stack or recursion and explores deeply first. BFS finds a shortest path in an unweighted graph. | Traverse an employee org chart by level or branch. |
| When is greedy wrong? | A locally best choice can block the best total answer. Test with a counterexample before claiming a greedy rule works. | For amount 6 and coins `[1, 3, 4]`, greedy picks 4+1+1 while 3+3 uses fewer coins. |
