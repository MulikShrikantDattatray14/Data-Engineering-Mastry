# 04. Strings: working with text

**Source:** Python for Data Engineering Notes, PDF page 8 (Lesson 4).

Product names, cities, statuses, file paths, and log lines are text. Python calls text a **string** (`str`).

## Build, measure, and slice

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=1>)

~~~python
name = "Aarav"
city = 'Bengaluru'  # Single and double quotes both work

print(name + " from " + city)
print("-" * 20)
print(len(name))
print(name[0], name[-1])
print(city[0:4], city[4:])
~~~

Output:

~~~text
Aarav from Bengaluru
--------------------
5
A v
Beng aluru
~~~

`+` joins strings; `*` repeats one. `len(name)` counts characters. Positions begin at **0**; `-1` means the last character. A slice `city[0:4]` includes positions 0 through 3 and stops **before** 4. Leaving out the start or stop means "from the beginning" or "to the end."

## Clean and reshape text

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=2>)

~~~python
status = "  Delivered  "
print("[" + status.strip() + "]")
print(status.strip().lower())
print("delivered".upper(), "pune".title())
print("2025-04-01".replace("-", "/"))
print("101,1,delivered".split(","))
print(" | ".join(["a", "b", "c"]))
print("deliver" in "delivered", "orders.csv".endswith(".csv"))
~~~

Output:

~~~text
[Delivered]
delivered
DELIVERED Pune
2025/04/01
['101', '1', 'delivered']
a | b | c
True True
~~~

`strip()` removes spaces at both ends; `lower()` and `upper()` change case; `title()` capitalizes words. `replace()` substitutes text. `split()` turns one string into a list, while `join()` builds a string from a list of strings. `in` checks whether text occurs inside other text; `endswith()` checks a suffix.

**Important:** String methods return a **new** string. They do not change the original. If you want to keep the cleaned value, assign it:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=3>)

~~~python
status = status.strip().lower()
print(status)
~~~

Output:

~~~text
delivered
~~~

## Build readable messages with f-strings

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=4>)

~~~python
name, orders, revenue = "Diya", 3, 4143.0
print(f"{name} placed {orders} orders worth {revenue}")
print(f"{revenue:,.2f}")
print(f"{orders:03d}")
print(f"{name:<8}|{name:>8}|")
print(f"{0.256:.1%}")
~~~

Output:

~~~text
Diya placed 3 orders worth 4143.0
4,143.00
003
Diya    |    Diya|
25.6%
~~~

The `f` before the quotes lets expressions inside `{...}` be filled in. A format after `:` controls presentation: `,.2f` adds a thousands comma and two decimals; `03d` pads a whole number with zeroes; `<8` and `>8` align within eight spaces; `.1%` makes a percentage.

## An extra store example

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=5>)

~~~python
raw_city = "  mUmBaI  "
city = raw_city.strip().title()
file_name = city.lower() + "_orders.csv"
print(city)
print(file_name)
~~~

Output:

~~~text
Mumbai
mumbai_orders.csv
~~~

The same pattern helps normalize messy city values before comparing or grouping them.

## Characters that mean something special

`"\n"` starts a new line, and `"\t"` inserts a tab. Triple quotes (`"""..."""`) let a string span multiple lines, which is useful when embedding a SQL query in Python.

### 11. Python Strings

**Source:** [Python Strings](https://www.w3schools.com/python/python_strings.asp). **Mentor lesson:** [Strings: working with text](<04. Strings - working with text.md>).

A string is text surrounded by single or double quotes. Use the other quote style or escape a quote when the text itself contains one. Triple quotes allow text across lines. Characters have positions starting at **0**; a character is itself a one-character string, not a separate `char` type.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=6>)

```python
status = " Delivered "
clean = status.strip().lower()
print(clean, len(clean), clean[0], clean[-1])
print(clean[:4], "liver" in clean, "cancelled" not in clean)

receipt = """order 101
delivered"""
print(receipt.splitlines())
```

```text
delivered 9 d d
deli True True
['order 101', 'delivered']
```

`strip()` removes the outer spaces, `lower()` normalizes case, `[:4]` takes the first four characters, and `in` checks whether text occurs inside other text. You can loop over a string one character at a time. Strings cannot be changed at a position; make a new string instead.

### 30. Python RegEx

[W3Schools: Python RegEx](https://www.w3schools.com/python/python_regex.asp) | [PDF preview: parsing logs, p. 64](<../Source/1793477658005.pdf#page=64>)

A regular expression describes a text pattern. The built-in **re** module can locate, list, split, or replace matches. A raw string, such as **r"\d+"**, makes backslashes easier to read.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=7>)

~~~python
import re

line = "order=101 status=delivered"
match = re.search(r"order=(\d+)", line)

print(match.group(1) if match else "no order ID")
print(re.findall(r"\w+=\w+", line))
print(re.sub(r"status=\w+", "status=hidden", line))
~~~

Output:

~~~text
101
['order=101', 'status=delivered']
order=101 status=hidden
~~~

**search** returns a match object or **None**. Check it before calling **group**. **findall** returns every match; **split** divides at matches; **sub** replaces them. For ordinary CSV, use the **csv** module instead of a regex parser.

<a id="topic-33"></a>
### 33. Python String Formatting

[W3Schools: Python String Formatting](https://www.w3schools.com/python/python_string_formatting.asp) | [Part 1 Lesson 4](<04. Strings - working with text.md>) | [Part 1 Lesson 6](<06. Input and output.md>)

An **f-string** puts a value or expression into text. Format instructions after **:** control how that value appears.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=04&snippet=8>)

~~~python
revenue = 18972
month = "April"
orders = 4

print(f"Revenue: Rs {revenue:,.2f}")
print(f"{month:<8}{orders:>3}")
print("Orders: {}".format(orders))
~~~

Output:

~~~text
Revenue: Rs 18,972.00
April     4
Orders: 4
~~~

**,.2f** adds a thousands separator and two decimal places. **<8** makes a field eight characters wide and left-aligns it; **>3** right-aligns the order count. **str.format()** is another formatting style you may meet in older code.
