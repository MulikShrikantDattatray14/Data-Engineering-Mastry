# Part 1 - Python from Zero

[Python master index](<../README.md>) | [Start Here](<../00. Start Here.md>) | [Original PDF](<../Source/1793477658005.pdf#page=5>)

Work through these 20 entries in order. The same online-store story grows from printing one value to reading an order file and writing a monthly report. Each lesson uses short theory, executable Python, expected output, common mistakes, and exercises. The PDF is the source; the notes expand its explanations and add small runnable examples.

**Pages covered:** 5-24 of the 80-page PDF. The opening dataset and coding-round context are in [Start Here](<../00. Start Here.md>).

## Run and edit examples

Python is installed locally. Open a terminal in the `2. Python Mastry` folder and run:

```powershell
py practice_runner.py
```

Keep that terminal open. Each lesson has a **▶ Run and edit this example** link beside its Python code. The playground shows the untouched original, an editable copy, and the output. It saves your edits separately for each example in this browser; **Reset** restores the original copy. The launcher [Start Practice.cmd](<../Start Practice.cmd>) can also be opened from File Explorer.

## Practice rhythm

1. Run the first code block and predict its output before looking.
2. Change one value and see what changes downstream.
3. Try the exercises yourself. Practice-set answers are hidden in expandable sections.
4. Keep a small note of any error you meet and what fixed it.

**Dataset note:** The [supplied files](<../python_de_dataset/README.md>) are available. Run note snippets from the `2. Python Mastry` folder using paths such as `python_de_dataset/orders.csv`. The file outputs in Lessons 18-20 match the PDF. Other examples are self-contained.
