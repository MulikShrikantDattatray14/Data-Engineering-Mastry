# 09. Loops part 2: while, break, continue

**Source:** Python for Data Engineering Notes, PDF page 13 (Lesson 9).

Use `for` when you know the values to visit. Use `while` when you need to keep going **until something changes**. `continue` skips one pass; `break` stops the loop entirely.

## Repeat while a condition is true

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=1>)

~~~python
balance = 1000
day = 0
while balance > 0:
    day += 1
    balance -= 300
    print(f"day {day}: balance {balance}")
print("ran out on day", day)
~~~

Output:

~~~text
day 1: balance 700
day 2: balance 400
day 3: balance 100
day 4: balance -200
ran out on day 4
~~~

The condition is checked **before** each pass. A balance of 100 starts another pass, which takes it to -200. Then the next check fails. Always ask what changes in a `while` loop. If nothing can make the condition false, it runs forever; press Ctrl+C in the terminal to stop it.

## Skip a bad record or stop at a marker

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=2>)

~~~python
statuses = ["delivered", "", "cancelled",
            "delivered", "STOP", "delivered"]
delivered = 0
for s in statuses:
    if s == "":
        continue
    if s == "STOP":
        break
    if s == "delivered":
        delivered += 1
print("delivered before STOP:", delivered)
~~~

Output:

~~~text
delivered before STOP: 2
~~~

The empty status is skipped by `continue`. `STOP` ends the loop by `break`; the last delivered value is never visited.

## Retry, but give up after a limit

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=3>)

~~~python
attempt = 0
connected = False
while not connected and attempt < 3:
    attempt += 1
    connected = attempt == 3  # Pretend the third try works
    result = "connected" if connected else "failed"
    print(f"try {attempt}: {result}")
if not connected:
    print("giving up")
~~~

Output:

~~~text
try 1: failed
try 2: failed
try 3: connected
~~~

A retry loop needs a counter, a maximum number of attempts, and a success flag. If success never happens, the counter still ends the loop. A later lesson turns this pattern into a reusable retry decorator (PDF page 37).

| Use `for` when... | Use `while` when... |
|---|---|
| You have a list, file, or `range(10)` to visit | You must wait for an event, such as a successful retry |
| You are processing known records | You are polling or requesting API pages until there are none |

## Find the first matching order

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=4>)

~~~python
amounts = [796, 1198, 2397, 1499, 3498]
found_at = None
for i, a in enumerate(amounts):
    if a > 2000:
        found_at = i
        break
print("first above 2,000:", amounts[found_at], "at", found_at)
~~~

Output:

~~~text
first above 2,000: 2397 at 2
~~~

`None` means "not found yet." `enumerate` starts at index 0 here. `break` keeps `found_at` at the **first** matching position. In production code, check `found_at is not None` before indexing, because no match would otherwise cause an error.

## An extra store example

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=5>)

~~~python
pending = 3
while pending > 0:
    print("Ship one order; remaining:", pending - 1)
    pending -= 1
print("All shipped")
~~~

Output:

~~~text
Ship one order; remaining: 2
Ship one order; remaining: 1
Ship one order; remaining: 0
All shipped
~~~

Each pass moves the program closer to its stopping condition.

### 20. Python While Loops

**Source:** [W3Schools Python While Loops](https://www.w3schools.com/python/python_while_loops.asp) | **Main lesson:** [09. While, break, continue](<09. Loops part 2 - while break continue.md>)

A while loop repeats while its condition remains true. Update the condition's variables so the loop can finish. Continue skips the rest of one pass; break stops the loop.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=09&snippet=6>)

~~~python
attempt = 0
while attempt < 3:
    attempt += 1
    if attempt == 2:
        continue
    print('attempt', attempt)
else:
    print('finished normally')
~~~

~~~text
attempt 1
attempt 3
finished normally
~~~

The increment happens before continue, so this loop cannot get stuck on 2. The else block runs only when the loop finishes normally; break would skip it.
