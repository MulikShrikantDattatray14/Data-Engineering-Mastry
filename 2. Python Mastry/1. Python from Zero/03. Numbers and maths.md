# 03. Numbers and maths

**Source:** Python for Data Engineering Notes, PDF page 7 (Lesson 3).

We need arithmetic to total orders, calculate discounts, and make averages. The operators are short, but their meanings matter.

## The operators

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=1>)

~~~python
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(2 + 3 * 4, (2 + 3) * 4)
~~~

Output:

~~~text
9 5 14
3.5
3
1
1024
14 20
~~~

| Operator | Meaning | Example |
|---|---|---|
| `+`, `-`, `*` | Add, subtract, multiply | `7 * 2` is `14` |
| `/` | Divide, returning a float | `7 / 2` is `3.5` |
| `//` | Floor division | `7 // 2` is `3` |
| `%` | Remainder | `7 % 2` is `1`; `x % 2 == 0` tests evenness |
| `**` | Power | `2 ** 10` is `1024` |

Python multiplies before it adds. Parentheses change the order: `2 + 3 * 4` is 14; `(2 + 3) * 4` is 20. Floor division rounds **down**, which matters for negative values; `-7 // 2` is `-4`.

## Everyday store calculations

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=2>)

~~~python
amount = 1198
gst = amount * 0.18
print("GST:", gst, "rounded:", round(gst, 2))

total = 0
total += 1198
total += 796
total -= 50  # Discount
print("total:", total)

orders, days = 15, 4
print("average per day:", orders / days, round(orders / days, 1))
print(abs(-50), max(3, 9, 4), min(3, 9, 4))
~~~

Output:

~~~text
GST: 215.64 rounded: 215.64
total: 1944
average per day: 3.75 3.8
50 9 3
~~~

`total += 1198` is a shortcut for `total = total + 1198`. `total -= 50` subtracts the discount. `round(value, 2)` displays a value rounded to two decimal places; `abs` removes a negative sign, and `max`/`min` find extremes.

## Convert text before calculating

Data from a file or `input()` often arrives as text:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=3>)

~~~python
text_amount = "1198.50"
print(text_amount + "1")
amount = float(text_amount)
print(amount + 1)
print(int("15") + 5, int(9.99), str(42) + " orders")
~~~

Output:

~~~text
1198.501
1199.5
20 9 42 orders
~~~

The first `+` joins two strings; it does not do arithmetic. `float()` and `int()` turn suitable text into numbers. `int(9.99)` cuts off the fraction; it does not round.

## An extra store example

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=4>)

~~~python
list_price = 1499
discount = 200
sale_price = list_price - discount

print("Each:", sale_price)
print("Basket:", sale_price * items)
~~~

Output:

~~~text
Each: 1299
Basket: 3897
~~~

For money, binary floats can produce surprises: `0.1 + 0.2` is `0.30000000000000004`. The PDF introduces `Decimal` later (page 27). Use this section to understand arithmetic; use decimal arithmetic when exact currency values matter.

### 09. Python Numbers

**Source:** [Python Numbers](https://www.w3schools.com/python/python_numbers.asp). **Mentor lesson:** [Numbers and maths](<03. Numbers and maths.md>).

`int` stores whole numbers, `float` stores decimal-point numbers, and `complex` has a real and an imaginary part written with `j`. Scientific notation such as `1.2e3` is a float for 1,200.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=5>)

```python
count = 15
price = 1198.0
signal = 2 + 3j
print(type(count).__name__, type(price).__name__, type(signal).__name__)
print(1.2e3)
print(int(12.9), float(12), complex(12))
```

```text
int float complex
1200.0
12 12.0 (12+0j)
```

`int(12.9)` **truncates** the decimal part; it does not round. `complex` is useful in specialized maths, but ordinary store amounts are usually `int`, `float`, or, when exact currency arithmetic matters, `Decimal` (covered later in the mentor PDF). The standard `random` module produces random values:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=6>)

```python
import random
draw = random.randrange(1, 10)  # 1 through 9
print(1 <= draw <= 9)
```

```text
True
```

### 10. Python Casting

**Source:** [Python Casting](https://www.w3schools.com/python/python_casting.asp). **Mentor lessons:** [Numbers and maths](<03. Numbers and maths.md>) and [Input and output](<06. Input and output.md>).

Casting converts a value to a requested type. Use `int()` for whole-number text, `float()` for decimal text, and `str()` when joining a number into text.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=7>)

```python
raw_amount = "1198.50"
amount = float(raw_amount)
print(amount + 1.50)
print(int(amount))
print("order-" + str(101))
```

```text
1200.0
1198
order-101
```

`int("3.5")` raises `ValueError` because `"3.5"` is not a whole-number string; `float("3.5")` works. `int(3.5)` truncates to `3`. Always check or catch bad input before conversion if the text comes from a person or a dirty file.

### 28. Python Math

[W3Schools: Python Math](https://www.w3schools.com/python/python_math.asp) | [Part 1 Lesson 3](<03. Numbers and maths.md>) | [Part 1 Lesson 16](<16. Modules packages and pip.md>)

Some math helpers are built into Python. The **math** module adds others.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=03&snippet=8>)

~~~python
import math

amounts = [1198, 796, 1499]
print(min(amounts), max(amounts), abs(-12))
print(pow(2, 3), math.sqrt(81))
print(math.floor(3.8), math.ceil(3.2))
~~~

Output:

~~~text
796 1499 12
8 9.0
3 4
~~~

**floor** goes down to an integer and **ceil** goes up; neither means "round to the nearest integer." The module also provides **math.pi**. For exact money calculations, use the decimal arithmetic introduced later in the PDF, rather than assuming binary float is exact.
