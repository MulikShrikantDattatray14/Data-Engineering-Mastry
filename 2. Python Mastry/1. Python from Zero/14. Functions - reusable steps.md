# 14. Functions: reusable steps

**Source:** *Python for Data Engineering Notes*, page 18 of 80 (Lesson 14).

A function is a named recipe: give it inputs, let it do one job, and use its result. In the store, tax calculation should be written once and called for many orders.

## Define once, call many times

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=1>)

```python
def add_gst(amount, rate=0.18):
    """Return the amount with GST added."""
    total = amount * (1 + rate)
    return round(total, 2)

print(add_gst(1000))                    # default rate: 18%
print(add_gst(1000, 0.05))              # second positional argument
print(add_gst(rate=0.12, amount=500))  # named arguments, either order
```

```text
1180.0
1050.0
560.0
```

Read the first call step by step: `amount` becomes `1000`, `rate` uses its default `0.18`, and the function returns `1000 * 1.18`. The triple-quoted text is a **docstring** that explains what the function does.

| Word | Meaning here |
|---|---|
| Parameter | Name in the definition, such as `amount` |
| Argument | Value passed by a caller, such as `1000` |
| Default | Value used when that argument is omitted, such as `rate=0.18` |
| Return value | The result the caller receives |
| Docstring | Description immediately under `def`; view it with `help(add_gst)` |

## Printing is different from returning

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=2>)

```python
def total_print(a, b):
    print(a + b)

def total_return(a, b):
    return a + b

x = total_print(2, 3)
y = total_return(2, 3)
print("x is", x, "| y is", y)
```

```text
5
x is None | y is 5
```

`total_print` shows `5` on the screen, but the caller receives `None`. If another calculation needs the result, use `return`.

## Local variables stay inside

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=3>)

```python
def double(n):
    result = n * 2
    return result

print(double(21))
# print(result)  # NameError: result exists only inside double()
```

```text
42
```

Each function call has its own local `result`. To see the source's error, run this line after the preceding block:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=4>)

```python
print(result)
```

Python stops with:

```text
NameError: name 'result' is not defined
```

The `result` variable existed only inside `double()`. When a name fails this way, check where it was created.

## Small functions can build a bigger answer

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=5>)

```python
def is_delivered(status):
    return status.strip().lower() == "delivered"

def delivered_total(rows):
    total = 0
    for status, amount in rows:
        if is_delivered(status):
            total += amount
    return total

rows = [
    ("Delivered", 1198),
    ("cancelled", 1999),
    (" delivered ", 796),
]
print(delivered_total(rows))
```

```text
1994
```

The first helper cleans one status. The second loops over all rows and asks the helper whether to count each one. `1198 + 796 = 1994`. Short, well-named functions make a data pipeline easier to check.

### 22. Python Functions

**Source:** [W3Schools Python Functions](https://www.w3schools.com/python/python_functions.asp) | **Main lesson:** [14. Functions](<14. Functions - reusable steps.md>)

A function gives reusable steps a name. Defining one does not run its body; calling it does. A parameter is a name inside the definition, while an argument is a value you pass when calling it.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=14&snippet=6>)

~~~python
def order_label(order_id, status='pending'):
    return f'{order_id}: {status}'

print(order_label(101))
print(order_label(102, status='delivered'))
~~~

~~~text
101: pending
102: delivered
~~~

Return gives the result to the caller; print only displays it. Without return, the call returns None. A temporary empty function body can use pass, but real functions should have one clear job.
