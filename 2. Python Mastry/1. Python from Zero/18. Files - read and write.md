# 18. Files: read and write

**Source:** *Python for Data Engineering Notes*, page 22 of 80 (Lesson 18).

Data engineers receive data as files. `with open(...) as file:` opens a file and closes it at the end of the block, even if an error occurs. Start with a tiny file you can see.

## Create a small practice file

This example is self-contained. It writes **sample_orders.csv**, leaving the PDF's `orders.csv` untouched.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=1>)

```python
Path("sample_orders.csv").write_text(
    "order_id,customer_id,order_date,status,amount\n"

    "102,2,2025-01-11,cancelled,1999.00\n"
    "103,1,2025-01-12,delivered,796.00\n",
    encoding="utf-8",

```

## Read two lines, then all lines

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=2>)

```python
with open("sample_orders.csv", encoding="utf-8") as file:
    header = file.readline()
    first_row = file.readline()

print(repr(header))
print(first_row.strip().split(","))

with open("sample_orders.csv", encoding="utf-8") as file:
    lines = file.read().splitlines()
print(len(lines), "lines; last:", lines[-1])
```

```text
'order_id,customer_id,order_date,status,amount\n'
['101', '1', '2025-01-10', 'delivered', '1198.00']
4 lines; last: 103,1,2025-01-12,delivered,796.00
```

`readline()` includes the ending newline. `repr(...)` makes `\n` visible. `strip()` removes surrounding whitespace; `split(",")` turns one simple row into fields. `splitlines()` removes newline characters from the whole-file result.

The supplied [15-order file](<../python_de_dataset/orders.csv>) has 16 lines including the header, first order `101,1,2025-01-10,delivered,1198.00`, and last order `115,5,2025-04-28,delivered,1598.00`. Try the same reading code again with `python_de_dataset/orders.csv` in place of `sample_orders.csv`. These 16-line results match the PDF; the four-line result above is from the small practice file.

## Stream one row at a time

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=4>)

```python
delivered = 0
with open("sample_orders.csv", encoding="utf-8") as file:
    next(file)  # skip header
    for line in file:
        columns = line.strip().split(",")
        status, amount = columns[3], columns[4]
        if status == "delivered":
            delivered += float(amount)

print(f"delivered revenue: {delivered:,.2f}")
```

```text
delivered revenue: 1,994.00
```

The loop does not load the entire file into memory. Using the supplied `python_de_dataset/orders.csv`, the corresponding output is **18,972.00**. Simple `split(",")` is safe for these rows; a real CSV may contain quoted commas, so use the `csv` module when you reach page 33.

## Write, append, or create safely

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=5>)

```python
with open("scratch_report.txt", "w", encoding="utf-8") as file:
    file.write("date,revenue\n")
    file.write("2025-04-20,2397\n")

with open("scratch_report.txt", "a", encoding="utf-8") as file:
    file.write("2025-04-28,1598\n")

with open("scratch_report.txt", encoding="utf-8") as file:
    print(file.read(), end="")
```

```text
date,revenue
2025-04-20,2397
2025-04-28,1598
```

| Mode | Existing file | Missing file |
|---|---|---|
| `"r"` (default) | Read | `FileNotFoundError` |
| `"w"` | **Erase old contents**, then write | Create |
| `"a"` | Add to the end | Create |
| `"x"` | `FileExistsError` | Create |

> **Watch out:** Opening yesterday's report with `"w"` truncates it. Use `"a"` to add a line or `"x"` when a new file must not replace an old one.

## Paths and folders with `pathlib`

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=6>)

```python
from pathlib import Path

out_dir = Path("reports") / "2025-04"
out_dir.mkdir(parents=True, exist_ok=True)
(out_dir / "summary.txt").write_text("orders,15\n", encoding="utf-8")

print(Path("sample_orders.csv").exists(), Path("missing.csv").exists())
print(sorted(path.name for path in Path("python_de_dataset").glob("*.json*")))
print([str(path) for path in Path("reports").rglob("*.txt")])
```

The first print is `True False` after the practice file is created: the sample file exists, but the missing file does not. The JSON list from the supplied data contains `customers.json` and `events.jsonl`. The final list includes `reports/2025-04/summary.txt` (path separators may display differently on Windows). `glob` searches one folder; `rglob` searches below it.

### 29. Python JSON

[W3Schools: Python JSON](https://www.w3schools.com/python/python_json.asp) | [PDF preview: file formats, p. 33](<../Source/1793477658005.pdf#page=33>) | [Start Here dataset](<../00. Start Here.md>)

JSON is text used to exchange structured data. Python's **json** module turns JSON text into dictionaries and lists, or Python values into JSON text. From the **2. Python Mastry** folder, try the supplied customers file:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=18&snippet=7>)

~~~python
import json
from pathlib import Path

text = Path("python_de_dataset/customers.json").read_text(encoding="utf-8")
customers = json.loads(text)

print(len(customers))
print(customers[5]["name"], customers[5]["address"]["city"])
print(json.dumps({"active": True, "city": None}, sort_keys=True))
~~~

Output:

~~~text
8
Sana None
{"active": true, "city": null}
~~~

**loads** reads from a string; **load** reads from an open file. **dumps** returns a string; **dump** writes to a file. Python **True** and **None** become JSON **true** and **null**. For a readable JSON string, pass **indent=2** to **json.dumps**.
