# 05. True, False, and comparisons

**Source:** Python for Data Engineering Notes, PDF page 9 (Lesson 5).

A program makes decisions by asking questions that evaluate to `True` or `False`. Those two values have the type `bool`.

## Ask questions about values

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=1>)

~~~python
amount = 1198
print(amount > 1000, amount < 500)
print(amount == 1198, amount != 1198)
print(amount >= 1198, amount <= 1000)
print(500 < amount < 2000)

status = "delivered"
print(status == "Delivered")
print(status.lower() == "delivered")
~~~

Output:

~~~text
True False
True False
True False
True
False
True
~~~

`=` **assigns** a value. `==` **compares** two values. `!=` asks whether they differ. `>=` and `<=` include equality. Python can chain comparisons, so `500 < amount < 2000` means the amount is above 500 and below 2000.

Strings are case sensitive: `"delivered"` and `"Delivered"` differ. Normalizing with `.lower()` can make a comparison predictable.

## Combine questions

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=2>)

~~~python
amount, status = 1198, "delivered"
print(amount > 1000 and status == "delivered")
print(amount > 5000 or status == "delivered")
print(not status == "cancelled")
~~~

Output:

~~~text
True
True
True
~~~

`and` requires both sides; `or` requires at least one side; `not` reverses the result.

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

Other useful checks: `x in [1, 2, 3]` asks whether a value occurs in a collection. Use `x is None` to check for the "no value" object.

## Truthy and falsy values

Python also allows values directly in a condition. `bool(value)` shows how Python sees them:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=3>)

~~~python
for value in [0, 15, "", "Pune", [], [1, 2], None]:
    print(repr(value), "->", bool(value))
~~~

Output:

~~~text
0 -> False
15 -> True
'' -> False
'Pune' -> True
[] -> False
[1, 2] -> True
None -> False
~~~

Empty values such as `0`, `""`, `[]`, `{}`, and `None` are falsy. Nonempty values are usually truthy. Thus `if name:` is a quick way to say "if the name is nonempty." A nonempty string such as `"False"` is still truthy; Python looks at whether it is empty, not at the word it contains.

## An extra store example

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=4>)

~~~python
amount = 799
status = "Delivered"
city = "Mumbai"
is_paid_sale = amount > 0 and status.lower() == "delivered"
is_metro = city in ["Bengaluru", "Mumbai", "Delhi"]

~~~

Output:

~~~text
True True
~~~

### 12. Python Booleans

**Source:** [Python Booleans](https://www.w3schools.com/python/python_booleans.asp). **Mentor lesson:** [True, False and comparisons](<05. True False and comparisons.md>).

A comparison returns `True` or `False`. `bool(value)` asks whether Python considers a value truthy. Empty strings and collections, zero, `None`, and `False` are falsey. Nonempty text is truthy, even the text `"0"`.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=5>)

```python
print(1198 > 1000, 1198 == 1000)
print(bool(""), bool("0"), bool([]), bool([101]))
print(isinstance(101, int))
```

```text
True False
False True False True
True
```

`isinstance(value, int)` checks the value's type. When a field might be missing, do not use truthiness to decide whether it is **zero** or **absent**: both `0` and `None` are falsey, so use `is None` when that distinction matters.

### 13. Python Operators

**Source:** [Python Operators](https://www.w3schools.com/python/python_operators.asp). **Mentor lessons:** [Numbers and maths](<03. Numbers and maths.md>) and [True, False and comparisons](<05. True False and comparisons.md>).

Operators calculate, compare, and combine values:

| Group | Operators to recognize | Example question |
|---|---|---|
| Arithmetic | `+`, `-`, `*`, `/`, `//`, `%`, `**` | How many packs, and how many left over? |
| Assignment | `=`, `+=`, `-=` | Update a running total |
| Comparison | `==`, `!=`, `<`, `<=`, `>`, `>=` | Is this order large? |
| Logical | `and`, `or`, `not` | Is it delivered **and** paid? |
| Membership | `in`, `not in` | Is this status allowed? |
| Identity | `is`, `is not` | Is this value `None`? |
| Bitwise | `&`, `|`, `^`, `~`, `<<`, `>>` | Work with integer bits |

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=05&snippet=6>)

```python
qty = 7
statuses = {"delivered", "returned"}
status = "delivered"
discount = None

print(qty // 2, qty % 2, 2 ** 3)
print(status in statuses, discount is None, qty > 0 and status == "delivered")
print(5 & 3, 5 | 3)
```

```text
3 1 8
True True True
1 7
```

`//` gives whole packs and `%` gives the remainder. Use `and` and `or` for conditions; `&` and `|` operate on bits in these integer examples. `==` compares values, while `is` checks identity; `is None` is the standard missing-value check. Parentheses help make mixed calculations and conditions easier to read.
