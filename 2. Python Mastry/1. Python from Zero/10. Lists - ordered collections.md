# 10. Lists: ordered collections

**Source:** *Python for Data Engineering Notes*, page 14 of 80 (Lesson 10).

A list keeps several values **in order**. Imagine the store has a queue of cities to visit. The first city is at position `0`; `-1` means the last city.

## Build and change a list

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=10&snippet=1>)

```python
cities = ["Bengaluru", "Mumbai", "Delhi"]
print(cities[0], cities[-1], len(cities))

cities.append("Pune")          # put Pune at the end
cities.insert(1, "Chennai")    # put Chennai before Mumbai
print(cities)

cities.remove("Delhi")         # delete a value
last = cities.pop()            # take and return the last value
print(cities, "| popped:", last)

cities[0] = "Bangalore"        # replace one value
print(cities, "Mumbai" in cities)
```

```text
Bengaluru Delhi 3
['Bengaluru', 'Chennai', 'Mumbai', 'Delhi', 'Pune']
['Bengaluru', 'Chennai', 'Mumbai'] | popped: Pune
['Bangalore', 'Chennai', 'Mumbai'] True
```

Follow the state: the list starts with three cities, grows to five, shrinks to three, and then its first value changes. Lists are **mutable**: editing them changes the same object.

| Operation | Meaning | Example |
|---|---|---|
| `append(x)` | Add one value at the end | `cities.append("Pune")` |
| `extend(other)` | Add every value from another sequence | `cities.extend(["Goa", "Jaipur"])` |
| `insert(i, x)` | Insert before position `i` | `cities.insert(1, "Chennai")` |
| `remove(x)` | Remove the first matching value | `cities.remove("Delhi")` |
| `pop(i)` | Remove and return a value; defaults to the last | `cities.pop()` |
| `index(x)`, `count(x)` | Find a position or count matches | `cities.count("Pune")` |
| `sort()`, `reverse()` | Reorder the same list | `cities.sort()` |
| `copy()`, `clear()` | Make a shallow copy or empty the list | `other = cities.copy()` |

## Calculate, sort, and slice

These five amounts can represent store orders. A slice `amounts[start:stop]` includes `start` and excludes `stop`.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=10&snippet=2>)

```python
amounts = [1198, 796, 1499, 1999, 1348]

print(sum(amounts), min(amounts), max(amounts))
print(sorted(amounts))                    # new sorted list
print(sorted(amounts, reverse=True)[:3])  # three largest
print(amounts[1:3], amounts[::-1])        # middle slice, reverse

amounts.sort()                            # change the original
print(amounts)

big = [amount for amount in amounts if amount > 1300]
print(big)
```

```text
6840 796 1999
[796, 1198, 1348, 1499, 1999]
[1999, 1499, 1348]
[796, 1499] [1348, 1999, 1499, 796, 1198]
[796, 1198, 1348, 1499, 1999]
[1348, 1499, 1999]
```

The last line is a *list comprehension*: it builds a new list from only the amounts passing a condition. Part 2 returns to this idea.

> **Watch out:** `sorted(amounts)` returns a new list. `amounts.sort()` changes the list and returns `None`. Do not assign `amounts = amounts.sort()`.

## A tiny table made of lists

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=10&snippet=3>)

```python
orders = [
    [101, "Aarav", 1198],
    [102, "Diya", 796],
    [103, "Aarav", 1499],
]

for order_id, name, amount in orders:
    print(order_id, name, amount)

print(orders[2][1])  # row at position 2, column at position 1
```

```text
101 Aarav 1198
102 Diya 796
103 Aarav 1499
Aarav
```

Each inner list is one row. Unpacking gives meaningful names to the three positions. A list of dictionaries (Lesson 12) will make column names explicit.

### 14. Python Lists

**Source:** [W3Schools Python Lists](https://www.w3schools.com/python/python_lists.asp) | **Main lesson:** [10. Lists](<10. Lists - ordered collections.md>)

A list keeps items in order. Positions start at 0. You can replace, add, or remove an item, and repeated values are allowed. This is useful for order rows in arrival order.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=10&snippet=4>)

~~~python
amounts = [1198, 796, 1198]
amounts[1] = 899             # replace the second amount
amounts.append(1499)         # add at the end
print(amounts[0], len(amounts), amounts.count(1198))
print(amounts[1:3])           # positions 1 and 2
~~~

~~~text
1198 4 2
[899, 1198]
~~~

The slice stops before position 3. Use list methods such as append, pop, and sort when you need to modify the same list. Use sorted(amounts) when you want a new sorted result and want to keep the original order intact.

### 24. Python Arrays

**Source:** [W3Schools Python Arrays](https://www.w3schools.com/python/python_arrays.asp) | **Related lesson:** [10. Lists](<10. Lists - ordered collections.md>)

This W3Schools beginner page calls an ordinary Python list an 'array'. Its indexing, append, pop, and remove examples therefore use list behavior. Python also has a separate standard-library array module and third-party NumPy arrays, which serve different needs.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=10&snippet=5>)

~~~python
prices = [799, 1499, 399]
prices.append(1198)
prices.pop(1)           # remove the item at index 1
print(prices[0], len(prices))
print(prices)
~~~

~~~text
799 3
[799, 399, 1198]
~~~

The remaining values kept their order. List remove(value) removes the first matching value; pop(index) removes by position.
