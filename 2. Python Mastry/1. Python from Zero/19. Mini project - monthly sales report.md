## Step 1: read rows with column names

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=19&snippet=1>)

```python
def read_orders(path):
    """Read a simple orders.csv into a list of dictionaries."""
    rows = []
    with open(path, encoding="utf-8") as file:
        header = file.readline().strip().split(",")
        for line in file:
            values = line.strip().split(",")
            rows.append(dict(zip(header, values)))
    return rows
```

If the header is `order_id,customer_id,order_date,status,amount`, `zip(header, values)` pairs every name with its field. `dict(...)` makes a row such as `{"order_id": "101", "status": "delivered", ...}`. File fields are initially strings, so amounts need conversion before arithmetic. This simple parser assumes no quoted commas; Lesson 18 points to the `csv` module for real CSVs.

## Step 2: identify a month and keep what counts

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=19&snippet=2>)

```python
def month_of(day):
    return day[:7]  # "2025-04-20" -> "2025-04"

def build_report(rows):
    report = {}

    for row in rows:
        if row["status"] != "delivered":
            continue

        month = month_of(row["order_date"])
        if month not in report:
            report[month] = {"orders": 0, "revenue": 0.0, "best": 0.0}

        stats = report[month]
        amount = float(row["amount"])
        stats["orders"] += 1
        stats["revenue"] += amount
        if amount > stats["best"]:
            stats["best"] = amount

    return report
```

Follow one delivered row from April: `month_of` gives `"2025-04"`. If April is new, the dictionary starts at zero. The row adds one order, increases revenue by its amount, and may replace the best order amount. A cancelled or returned row hits `continue`, so it changes none of those numbers.

## Step 3: print a readable result

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=19&snippet=3>)

```python
def print_report(report):
    print(f"{'month':<9}{'orders':>7}{'revenue':>11}"
          f"{'average':>10}{'best':>9}")
    print("-" * 46)

    grand = 0.0
    for month in sorted(report):
        stats = report[month]
        avg = stats["revenue"] / stats["orders"]
        grand += stats["revenue"]
        print(f"{month:<9}{stats['orders']:>7}"
              f"{stats['revenue']:>11,.2f}{avg:>10,.2f}"
              f"{stats['best']:>9,.0f}")

    print("-" * 46)
    print(f"{'total':<9}{'':>7}{grand:>11,.2f}")
```

The widths (`<9`, `>7`, and so on) align columns; `,.2f` adds thousands separators and two decimal places. The sorted month keys put January before February.
