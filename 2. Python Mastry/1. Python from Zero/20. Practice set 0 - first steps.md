## Q1. FizzBuzz from 1 to 15

Print the numbers 1 to 15, but print `"Fizz"` for multiples of 3, `"Buzz"` for multiples of 5, and `"FizzBuzz"` for multiples of both. *Difficulty: Easy (DA and DE).*

<details>
<summary>Show approach and solution</summary>

Check the both-divisible case **first**. `%` gives a remainder, so `n % 15 == 0` means `n` is divisible by 3 and 5.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=20&snippet=1>)

```python
out = []
for n in range(1, 16):
    if n % 15 == 0:
        out.append("FizzBuzz")
    elif n % 3 == 0:
        out.append("Fizz")
    elif n % 5 == 0:
        out.append("Buzz")
    else:
        out.append(str(n))
print(" ".join(out))
```

```text
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
```

</details>

## Q2. Smallest and largest without `min` or `max`

Find both values in `[1198, 796, 1499, 1999, 747, 3498]` without calling `min()` or `max()`. *Difficulty: Easy (DA and DE).*

<details>
<summary>Show approach and solution</summary>

Start at the **first real value**, not zero. Starting at zero would give a wrong maximum for a list of negative numbers.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=20&snippet=2>)

```python
amounts = [1198, 796, 1499, 1999, 747, 3498]
low = high = amounts[0]
for amount in amounts[1:]:
    if amount > high:
        high = amount
    if amount < low:
        low = amount
print(low, high)
```

```text
747 3498
```

</details>

## Q3. Count words without caring about case

Count each word in `"Data pipelines move data and data pipelines fail"`. *Difficulty: Easy (DA and DE).*

<details>
<summary>Show approach and solution</summary>

Lowercase first, split into words, then add one to the dictionary value under each word.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=20&snippet=3>)

```python
text = "Data pipelines move data and data pipelines fail"
counts = {}
for word in text.lower().split():
    counts[word] = counts.get(word, 0) + 1
print(counts)
```

```text
{'data': 3, 'pipelines': 2, 'move': 1, 'and': 1, 'fail': 1}
```

</details>

## Q4. Palindrome ignoring spaces and case

Return whether a phrase reads the same backwards. Ignore spaces, case, and nonletters. Check `"Never odd or even"` and `"Python"`. *Difficulty: Easy (DA and DE).*

<details>
<summary>Show approach and solution</summary>

Keep letters, lowercase them, then compare the result with its reverse slice.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=20&snippet=4>)

```python
def is_palindrome(text):
    letters = "".join(ch.lower() for ch in text if ch.isalpha())
    return letters == letters[::-1]

print(is_palindrome("Never odd or even"), is_palindrome("Python"))
```

```text
True False
```

</details>

## Q5. Share of orders by status

For every status in the store's `orders.csv`, report its count and its share of all orders as a percentage. *Difficulty: Easy (DA).*

<details>
<summary>Show approach and solution</summary>

Collect statuses, count them, then divide each count by the number of orders. Run from the `2. Python Mastry` folder; the supplied file is `python_de_dataset/orders.csv`.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=20&snippet=5>)

```python
statuses = []
with open("python_de_dataset/orders.csv", encoding="utf-8") as file:
    next(file)  # skip header
    for line in file:
        statuses.append(line.strip().split(",")[3])

counts = {}
for status in statuses:
    counts[status] = counts.get(status, 0) + 1

for status, count in counts.items():
    print(f"{status:<10} {count:>2}  {count / len(statuses):.1%}")
```

**Expected output for the supplied 15-order file (matches the PDF):**

```text
delivered  12  80.0%
cancelled   2  13.3%
returned    1  6.7%
```

For a self-contained check, replace the file-reading block with `statuses = ["delivered", "cancelled", "delivered"]`. The counting and formatting code then works on that smaller example.

</details>
