# 12. Dictionaries: key and value

**Source:** *Python for Data Engineering Notes*, page 16 of 80 (Lesson 12).

A dictionary connects a **key** to a **value**. For a customer record, keys such as `"name"` and `"city"` act like column names. For a lookup table, a product name can point to its price.

## Create, read, and update a record

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=1>)

```python
customer = {"id": 4, "name": "Meera", "city": "Bengaluru"}
print(customer["name"])

customer["city"] = "Pune"   # change
customer["tier"] = "gold"   # add
del customer["id"]        # remove
print(customer)

print(customer.get("phone"), customer.get("phone", "not given"))
print("tier" in customer, len(customer))
```

```text
Meera
{'name': 'Meera', 'city': 'Pune', 'tier': 'gold'}
None not given
True 3
```

`customer["phone"]` would raise `KeyError`, because that key does not exist. `customer.get("phone")` returns `None`; its optional second argument supplies a fallback.

## Loop through keys and values

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=2>)

```python
prices = {"Mouse": 799, "Hub": 1499, "Pens": 149}

for product in prices:  # keys
    print(product, end=" ")
print()

for product, price in prices.items():
    print(f"{product:<6} {price:>5}")

print(list(prices.keys()))
print(list(prices.values()))
```

```text
Mouse Hub Pens
Mouse    799
Hub     1499
Pens     149
['Mouse', 'Hub', 'Pens']
[799, 1499, 149]
```

`.items()` gives each `(key, value)` pair. Dictionaries preserve insertion order in modern Python, but use a deliberate `sorted(...)` when a report requires alphabetical output.

## Job 1: count events

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=3>)

```python
statuses = ["delivered", "cancelled", "delivered",
            "returned", "delivered"]
counts = {}

for status in statuses:
    counts[status] = counts.get(status, 0) + 1

print(counts)
```

```text
{'delivered': 3, 'cancelled': 1, 'returned': 1}
```

On the first `"delivered"`, `.get(..., 0)` supplies zero. The next two occurrences add one each. The status is the key; its count is the value.

The PDF also spells out the count update with `if` and `else`:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=4>)

```python
statuses = ["delivered", "cancelled", "delivered",
            "returned", "delivered"]
counts = {}
for status in statuses:
    if status in counts:
        counts[status] += 1
    else:
        counts[status] = 1
print(counts)
```

```text
{'delivered': 3, 'cancelled': 1, 'returned': 1}
```

The first occurrence creates the key with a count of 1; later occurrences increase it. The `.get(status, 0) + 1` version above does the same work in one line.

## Job 2: group and sum orders

A list of dictionaries is a small table with named columns:

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=5>)

```python
orders = [
    {"id": 101, "city": "Pune", "amount": 1198},
    {"id": 102, "city": "Delhi", "amount": 796},
    {"id": 103, "city": "Pune", "amount": 1499},
]
by_city = {}

for order in orders:
    city = order["city"]
    by_city[city] = by_city.get(city, 0) + order["amount"]

print(by_city)
```

```text
{'Pune': 2697, 'Delhi': 796}
```

The second Pune row updates the existing Pune total: `1198 + 1499 = 2697`. Counting and grouping share the same pattern: choose a key, then update the value stored under it. JSON files, APIs, and `csv.DictReader` often give records in this shape.

### 17. Python Dictionaries

**Source:** [W3Schools Python Dictionaries](https://www.w3schools.com/python/python_dictionaries.asp) | **Main lesson:** [12. Dictionaries](<12. Dictionaries - key and value.md>)

A dictionary maps a key to a value. Its keys are unique, and assigning an existing key replaces its previous value. Modern Python preserves insertion order, but keys are still used to look up values.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=6>)

~~~python
order = {'id': 101, 'city': 'Pune', 'amount': 1198}
order['status'] = 'delivered'
print(order['city'], order.get('coupon', 'none'))

counts = {}
for status in ['delivered', 'cancelled', 'delivered']:
    counts[status] = counts.get(status, 0) + 1
print(counts)
~~~

~~~text
Pune none
{'delivered': 2, 'cancelled': 1}
~~~

A missing key with order['coupon'] would raise KeyError; get supplies a fallback. Dictionary values may repeat even though keys cannot. Loop over dictionary.items() when you need both key and value.

### 34. Python None

[W3Schools: Python None](https://www.w3schools.com/python/python_none.asp) | [Part 1 Lesson 12](<12. Dictionaries - key and value.md>) | [Part 1 Lesson 14](<14. Functions - reusable steps.md>)

**None** means no value is present. It differs from **0**, an empty string, and the text **"None"**. Compare with **is None** or **is not None**.

[▶ Run and edit this example](<http://127.0.0.1:8765/?lesson=12&snippet=7>)

~~~python
city = None

if city is None:
    print("City is missing")
print(bool(city))

def show_order():
    print("Order checked")

result = show_order()
print(result)
~~~

Output:

~~~text
City is missing
False
Order checked
None
~~~

None is false in a condition. A function without a **return** statement also returns None, as **show_order** does here. In the supplied customer file, Sana's missing city appears as JSON **null**, which becomes Python **None**.
