## Practice

Open [Start Practice.cmd](<../Start Practice.cmd>) or run the local [practice runner](<../practice_runner.py>) from the Python Mastry folder. Follow **Run and edit this example** beside a Python snippet. The editor keeps the original snippet and your draft separately. The supplied [store dataset](<../python_de_dataset/README.md>) is copied into the runner's temporary practice folder.

The PDF examples use Python 3.12 syntax; use Python 3.12 or newer. Expected timings and memory sizes vary by machine. This Part uses only the Python standard library.
