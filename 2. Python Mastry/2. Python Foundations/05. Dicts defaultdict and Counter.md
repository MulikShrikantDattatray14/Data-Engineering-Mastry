A dictionary connects a key to a value. In a store pipeline, the key may be a customer ID, status, or two-column tuple. The value may be a row, count, total, or list of rows.

## Build a safe lookup

Square brackets raise <code>KeyError</code> for a missing key. <code>get()</code> returns <code>None</code> or a fallback. A fallback in <code>get()</code> only applies when the key is absent; it does not replace an existing <code>None</code> value.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=05&snippet=1>)

~~~python
customers = [
    {"id": 1, "name": "Aarav", "city": "Pune"},
    {"id": 2, "name": "Diya", "city": None},
]
by_id = {row["id"]: row for row in customers}
print(by_id[1]["name"])
print(by_id.get(99))
print(by_id[2].get("city", "Unknown"))
print(by_id[2].get("city") or "Unknown")
~~~

Expected output:

~~~text
Aarav
None
None
Unknown
~~~

For a nested row, <code>(row.get("address") or {}).get("city") or "Unknown"</code> covers missing dictionaries and a city explicitly set to <code>None</code>.

## Group and count

<code>defaultdict(list)</code> gives each new key its own empty list. <code>Counter</code> counts items and supplies <code>most_common()</code>. Dictionary union creates a new dictionary; the right-hand value wins for duplicate keys.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=05&snippet=2>)

~~~python
from collections import Counter, defaultdict

items = [(101, "mouse"), (101, "hub"), (102, "mouse")]
by_order = defaultdict(list)
for order_id, product in items:
    by_order[order_id].append(product)
print(dict(by_order))
print(Counter(product for _, product in items).most_common())
print({"retries": 3, "env": "dev"} | {"env": "prod"})
~~~

Expected output:

~~~text
{101: ['mouse', 'hub'], 102: ['mouse']}
[('mouse', 2), ('hub', 1)]
{'retries': 3, 'env': 'prod'}
~~~

Keys must be hashable because the dictionary uses their hash to locate a slot. Avoid adding or deleting keys while looping over <code>dict.items()</code>; build a new dictionary instead.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=05&snippet=3>)

~~~python
prices = {"mouse": 799, "hub": 1499, "pens": 149}
kept = {name: price for name, price in prices.items() if price >= 500}
print(kept)
~~~

Expected output:

~~~text
{'mouse': 799, 'hub': 1499}
~~~

Dictionary lookup is O(1) on average; the table itself uses extra memory.

Dictionary keys retain their insertion order (guaranteed in Python 3.7 and newer). Updating an existing key changes its value without moving it. This matters when a pipeline's output must follow the order in which IDs first appeared; sort explicitly when the required order is different.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=05&snippet=4>)

~~~python
status_by_id = {}
status_by_id[102] = "placed"
status_by_id[101] = "placed"
status_by_id[102] = "delivered"
print(list(status_by_id.items()))
~~~

Expected output:

~~~text
[(102, 'delivered'), (101, 'placed')]
~~~

The [Dictionaries lesson](https://www.w3schools.com/python/python_dictionaries.asp) covers creating and reading keys. This original example counts arrivals without <code>Counter</code>:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=05&snippet=5>)

~~~python
statuses = ["paid", "paid", "pending"]
counts = {}
for status in statuses:
    counts[status] = counts.get(status, 0) + 1
print(counts)
~~~

Expected output:

~~~text
{'paid': 2, 'pending': 1}
~~~
