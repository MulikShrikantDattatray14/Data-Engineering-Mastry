## Q7. Count and total orders by status

Read <code>orders.csv</code> without pandas. Return each status, its order count, and its total amount. Expected lines are cancelled 2 and 3498.00; delivered 12 and 18972.00; returned 1 and 798.00.

<details>
<summary>Show approach and runnable answer</summary>

Use one dictionary keyed by status. Each row updates a count and a money total.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=10&snippet=1>)

~~~python
import csv
from collections import defaultdict
from decimal import Decimal

stats = defaultdict(lambda: [0, Decimal("0")])
with open("python_de_dataset/orders.csv", newline="", encoding="utf-8") as file:
    for row in csv.DictReader(file):
        group = stats[row["status"]]
        group[0] += 1
        group[1] += Decimal(row["amount"])
for status, (count, total) in sorted(stats.items()):
    print(status, count, total)
~~~

Expected output:

~~~text
cancelled 2 3498.00
delivered 12 18972.00
returned 1 798.00
~~~

</details>

## Q8. Customers who never ordered

Compare customer IDs from <code>customers.json</code> with customer IDs from <code>orders.csv</code>. Expected name: Zoya.

<details>
<summary>Show approach and runnable answer</summary>

Use set difference for IDs and a dictionary to look up names.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=10&snippet=2>)

~~~python
import csv
import json

with open("python_de_dataset/customers.json", encoding="utf-8") as file:
    customers = json.load(file)
with open("python_de_dataset/orders.csv", newline="", encoding="utf-8") as file:
    ordered = {int(row["customer_id"]) for row in csv.DictReader(file)}
never = [c["name"] for c in customers if c["customer_id"] not in ordered]
print(never)
~~~

Expected output:

~~~text
['Zoya']
~~~

## Q9. Count events per device

The device field is nested under <code>props</code> in <code>events.jsonl</code>. Stream the lines and handle a missing device as <code>unknown</code>.

<details>
<summary>Show approach and runnable answer</summary>

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=10&snippet=3>)

~~~python
import json
from collections import Counter

with open("python_de_dataset/events.jsonl", encoding="utf-8") as file:
    devices = Counter(
        json.loads(line).get("props", {}).get("device", "unknown")
        for line in file
    )
print(devices.most_common())
~~~

Expected output:

~~~text
[('mobile', 7), ('desktop', 4), ('tablet', 1)]
~~~

</details>

## Q10. Clean money strings

Convert <code>"₹1,198.00"</code>, <code>" 796 "</code>, <code>"N/A"</code>, and <code>"1,499.5"</code> into Decimals. Keep rejected strings separately.

<details>
<summary>Show approach and runnable answer</summary>

Strip the currency symbol, commas, and spaces. Catch only <code>InvalidOperation</code>.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=10&snippet=4>)

~~~python
from decimal import Decimal, InvalidOperation

raw = ["₹1,198.00", " 796 ", "N/A", "1,499.5"]
clean, rejected = [], []
for text in raw:
    value = text.replace("₹", "").replace(",", "").strip()
    try:
        clean.append(Decimal(value))
    except InvalidOperation:
        rejected.append(text)
print(clean, rejected)
~~~

Expected output:

~~~text
[Decimal('1198.00'), Decimal('796'), Decimal('1499.5')] ['N/A']
~~~

</details>

## Q11. Second-highest distinct salary

Use <code>employees.csv</code>. Tied salaries count once; return <code>None</code> if fewer than two distinct values exist.

<details>
<summary>Show approach and runnable answer</summary>

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=10&snippet=5>)

import csv

with open("python_de_dataset/employees.csv", newline="", encoding="utf-8") as file:
    salaries = {int(row["salary"]) for row in csv.DictReader(file)}

second = ordered[1] if len(ordered) > 1 else None
