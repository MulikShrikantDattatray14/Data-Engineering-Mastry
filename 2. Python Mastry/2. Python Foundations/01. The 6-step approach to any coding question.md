## The six moves

| Move | Question to answer | Store example |
|---|---|---|
| 1. Pin input and output | What exactly comes in and goes out? | Order rows in; customer totals out. |
| 2. List edge cases | What might be missing or repeated? | Cancelled orders, money stored as text, tied totals. |
| 3. State a simple method | What is the first correct approach? | Scan all orders for each customer. |
| 4. Choose a structure | Which container removes repeated work? | A dictionary keyed by customer ID. |
| 5. Split into steps | What should each function do? | Read, total, sort. |
| 6. Test and cost | Does the sample work and how does work grow? | One pass plus sorting the customers. |

## Walk a small input by hand

The output should contain only customers with delivered orders. Customer 1 has two delivered rows, so their total is 120 + 80 = 200. The cancelled row contributes nothing.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=01&snippet=1>)

~~~python
orders = [
    {"customer_id": 1, "status": "delivered", "amount": 120},
    {"customer_id": 2, "status": "cancelled", "amount": 900},
    {"customer_id": 1, "status": "delivered", "amount": 80},
    {"customer_id": 3, "status": "delivered", "amount": 50},
]
totals = {}
for row in orders:
    if row["status"] == "delivered":
        cid = row["customer_id"]
        totals[cid] = totals.get(cid, 0) + row["amount"]
print(sorted(totals.items(), key=lambda pair: (-pair[1], pair[0])))
~~~

Expected output:

~~~text
[(1, 200), (3, 50)]
~~~

The dictionary avoids scanning all orders again for each customer. If there are <code>n</code> orders and <code>k</code> customers in the answer, totaling costs O(n) time and O(k) memory. Sorting costs O(k log k).

## Apply it to the supplied store data (PDF Q6)

Use <code>Decimal</code> for money and convert IDs from CSV text to integers. The secondary sort key makes smaller customer IDs win ties.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=01&snippet=2>)

~~~python
import csv
from collections import defaultdict
from decimal import Decimal

def load_rows(path):
    with open(path, newline="", encoding="utf-8") as file:
        yield from csv.DictReader(file)

def delivered_totals(rows):
    totals = defaultdict(Decimal)
    for row in rows:
        if row["status"] == "delivered":
            totals[int(row["customer_id"])] += Decimal(row["amount"])
    return totals

totals = delivered_totals(load_rows("python_de_dataset/orders.csv"))
for cid, total in sorted(totals.items(), key=lambda item: (-item[1], item[0])):
    print(cid, total)
~~~

Expected output:

~~~text
5 5096.00
1 5094.00
2 4143.00
6 1998.00
4 1048.00
7 846.00
3 747.00
~~~

Customer 8 has no delivered order and does not enter the dictionary. Always check one total by hand before trusting the sort.
