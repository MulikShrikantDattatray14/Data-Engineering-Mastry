## Build list, set, and dictionary results

Use brackets for a list, braces for a set or dictionary, and parentheses for a generator expression. A set removes duplicates; a generator feeds values without building a list.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=06&snippet=1>)

~~~python
rows = [
    {"id": 101, "status": "delivered", "amount": 120},
    {"id": 102, "status": "cancelled", "amount": 900},
    {"id": 103, "status": "delivered", "amount": 80},
]
amounts = [r["amount"] for r in rows if r["status"] == "delivered"]
statuses = {r["status"] for r in rows}
by_id = {r["id"]: r["status"] for r in rows}
print(amounts, sorted(statuses), by_id[102])
print(sum(r["amount"] for r in rows if r["status"] == "delivered"))
print([x for row in [[1, 2], [3], [4, 5]] for x in row])
~~~

Expected output:

~~~text
[120, 80] ['cancelled', 'delivered'] cancelled
200
[1, 2, 3, 4, 5]
~~~

## Keep positions and pair parallel lists

<code>enumerate()</code> adds an index. Ordinary <code>zip()</code> stops at the shorter input, which can silently lose data. Use <code>strict=True</code> when equal lengths are required. Star unpacking collects the remaining values. <code>any()</code> and <code>all()</code> test an iterable.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=06&snippet=2>)

~~~python
ids = [101, 102, 103]
names = ["Aarav", "Diya"]
print(list(zip(ids, names)))
try:
    print(list(zip(ids, names, strict=True)))
except ValueError:
    print("length mismatch")
for position, name in enumerate(names, start=1):
    print(position, name)
first, *rest = ids
print(first, rest)
print(any(name.startswith("D") for name in names),
      all(order_id > 100 for order_id in ids))
~~~

Expected output:

~~~text
[(101, 'Aarav'), (102, 'Diya')]
length mismatch
1 Aarav
2 Diya
101 [102, 103]
True True
~~~

## Other loop shapes

A <code>for ... else</code> clause runs only if no <code>break</code> happened. The walrus operator <code>:=</code> assigns a value while testing it. <code>map()</code> and <code>filter()</code> can express transformations, but a comprehension is often easier to read.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=06&snippet=3>)

~~~python
amounts = [120, 80, 50]
for amount in amounts:
    if amount > 100:
        print("first large:", amount)
        break
else:
    print("none large")
if (count := len(amounts)) > 2:
    print("batch size:", count)
print(sum(float(x) for x in ["120", "", "80"] if x))
~~~

Expected output:

~~~text
first large: 120
batch size: 3
200.0
~~~
