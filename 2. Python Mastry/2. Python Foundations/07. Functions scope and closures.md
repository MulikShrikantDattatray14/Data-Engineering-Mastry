## Arguments and returned values

<code>*columns</code> collects extra positional arguments in a tuple. <code>**options</code> collects extra keyword arguments in a dictionary. A bare <code>*</code> makes later parameters keyword-only, so the call tells readers what a number means.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=07&snippet=1>)

~~~python
def describe(path, *columns, sep=",", **options):
    return path, columns, sep, options

print(describe("orders.csv", "order_id", "amount", sep="|", skip=1))

def area(*, width, height):
    return width * height

print(area(width=3, height=4))

def summary(values):
    return min(values), max(values), sum(values) / len(values)

low, high, average = summary([747, 3498, 1048])
print(low, high, round(average, 1))
~~~

Expected output:

~~~text
('orders.csv', ('order_id', 'amount'), '|', {'skip': 1})
12
747 3498 1764.3
~~~

## Scope and a closure

Python looks up a name in Local, Enclosing, Global, then Built-in scope. Assigning to a name inside a function makes that name local for the whole function; reading it before assignment causes <code>UnboundLocalError</code>. A nested function can use <code>nonlocal</code> to update its enclosing function's variable.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=07&snippet=2>)

~~~python
count = 0
def broken_bump():
    count += 1

try:
    broken_bump()
except UnboundLocalError:
    print("local count was not set")

def make_counter():
    count = 0
    def bump():
        nonlocal count
        count += 1
        return count
    return bump

counter = make_counter()
print(counter(), counter(), counter())
~~~

Expected output:

~~~text
local count was not set
1 2 3
~~~

A closure reads a variable when called, not necessarily its value when created. A default parameter can freeze a loop value now.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=07&snippet=3>)

~~~python
late = [lambda: i for i in range(3)]
fixed = [lambda i=i: i for i in range(3)]
print([fn() for fn in late])
print([fn() for fn in fixed])
~~~

Expected output:

~~~text
[2, 2, 2]
[0, 1, 2]
~~~

## Put pure transforms in the middle

A pure function returns a result from its arguments without reading files or changing hidden state. Type hints document intended input and output; Python does not enforce them automatically.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=07&snippet=4>)

~~~python
STATUS_MAP = {"dlvd": "delivered", "canceled": "cancelled"}

def normalize_status(raw: str | None) -> str:
    if not raw:
        return "unknown"
    clean = raw.strip().lower()
    return STATUS_MAP.get(clean, "unknown")

print([normalize_status(x) for x in [" DLVD ", "Canceled", None, "Shipped"]])
~~~

Expected output:

~~~text
['delivered', 'cancelled', 'unknown', 'unknown']
~~~

Read and write files at the edges; pure functions in between are easier to test and reuse.

## More from W3Schools: scope

The [Python Scope lesson](https://www.w3schools.com/python/python_scope.asp) covers local, enclosing, and global names. This original example shows an inner function reading its enclosing value:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=07&snippet=5>)

~~~python
def label_for(month):
    prefix = "Sales"
    def make_label():
        return f"{prefix}: {month}"
    return make_label()

print(label_for("April"))
~~~

Expected output:

~~~text
Sales: April
~~~
