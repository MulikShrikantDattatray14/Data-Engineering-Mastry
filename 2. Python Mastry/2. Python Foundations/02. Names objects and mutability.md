A Python name points to an object. When two names point to the same mutable list, a change through either name is visible through both.

## Equality and identity

<code>==</code> asks whether values match. <code>is</code> asks whether two names point to the same object. Use <code>is None</code> when checking for no value; do not use <code>is</code> as a substitute for value comparison.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=02&snippet=1>)

~~~python
orders = [101, 102]
same_list = orders
copy_list = orders.copy()
print(orders == copy_list, orders is copy_list)
same_list.append(103)
print(orders)
print(orders is same_list, orders is copy_list)
print(orders == copy_list)
~~~

Expected output:

~~~text
True False
[101, 102, 103]
True False
False
~~~

Lists, dictionaries, and sets can change in place. Integers, strings, tuples, bytes, and frozen sets cannot. Reassigning a name to a new immutable value does not modify another name.

## A default list is shared across calls

Python evaluates default arguments when the function is defined. A list default therefore keeps earlier rows. Use <code>None</code> and create a fresh list inside the function.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=02&snippet=2>)

~~~python
def bad_add(row, batch=[]):
    batch.append(row)
    return batch

print(bad_add("r1"))
print(bad_add("r2"))

def add_row(row, batch=None):
    batch = [] if batch is None else batch
    batch.append(row)
    return batch

print(add_row("r1"), add_row("r2"))
~~~

Expected output:

~~~text
['r1']
['r1', 'r2']
['r1'] ['r2']
~~~

## Copy nested data with care

A shallow copy makes a new outer list but keeps its inner dictionaries and lists. A deep copy recursively copies them. For a single row, building a new dictionary with a new nested list is often clearest.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=02&snippet=3>)

~~~python
from copy import deepcopy

rows = [{"id": 101, "tags": ["new"]}]
shallow = rows.copy()
deep = deepcopy(rows)
shallow[0]["tags"].append("vip")
print(rows[0]["tags"])
print(deep[0]["tags"])
clean = {**rows[0], "tags": [*rows[0]["tags"], "checked"]}
print(clean["tags"])
~~~

Expected output:

~~~text
['new', 'vip']
['new']
['new', 'vip', 'checked']
~~~

Function arguments behave the same way: the function receives another name for the object. Mutating that object affects the caller; rebinding the local name does not.
