## Find and read CSV files

<code>pathlib.Path</code> helps build paths and inspect files. <code>csv.DictReader</code> gives each row a dictionary whose keys come from the header. It handles quoted commas that a simple <code>split(",")</code> cannot. Use <code>newline=""</code> and an explicit encoding when opening CSV.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=09&snippet=1>)

~~~python
from pathlib import Path
import csv

data = Path("python_de_dataset")
print(sorted(path.name for path in data.glob("*.csv"))[:4])
with (data / "orders.csv").open(newline="", encoding="utf-8") as file:
    reader = csv.DictReader(file)
    print(reader.fieldnames)
    first = next(reader)
print(first["order_id"], first["status"], first["amount"])
~~~

Expected output:

~~~text
['employees.csv', 'logins.csv', 'order_items.csv', 'orders.csv']
['order_id', 'customer_id', 'order_date', 'status', 'amount']
101 delivered 1198.00
~~~

CSV values are text. Convert amount and ID fields deliberately, as in the previous lessons. <code>csv.DictWriter</code> writes a header plus rows. <code>extrasaction="ignore"</code> omits fields not in the output header.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=09&snippet=2>)

~~~python
from pathlib import Path
import csv

with open("python_de_dataset/orders.csv", newline="", encoding="utf-8") as source:
    rows = list(csv.DictReader(source))
output = Path("sample_delivered.csv")
with output.open("w", newline="", encoding="utf-8") as target:
    writer = csv.DictWriter(target, fieldnames=["order_id", "amount"],
                            extrasaction="ignore")
    writer.writeheader()
    writer.writerows(row for row in rows if row["status"] == "delivered")
print(output.read_text(encoding="utf-8").splitlines()[:3])
~~~

Expected output:

~~~text
['order_id,amount', '101,1198.00', '102,796.00']
~~~

## JSON versus JSON Lines

JSON is one document; <code>json.load(file)</code> reads the file object. JSON Lines stores one independent JSON value per line; <code>json.loads(line)</code> parses each line as it arrives. This makes JSON Lines suitable for streaming and appending event records.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=09&snippet=3>)

~~~python
import json
from pathlib import Path

data = Path("python_de_dataset")
with (data / "events.jsonl").open(encoding="utf-8") as file:
    for index, line in enumerate(file):
        event = json.loads(line)
        if index < 2:
            print(event["event"], event["props"]["device"])
with (data / "customers.json").open(encoding="utf-8") as file:
    customers = json.load(file)
print(len(customers), customers[1]["address"]["city"])
print(json.dumps({"id": 1, "city": None}))
~~~

Expected output:

~~~text
view mobile
cart mobile
8 Mumbai
{"id": 1, "city": null}
~~~

For a large text file, <code>for line in file</code> uses memory proportional to a line. <code>file.read()</code>, <code>readlines()</code>, and a whole JSON document load all content. A later pandas lesson shows CSV chunking.
