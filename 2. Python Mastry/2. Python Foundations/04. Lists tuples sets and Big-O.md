Lists keep order and allow duplicates; tuples are fixed records; sets keep unique hashable items. Choosing among them changes both the result and the cost.

## Slice and sort a list

A slice creates a new list. <code>sorted()</code> returns a new list, while <code>list.sort()</code> changes the existing list and returns <code>None</code>. Python sorting is stable, so rows with equal keys keep their relative order.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=04&snippet=1>)

~~~python
amounts = [1198, 796, 1499, 1999, 1348]
print(amounts[0], amounts[-1], amounts[1:3])
print(sorted(amounts, reverse=True)[:3])
amounts.sort()
print(amounts)

orders = [("Delhi", 747), ("Pune", 3498),
          ("Delhi", 846), ("Mumbai", 796)]
print(sorted(orders, key=lambda row: (row[0], -row[1])))
~~~

Expected output:

~~~text
1198 1348 [796, 1499]
[1999, 1499, 1348]
[796, 1198, 1348, 1499, 1999]
[('Delhi', 846), ('Delhi', 747), ('Mumbai', 796), ('Pune', 3498)]
~~~

## Reconcile IDs with sets

A source-only ID is missing from the target. A target-only ID is unexpected. Sort set results for predictable report output. An immutable tuple can serve as a composite dictionary key, like two SQL grouping columns.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=2&lesson=04&snippet=2>)

~~~python
source = {101, 102, 103, 104, 105}
target = {101, 102, 104, 106}
print(sorted(source - target))
print(sorted(target - source))
print(sorted(source & target))
totals = {(1, "2025-04"): 5094}
print(totals[(1, "2025-04")])
~~~

Expected output:

~~~text
[103, 105]
[106]
[101, 102, 104]
5094
~~~

## Costs that change the choice

| Operation | List | Set or dictionary |
|---|---:|---:|
| Membership check | O(n) scan | O(1) average |
| Append or add | O(1) amortized | O(1) average |
| Read by index or key | O(1) | O(1) average |
| Insert or remove at front | O(n) | Use a deque for O(1) ends |
| Sort | O(n log n) | Sort its values into a list |
| Memory | Usually lower | Hash table uses more |

For a huge input, streaming may matter more than choosing a container; Part 3 covers that.
