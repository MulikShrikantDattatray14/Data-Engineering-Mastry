# Python Basics — Foundation Notes

**Main idea:** Python stores values in variables and uses their types to decide what operations are valid. This is the quick-revision version of the [original lessons on programs, variables, numbers, strings and input/output](../../1.%20Python%20from%20Zero/README.md), not a separate PDF completion record.

## 1. Your first program

```python
print("Hello, Python")  # Hello, Python
```

`print()` displays a value. Python uses indentation for blocks rather than JavaScript's braces.

| JavaScript | Python |
|---|---|
| `console.log(x)` | `print(x)` |
| `let age = 24` | `age = 24` |
| `null` | `None` |
| `true / false` | `True / False` |

## 2. Variables and types

A variable is a name referring to a value. Python is dynamically typed: you do not declare `let`, `const` or a fixed type.

```python
amount = 2500           # int
status = "SUCCESS"      # str
rate = 0.18             # float
is_paid = True          # bool
amount = "2500"         # now str
print(type(amount))     # <class 'str'>
```

**Why:** CSV fields may look numeric but arrive as strings. Check or convert them before calculations.

## 3. Type conversion

```python
amount_text = "2500"
amount = int(amount_text)
print(amount + 500)       # 3000
print(str(amount) + "INR") # 2500INR
print(float("2.5"))       # 2.5
```

- `int()` converts a compatible value to an integer.
- `float()` converts to a floating-point number.
- `str()` converts to a string.
- Invalid conversions such as `int("hello")` raise `ValueError`.

## 4. Strings

Strings store text. Indexing begins at 0; slices stop **before** the end position.

```python
city = "Pune"
print(city[0])       # P
print(city[-1])      # e
print(city[:2])      # Pu
print(city.lower())  # pune
print(city.strip())  # Pune
```

**JavaScript link:** `city.toLowerCase()` ≈ `city.lower()`; `city.trim()` ≈ `city.strip()`.

## 5. Input and output

```python
name = input("Name: ") # input() returns a str
print("Hello", name)
```

Convert input before numeric operations, e.g. `age = int(input("Age: "))`. Input can fail when text is not numeric; error handling comes later.

## Quick revision

- `=` assigns; `==` compares.
- `type()` reports a value's type.
- `[index]` reads a single element; `[start:stop]` slices.
- Python uses `None`, not JavaScript `null`.
