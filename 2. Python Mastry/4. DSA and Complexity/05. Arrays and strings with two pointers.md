# 05. Arrays and strings with two pointers

**Source:** [Python for Data Engineering Notes, page 45](<../Source/1793477658005.pdf#page=45>).

Two pointers mean two positions moving through one collection. Sorted data often lets you discard impossible answers without checking every pair.

## Find a pair in a sorted price list

Start at the smallest and largest prices. If their sum is too small, move the left pointer toward a larger value. If too large, move the right pointer toward a smaller value.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=05&snippet=1>)

~~~python
def pair_with_sum(prices, target):
    left, right = 0, len(prices) - 1
    while left < right:
        total = prices[left] + prices[right]
        if total == target:
            return prices[left], prices[right]
        if total < target:
            left += 1
        else:
            right -= 1
    return None

prices = sorted([1198, 796, 1499, 1999, 1348, 1048, 747, 3498])
print(prices)
print(pair_with_sum(prices, 2847))
print(pair_with_sum(prices, 5))
~~~

Expected output:

~~~text
[747, 796, 1048, 1198, 1348, 1499, 1999, 3498]
(1348, 1499)
None
~~~

The scan is O(n) time and O(1) extra space **after sorting**. Sorting unsorted input first costs O(n log n). On unsorted input, a hash map can find the pair in average O(n) time with O(n) memory.

## Read and write positions remove duplicates in place

When IDs are sorted, duplicates sit together. Read every ID and write each new one at the front of the same list.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=05&snippet=2>)

~~~python
def dedupe_sorted(ids):
    if not ids:
        return 0
    write = 1
    for read in range(1, len(ids)):
        if ids[read] != ids[write - 1]:
            ids[write] = ids[read]
            write += 1
    del ids[write:]
    return write

ids = [101, 101, 102, 103, 103, 103, 105]
print(dedupe_sorted(ids), ids)
~~~

Expected output:

~~~text
4 [101, 102, 103, 105]
~~~

The returned 4 is the unique count. The list itself is modified. Time is O(n); extra space is O(1).

## Check a phrase from both ends

Skip spaces and punctuation, then compare the remaining characters without creating a cleaned copy.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=05&snippet=3>)

~~~python
def is_palindrome(text):
    left, right = 0, len(text) - 1
    while left < right:
        if not text[left].isalnum():
            left += 1
        elif not text[right].isalnum():
            right -= 1
        elif text[left].lower() != text[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True

print(is_palindrome("Was it a car or a cat I saw?"))
print(is_palindrome("orders"))
~~~

Expected output:

~~~text
True
False
~~~

## A running prefix and a log line

Prefix totals record a result at each position. For a log line, split only three times so its final field stays together. partition("=") safely returns three pieces even if the separator is absent.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=05&snippet=4>)

~~~python
from itertools import accumulate

changes = [5, -2, -8, 3, 4, -1, 6, -9]
running = list(accumulate(changes))
print(running)
print("lowest after day", running.index(min(running)) + 1)

line = "2025-04-01 02:00:05 WARN job=orders_daily"
day, time, level, detail = line.split(maxsplit=3)
print(day, level, detail.partition("=")[2])
~~~

Expected output:

~~~text
[5, 3, -5, -2, 2, 1, 7, -2]
lowest after day 3
2025-04-01 WARN orders_daily
~~~
