# 07. Sliding windows

**Source:** [Python for Data Engineering Notes, page 47](<../Source/1793477658005.pdf#page=47>).

A sliding window is a current stretch of data. A variable-size window expands at the right edge and moves its left edge when its rule breaks. Each item enters and leaves at most once.

## Longest text segment without repeats

Keep the most recent position of each character. If it reappears inside the current segment, move the start past that earlier position.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=07&snippet=1>)

~~~python
def longest_unique(text):
    last_position = {}
    start = best = 0
    for end, character in enumerate(text):
        if character in last_position and last_position[character] >= start:
            start = last_position[character] + 1
        last_position[character] = end
        best = max(best, end - start + 1)
    return best

print([longest_unique(text) for text in ("abcabcbb", "pwwkew", "")])
~~~

Expected output:

~~~text
[3, 3, 0]
~~~

The dictionary remembers at most k distinct characters: O(k) extra space. The pass is O(n).

## Shortest positive run reaching a total

Add at the right until the target is met. Then remove values at the left while the target still holds, recording the shortest run.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=07&snippet=2>)

~~~python
def shortest_with_sum(values, target):
    left = total = 0
    best = float("inf")
    for right, value in enumerate(values):
        total += value
        while total >= target:
            best = min(best, right - left + 1)
            total -= values[left]
            left += 1
    return 0 if best == float("inf") else best

print(shortest_with_sum([2, 3, 1, 2, 4, 3], 7))
~~~

Expected output:

~~~text
2
~~~

This version assumes **positive values**. If negative values are allowed, adding or removing one value no longer changes the total predictably; a different method is needed.

## Busiest rolling 30-minute event window

Timestamps are already sorted. A deque holds events that still belong to the current half-open 30-minute window.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=07&snippet=3>)

~~~python
from collections import deque
from datetime import datetime, timedelta

labels = ["10:00", "10:02", "10:05", "10:20", "10:22",
          "10:40", "11:00", "11:10", "11:15", "12:00"]
times = [datetime.strptime(label, "%H:%M") for label in labels]
window = deque()
peak_count, peak_end = 0, None

for current in times:
    window.append(current)
    while window[0] <= current - timedelta(minutes=30):
        window.popleft()
    if len(window) > peak_count:
        peak_count, peak_end = len(window), current.strftime("%H:%M")

print(peak_count, peak_end)
~~~

Expected output:

~~~text
5 10:22
~~~

A fixed-size window always contains k items; a variable-size window is controlled by a rule such as “within 30 minutes” or “sum below target.” The deque is appropriate when old events leave from the front.
