## Q16. Missing order ID — Easy

Order IDs should be 1 through n, with exactly one missing. Find that ID in [1, 2, 4, 5, 6]. What if the list is [2, 3, 1, 5]?

<details>
<summary>Show approach and solution</summary>

The expected sum is n(n+1)/2. Subtract the sum of the observed IDs.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=17&snippet=1>)

~~~python
def missing(ids):
    n = len(ids) + 1
    return n * (n + 1) // 2 - sum(ids)

print(missing([1, 2, 4, 5, 6]), missing([2, 3, 1, 5]))
~~~

Expected output:

~~~text
3 4
~~~

Time O(n), extra space O(1). The guarantee of exactly one missing ID is essential.

</details>

## Q17. K-th largest order amount — Medium

Find the third-largest amount in the supplied orders.csv **without sorting the entire list**. Count tied amounts as separate rows.

<details>
<summary>Show approach and solution</summary>

Keep the k largest amounts in a min-heap of size k. Its smallest value is the k-th largest overall.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=17&snippet=2>)

~~~python
import csv
import heapq
from pathlib import Path

with Path("python_de_dataset/orders.csv").open(newline="", encoding="utf-8") as file:
    amounts = [float(row["amount"]) for row in csv.DictReader(file)]

def kth_largest(values, k):
    if not 1 <= k <= len(values):
        raise ValueError("k must be between 1 and the number of values")
    heap = values[:k]
    heapq.heapify(heap)
    for value in values[k:]:
        if value > heap[0]:
            heapq.heapreplace(heap, value)
    return heap[0]

print(kth_largest(amounts, 3), sorted(amounts, reverse=True)[2])
~~~

Expected output:

~~~text
1999.0 1999.0
~~~

Time O(n log k), extra heap space O(k). The sorted comparison in the final print only checks the result; remove it when processing a large stream.

</details>

## Q18. Longest common S3 path prefix — Easy

Find the common text prefix of these three paths:

- s3://raw/orders/2025/04/01/part-0.csv
- s3://raw/orders/2025/04/02/part-0.csv
- s3://raw/orders/2025/03/31/part-1.csv

<details>
<summary>Show approach and solution</summary>

The smallest and largest strings in lexicographic order delimit all the others. Compare their characters until they differ.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=17&snippet=3>)

~~~python
def common_prefix(paths):
    if not paths:
        return ""
    first, last = min(paths), max(paths)
    position = 0
    while position < len(first) and first[position] == last[position]:
        position += 1
    return first[:position]

paths = [
    "s3://raw/orders/2025/04/01/part-0.csv",
    "s3://raw/orders/2025/04/02/part-0.csv",
    "s3://raw/orders/2025/03/31/part-1.csv",
]
print(common_prefix(paths))
~~~

Expected output:

~~~text
s3://raw/orders/2025/0
~~~

Time O(total characters inspected), extra space O(1) apart from the returned prefix. A text prefix can end inside a path component; if you need a **directory** prefix, split on slashes instead.

</details>

## Q19. Product of every other growth factor — Medium

For [2, 3, 4, 5], return at each position the product of all other values, without division.

<details>
<summary>Show approach and solution</summary>

First fill the output with products to the left. Then walk right to left and multiply by products to the right.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=17&snippet=4>)

~~~python
def product_except_self(values):
    answer = [1] * len(values)
    left_product = 1
    for position, value in enumerate(values):
        answer[position] = left_product
        left_product *= value
    right_product = 1
    for position in range(len(values) - 1, -1, -1):
        answer[position] *= right_product
        right_product *= values[position]
    return answer

print(product_except_self([2, 3, 4, 5]))
~~~

Expected output:

~~~text
[60, 40, 30, 24]
~~~

Time O(n), O(1) auxiliary space besides the O(n) output. This works even if values include zero.

</details>

## Q20. Files with identical content — Medium

Find files that contain the same bytes, even when their names differ. Use the supplied orders.csv as the sample content.

<details>
<summary>Show approach and solution</summary>

Hash each file's bytes with SHA-256 and group names by digest. The example uses a temporary folder so it does not add a backup.csv to your notes directory.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=17&snippet=5>)

~~~python
import hashlib
import shutil
import tempfile
from collections import defaultdict
from pathlib import Path

source = Path("python_de_dataset/orders.csv")
with tempfile.TemporaryDirectory() as temporary:
    folder = Path(temporary)
    shutil.copyfile(source, folder / "orders.csv")
    shutil.copyfile(source, folder / "backup.csv")

    groups = defaultdict(list)
    for path in sorted(folder.glob("*.csv")):
        digest = hashlib.sha256(path.read_bytes()).hexdigest()
        groups[digest].append(path.name)
    print([names for names in groups.values() if len(names) > 1])
~~~

Expected output:

~~~text
[['backup.csv', 'orders.csv']]
~~~

Hashing takes O(total bytes). The name groups use O(number of files) space; read_bytes() also temporarily holds one whole file in memory. For very large files, hash chunks and compare bytes before declaring two files identical, because a hash match alone is not a mathematical proof of equality.

</details>
