# 13. Trees with DFS and BFS

**Source:** [Python for Data Engineering Notes, page 53](<../Source/1793477658005.pdf#page=53>).

A tree is a hierarchy with one root and one parent for every other node. The store's employee reporting structure is a tree. Depth-first search (DFS) follows a branch down; breadth-first search (BFS) visits a whole level before going deeper.

## Build the org chart from the supplied CSV

The file has emp_id and manager_id columns. Group each employee under their manager. An empty manager_id identifies the root.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=13&snippet=1>)

~~~python
import csv
from collections import defaultdict, deque
from pathlib import Path

path = Path("python_de_dataset/employees.csv")
with path.open(newline="", encoding="utf-8") as file:
    employees = list(csv.DictReader(file))

names = {row["emp_id"]: row["name"] for row in employees}
children = defaultdict(list)
root = None
for row in employees:
    if row["manager_id"]:
        children[row["manager_id"]].append(row["emp_id"])
    else:
        root = row["emp_id"]

def dfs(employee_id, depth=0):
    print("  " * depth + names[employee_id])
    for child_id in children[employee_id]:
        dfs(child_id, depth + 1)

def bfs(start):
    levels = []
    queue = deque([(start, 0)])
    while queue:
        employee_id, depth = queue.popleft()
        if depth == len(levels):
            levels.append([])
        levels[depth].append(names[employee_id])
        queue.extend((child_id, depth + 1) for child_id in children[employee_id])
    return levels

dfs(root)
print(bfs(root))
~~~

Expected output:

~~~text
Anita
  Rahul
    Priya
    Karan
  Neha
    Arjun
    Ishita
  Dev
    Tara
[['Anita'], ['Rahul', 'Neha', 'Dev'], ['Priya', 'Karan', 'Arjun', 'Ishita', 'Tara']]
~~~

Both walks visit each employee once: O(n) time. DFS uses call-stack space proportional to tree height; BFS keeps a queue proportional to a level's width.

## A binary search tree, and why its shape matters

For every node, smaller values go left and larger values go right. Reading left, then root, then right gives sorted values. Inserting already sorted values creates a long chain.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=13&snippet=2>)

~~~python
from dataclasses import dataclass

@dataclass
class Node:
    value: int
    left: "Node | None" = None
    right: "Node | None" = None

def insert(node, value):
    if node is None:
        return Node(value)
    if value < node.value:
        node.left = insert(node.left, value)
    else:
        node.right = insert(node.right, value)
    return node

def inorder(node):
    if node is None:
        return []
    return inorder(node.left) + [node.value] + inorder(node.right)

def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

balanced = chain = None
for value in (50, 30, 70, 20, 40, 60, 80):
    balanced = insert(balanced, value)
for value in (10, 20, 30, 40, 50, 60, 70):
    chain = insert(chain, value)
print(inorder(balanced), height(balanced), height(chain))
~~~

Expected output:

~~~text
[20, 30, 40, 50, 60, 70, 80] 3 7
~~~

Searching a balanced tree is O(log n); in the chain it degrades to O(n). Database indexes use balanced tree structures to avoid that degeneration.

| Traversal | Order | Useful for |
|---|---|---|
| DFS pre-order | Parent before children | Print an org chart |
| DFS post-order | Children before parent | Calculate team totals |
| BST in-order | Left, parent, right | Read sorted values |
| BFS level-order | Entire level before next | Find depth or nearest match |

[W3Schools Trees](https://www.w3schools.com/python/python_dsa_trees.asp) and [Binary Trees](https://www.w3schools.com/python/python_dsa_binarytrees.asp) explain the hierarchy and traversal vocabulary. A tiny category tree can be walked recursively:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=13&snippet=3>)

~~~python
categories = {"Store": {"Clothes": {}, "Electronics": {"Phones": {}}}}

def names(tree):
    for name, children in tree.items():
        print(name)
        names(children)

names(categories)
~~~

Expected output:

~~~text
Store
Clothes
Electronics
Phones
~~~
