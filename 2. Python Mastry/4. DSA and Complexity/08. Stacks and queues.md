# 08. Stacks and queues

**Source:** [Python for Data Engineering Notes, page 48](<../Source/1793477658005.pdf#page=48>).

A stack handles the newest item first: last in, first out. A queue handles the oldest item first: first in, first out. Use a Python list for a stack and collections.deque for a queue.

## Balanced brackets need a stack

The latest opening bracket must be the first one closed.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=08&snippet=1>)

~~~python
def balanced(text):
    matching = {")": "(", "]": "[", "}": "{"}
    stack = []
    for character in text:
        if character in "([{":
            stack.append(character)
        elif character in matching:
            if not stack or stack.pop() != matching[character]:
                return False
    return not stack

print(balanced('{"a": [1, 2, {"b": (3)}]}'))
print(balanced('{"a": [1, 2}'))
print(balanced("(("))
~~~

Expected output:

~~~text
True
False
False
~~~

Time O(n); worst-case stack space O(n).

## A monotonic stack remembers unresolved days

The stack holds indices of days still waiting for a higher value. A higher day resolves the lower days at the top.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=08&snippet=2>)

~~~python
def days_until_higher(revenue):
    waiting = []
    answer = [0] * len(revenue)
    for today, value in enumerate(revenue):
        while waiting and revenue[waiting[-1]] < value:
            earlier = waiting.pop()
            answer[earlier] = today - earlier
        waiting.append(today)
    return answer

print(days_until_higher([1994, 2847, 7291, 6840, 7500, 3000, 3100]))
~~~

Expected output:

~~~text
[1, 1, 2, 1, 0, 1, 0]
~~~

Each index is pushed and popped at most once: O(n) time.

## A queue walks folders level by level

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=08&snippet=3>)

~~~python
from collections import deque

lake = {
    "raw": {"orders": ["01.csv", "02.csv"], "events": ["a.jsonl"]},
    "README.md": None,
}
queue = deque([("", lake)])
files = []
while queue:
    path, folder = queue.popleft()
    for name, child in folder.items():
        full = f"{path}/{name}"
        if isinstance(child, dict):
            queue.append((full, child))
        elif child is None:
            files.append(full)
        else:
            files.extend(f"{full}/{filename}" for filename in child)
print(files)
~~~

Expected output:

~~~text
['/README.md', '/raw/orders/01.csv', '/raw/orders/02.csv', '/raw/events/a.jsonl']
~~~

The queue handles the shallow folder before its subfolders. This is breadth-first search (BFS). A stack would go deep first (DFS).
