A dictionary or set helps answer “have I seen this key?” without scanning earlier rows. Average lookup is O(1), but storing keys uses memory. The real skill is choosing a useful key and value.

## Unsorted two-sum: value to position

For each price, look for its missing partner among prices already seen. Only then store the current price.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=06&snippet=1>)

~~~python
def two_sum(amounts, target):
    seen = {}
    for position, amount in enumerate(amounts):
        needed = target - amount
        if needed in seen:
            return seen[needed], position
        seen[amount] = position
    return None

print(two_sum([1198, 796, 1499, 1999, 1348], 2847))
~~~

Expected output:

~~~text
(2, 4)
~~~

The result is a pair of positions, not amounts. Time and extra space are O(n).

## Equivalent words: normalized letters to a group

Sorting each word gives anagrams the same key.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=06&snippet=2>)

~~~python
from collections import defaultdict

def group_anagrams(words):
    groups = defaultdict(list)
    for word in words:
        key = "".join(sorted(word))
        groups[key].append(word)
    return list(groups.values())

print(group_anagrams(["listen", "silent", "enlist", "data", "tada", "etl"]))
~~~

Expected output:

~~~text
[['listen', 'silent', 'enlist'], ['data', 'tada'], ['etl']]
~~~

For n words of length k, sorting keys costs O(n × k log k). The dictionary stores the groups.

## Earlier prefix totals: count matching ranges

A range sums to k when the current running total minus an earlier total equals k. Count how many earlier totals have the needed value.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=06&snippet=3>)

~~~python
from collections import Counter

def subarrays_with_sum(values, target):
    earlier = Counter({0: 1})
    running = answer = 0
    for value in values:
        running += value
        answer += earlier[running - target]
        earlier[running] += 1
    return answer

print(subarrays_with_sum([1, 2, 3, -1, 1, 2], 3))
~~~

Expected output:

~~~text
4
~~~

The initial {0: 1} counts a range that begins at position zero. This works with negative numbers too. Time O(n), extra space O(n).

## Item to count: find the first unique item

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=06&snippet=4>)

~~~python
from collections import Counter

def first_unique(events):
    counts = Counter(events)
    return next((event for event in events if counts[event] == 1), None)

print(first_unique(["u2", "u1", "u2", "u3", "u1"]))
~~~

Expected output:

~~~text
u3
~~~

| Store in the map | Question it answers |
|---|---|
| Value to index | Where was the matching partner? |
| Normalized key to rows | Which records belong together? |
| Item to count | How often did it occur? |
| Prefix total to count | How many ranges make this total? |
| ID to latest record | What is the current state of each ID? |

[W3Schools Hash Tables](https://www.w3schools.com/python/python_dsa_hashtables.asp) covers keys, hashes and collisions. A dictionary can also keep the latest status for each order:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=4&lesson=06&snippet=5>)

~~~python
updates = [(101, "placed"), (102, "placed"), (101, "delivered")]
latest = {}
for order_id, status in updates:

print(latest)
~~~

~~~text
{101: 'delivered', 102: 'placed'}
~~~
