## Q12. Chunk any iterable

Write <code>chunked(iterable, n)</code> that yields lists of at most <code>n</code> items and works with a generator. Expected chunks for IDs 101 to 107, size 3: <code>[[101, 102, 103], [104, 105, 106], [107]]</code>.

<details>
<summary>Show approach and runnable answer</summary>

Keep one iterator and pull up to <code>n</code> items on each pass. Reject a nonpositive chunk size so the loop cannot run forever.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=06&snippet=1>)

~~~python
from itertools import islice

def chunked(iterable, n):
    if n <= 0:
        raise ValueError("n must be positive")
    source = iter(iterable)
    while batch := list(islice(source, n)):
        yield batch

print(list(chunked(range(101, 108), 3)))
print(list(chunked((ch for ch in "abcde"), 2)))
~~~

Expected output:

~~~text
[[101, 102, 103], [104, 105, 106], [107]]
[['a', 'b'], ['c', 'd'], ['e']]
~~~

</details>

## Q13. Run-length encode a status stream

Turn <code>["D", "D", "C", "D", "D", "D"]</code> into <code>D2C1D3</code>. Here, adjacent runs are exactly what <code>groupby()</code> provides, so do not sort first.

<details>
<summary>Show approach and runnable answer</summary>

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=06&snippet=2>)

~~~python
from itertools import groupby

stream = ["D", "D", "C", "D", "D", "D"]
encoded = "".join(
    f"{status}{sum(1 for _ in group)}"
    for status, group in groupby(stream)
)
print(encoded)
~~~

Expected output:

~~~text
D2C1D3
~~~

</details>

## Q14. Count decorated function calls

Write <code>@count_calls</code> so each decorated function records its own number of calls and keeps its original name.

<details>
<summary>Show approach and runnable answer</summary>

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=06&snippet=3>)

~~~python
from functools import wraps

def count_calls(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        wrapper.calls += 1
        return fn(*args, **kwargs)
    wrapper.calls = 0
    return wrapper

@count_calls
def load(batch):
    return len(batch)

for batch in ([1, 2], [3], [4, 5, 6]):
    load(batch)
print(load.__name__, load.calls)
~~~

Expected output:

~~~text
load 3
~~~

</details>

## Q15. Top two salaries per department

Sort <code>employees.csv</code> by department A to Z, salary high to low, then name A to Z. Print the first two people in each department.

<details>
<summary>Show approach and runnable answer</summary>

Sorting puts each department's rows together. <code>groupby()</code> then makes one group per department and <code>islice()</code> takes its first two rows.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=06&snippet=4>)

~~~python
import csv
from itertools import groupby, islice

with open("python_de_dataset/employees.csv", newline="", encoding="utf-8") as file:
    rows = list(csv.DictReader(file))
rows.sort(key=lambda row: (row["dept"], -int(row["salary"]), row["name"]))
for dept, group in groupby(rows, key=lambda row: row["dept"]):
    top = [(row["name"], row["salary"]) for row in islice(group, 2)]
    print(dept, top)
~~~

Expected output:

~~~text
Analytics [('Ishita', '160000'), ('Neha', '150000')]
Engineering [('Anita', '250000'), ('Rahul', '180000')]
Sales [('Dev', '90000'), ('Tara', '90000')]
~~~

</details>
