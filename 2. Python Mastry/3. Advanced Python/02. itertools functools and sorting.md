## groupby groups adjacent runs

<code>itertools.groupby()</code> starts a new group whenever the key changes. It does not collect all equal keys across the input the way SQL <code>GROUP BY</code> does. Sort by the same key first when you want one group per value.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=02&snippet=1>)

~~~python
from itertools import groupby

statuses = ["delivered", "cancelled", "delivered", "delivered"]
print([(key, len(list(group))) for key, group in groupby(statuses)])
print([(key, len(list(group))) for key, group in groupby(sorted(statuses))])
~~~

Expected output:

~~~text
[('delivered', 1), ('cancelled', 1), ('delivered', 2)]
[('cancelled', 1), ('delivered', 3)]
~~~

The group iterator must be consumed before advancing to the next group.

## Five iterator tools

<code>batched()</code> needs Python 3.12 or newer. <code>islice()</code> takes part of any iterable. <code>chain()</code> joins streams without copying them. <code>accumulate()</code> gives running totals. <code>pairwise()</code> gives neighboring pairs.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=02&snippet=2>)

~~~python
from itertools import accumulate, batched, chain, islice, pairwise

print(list(batched(range(101, 108), 3)))
print(list(islice(range(101, 108), 2, 5)))
print(list(chain([1, 2], (3,), "ab")))
print(list(accumulate([1198, 796, 1499])))
print(list(pairwise(["01-10", "02-02", "03-05"])))
~~~

Expected output:

~~~text
[(101, 102, 103), (104, 105, 106), (107,)]
[103, 104, 105]
[1, 2, 3, 'a', 'b']
[1198, 1994, 3493]
[('01-10', '02-02'), ('02-02', '03-05')]
~~~

## Stable sorting and functools

For mixed sort directions, sort by the less important key first; the second stable sort keeps that order within equal primary keys. Negating a key works for numeric descending order, not text. <code>partial()</code> fixes some arguments of a function; <code>reduce()</code> folds items into one result.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=02&snippet=3>)

~~~python
from functools import partial, reduce
from operator import itemgetter

rows = [("Delhi", 747), ("Pune", 3498),
        ("Delhi", 846), ("Pune", 1598)]
rows.sort(key=itemgetter(1))
rows.sort(key=itemgetter(0), reverse=True)
print(rows)
parse_binary = partial(int, base=2)
print(parse_binary("1010"), reduce(lambda a, b: a * b, [1, 2, 3]))
~~~

Expected output:

~~~text
[('Pune', 1598), ('Pune', 3498), ('Delhi', 747), ('Delhi', 846)]
10 6
~~~

## Other standard-library shortcuts and what they replace

| Tool | Use it for | If you had to build the idea yourself |
|---|---|---|
| <code>collections.Counter</code> | Count occurrences | Update a dictionary with <code>counts.get(item, 0) + 1</code> |
| <code>heapq.nlargest(k, values)</code> | Keep the top K without sorting everything | Maintain a size-K min-heap |
| <code>collections.deque(maxlen=k)</code> | Keep the most recent K items | Evict the oldest item as each new one arrives |
| <code>functools.lru_cache</code> | Reuse results of repeated calls | Combine a dictionary with an <code>OrderedDict</code>-style recency order for bounded LRU |
| <code>bisect.insort</code> | Insert while keeping a list sorted | Binary-search for the position, then insert there |

<code>bisect.insort</code> finds the position in O(log n), but inserting into a Python list shifts later values, so the whole operation is O(n). A bounded deque drops the oldest item automatically when full. An LRU cache must also update which key was used most recently.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=02&snippet=4>)

~~~python
from bisect import insort
from collections import OrderedDict, deque

recent = deque(maxlen=3)
for order_id in (101, 102, 103, 104):
    recent.append(order_id)
print(list(recent))

scores = [10, 30]
insort(scores, 20)
print(scores)

cache = OrderedDict([(101, "placed"), (102, "paid")])
cache.move_to_end(101)  # 101 was just used
cache[103] = "shipped"
cache.popitem(last=False)  # evict least recently used key, 102
print(list(cache.items()))
~~~

Expected output:

~~~text
[102, 103, 104]
[10, 20, 30]
[(101, 'placed'), (103, 'shipped')]
~~~

## More from W3Schools: lambda

The [Python Lambda lesson](https://www.w3schools.com/python/python_lambda.asp) introduces short functions as values. This original example sorts by an amount field:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=02&snippet=5>)

~~~python
orders = [{"id": 1, "amount": 80}, {"id": 2, "amount": 120}]
print([row["id"] for row in sorted(orders, key=lambda row: -row["amount"])])
~~~

Expected output:

~~~text
[2, 1]
~~~
