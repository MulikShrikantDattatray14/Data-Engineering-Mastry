## Practice

Open [Start Practice.cmd](<../Start Practice.cmd>) or run the local [practice runner](<../practice_runner.py>) from the Python Mastry folder. The runner copies the [store dataset](<../python_de_dataset/README.md>) into a temporary practice folder. Use each **Run and edit this example** link; your edits stay separate from the lesson's original code.

All examples use the standard library. The process-pool snippet runs from a script under the local runner and keeps the Windows main guard. Performance times depend on the computer. Answers in Practice Set 2 are folded until you choose to view them.
