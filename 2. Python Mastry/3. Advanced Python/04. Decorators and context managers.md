A decorator wraps a function to add behavior around a call. Timing, retrying, logging, and caching are common uses. A context manager wraps a block so cleanup happens reliably.

## Time a function while keeping its name

<code>@timed</code> means <code>load_batch = timed(load_batch)</code>. The wrapper accepts any arguments and returns the original result. <code>functools.wraps</code> preserves the original name and docstring.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=04&snippet=1>)

~~~python
from functools import wraps
from time import perf_counter

def timed(fn):
    @wraps(fn)
    def wrapper(*args, **kwargs):
        start = perf_counter()
        result = fn(*args, **kwargs)
        elapsed = perf_counter() - start
        print(fn.__name__, "measured:", elapsed >= 0)
        return result
    return wrapper

@timed
def load_batch(rows):
    """Count rows before loading."""
    return len(rows)

print(load_batch([101, 102, 103]))
print(load_batch.__name__, load_batch.__doc__)
~~~

Expected output:

~~~text
load_batch measured: True
3
load_batch Count rows before loading.
~~~

Actual durations vary by computer, so the example checks only that a measurement was made.

## A retry decorator takes arguments

A decorator with options has three layers: <code>retry(...)</code> returns a decorator, which accepts a function and returns a wrapper. Retry only transient failures such as timeouts or dropped connections. Do not retry invalid data.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=04&snippet=2>)

~~~python
from functools import wraps
from time import sleep

def retry(times=3, delay=0.001, on=(ConnectionError,)):
    def decorate(fn):
        @wraps(fn)
        def wrapper(*args, **kwargs):
            for attempt in range(1, times + 1):
                try:
                    return fn(*args, **kwargs)
                except on:
                    print("attempt", attempt, "failed")
                    if attempt == times:
                        raise
                    sleep(delay * 2 ** (attempt - 1))
        return wrapper
    return decorate

calls = 0
@retry(times=3)
def fetch_page():
    global calls
    calls += 1
    if calls < 3:
        raise ConnectionError("temporary outage")
    return "page ok"

print(fetch_page())
~~~

Expected output:

~~~text
attempt 1 failed
attempt 2 failed
page ok
~~~

## A context manager wraps a block

With <code>@contextmanager</code>, code before <code>yield</code> sets up; the block runs at <code>yield</code>; the <code>finally</code> section cleans up even if the block raises.

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=04&snippet=3>)

~~~python
from contextlib import contextmanager

@contextmanager
def step(name):
    print("start", name)
    try:
        yield
        print("done", name)
    except Exception as error:
        print("failed", name, type(error).__name__)
        raise
    finally:
        print("cleanup", name)

with step("extract"):
    print("read 3 rows")
try:
    with step("load"):
        raise TimeoutError("offline")
except TimeoutError:
    print("handled load error")
~~~

Expected output:

~~~text
start extract
read 3 rows
done extract
cleanup extract
start load
failed load TimeoutError
cleanup load
handled load error
~~~

## More from W3Schools: decorators

The [Python Decorators lesson](https://www.w3schools.com/python/python_decorators.asp) introduces wrapping a function. This original example normalizes a returned status:

[▶ Run and edit this example](<http://127.0.0.1:8765/?part=3&lesson=04&snippet=4>)

~~~python
from functools import wraps

def cleaned(fn):
    @wraps(fn)
    def wrapper():
        return fn().strip().lower()
    return wrapper

@cleaned
def source_status():
    return "  Delivered "

print(source_status())
~~~

Expected output:

~~~text
delivered
~~~
