# Python Mastry

Learn Python in the order used by the [original 80-page PDF](<Source/1793477658005.pdf>). The book has 7 parts and 76 listed lessons, practice sets, and revision topics. The [Start Here notes](<00. Start Here.md>) cover its opening dataset and interview guidance (PDF pp. 3-4).

**Progress:** Part 1 has detailed notes. Parts 2-7 are indexed below and will receive detailed notes only after you approve each next part.

**Learning path:** Read the Start Here notes, then follow Parts 1 through 7 in order. Examples keep returning to the same online-store story. Each Part 1 lesson includes simple explanations, code, expected output, and exercises.

## Work with the companion dataset

The [original dataset ZIP](<Source/Python_Dataset_DE.zip>) is saved with the PDF. Its [extracted files and run guide](<python_de_dataset/README.md>) are ready to use. The 15 orders and worked monthly totals match the PDF.

Open a terminal in this `2. Python Mastry` folder for the note examples. Data paths start with `python_de_dataset/`, such as `python_de_dataset/orders.csv`. To run a PDF snippet exactly as printed with `open("orders.csv")`, first set your terminal's working folder to `python_de_dataset`.
