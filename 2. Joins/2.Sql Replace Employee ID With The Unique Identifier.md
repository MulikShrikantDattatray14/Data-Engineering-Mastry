# 2. SQL Replace Employee ID With The Unique Identifier

## Question and image

Show the unique ID and name of **each employee**. If an employee has no unique ID in EmployeeUNI, display NULL for the unique ID.

Return the result in any order.

**Example 1**

Input — Employees:

| id | name |
|---:|---|
| 1 | Alice |
| 7 | Bob |
| 11 | Meir |
| 90 | Winston |
| 3 | Jonathan |

Input — EmployeeUNI:

| id | unique_id |
|---:|---:|
| 3 | 1 |
| 11 | 2 |
| 90 | 3 |

Expected output:

| unique_id | name |
|---:|---|
| NULL | Alice |
| NULL | Bob |
| 2 | Meir |
| 3 | Winston |
| 1 | Jonathan |

Alice and Bob have no unique ID. Meir, Winston, and Jonathan have the IDs shown in EmployeeUNI.

## Schema

Employees:

| Column Name | Type |
|---|---|
| id | int |
| name | varchar |

id is the primary key. Each row holds an employee ID and name.

EmployeeUNI:

| Column Name | Type |
|---|---|

| unique_id | int |

(id, unique_id) is the stated composite primary key. Each row associates an employee ID with a unique ID.
