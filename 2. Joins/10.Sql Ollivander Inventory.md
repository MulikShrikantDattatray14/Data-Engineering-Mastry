# 10. SQL Ollivander Inventory

## Question and image

Harry Potter and his friends visit Ollivander's to replace Charlie's broken wand. Hermione wants to identify the minimum number of gold galleons needed to buy each non-evil wand of high power and age.

Source: [HackerRank — Ollivander's Inventory](https://www.hackerrank.com/challenges/harry-potter-and-wands/problem).

Print the wand's `id`, `age`, `coins_needed`, and `power`, ordered by `power` descending and then `age` descending when powers tie.

## Schema

`Wands`:

| Column Name | Type |
|---|---|
| id | Integer |
| code | Integer |
| coins_needed | Integer |
| power | Integer |

`id` identifies the wand, `code` links to its properties, `coins_needed` is its cost in gold galleons, and higher `power` means a better-quality wand.

`Wands_Property`:

| Column Name | Type |
|---|---|
| code | Integer |
| age | Integer |
| is_evil | Integer |

`code` identifies the wand properties. `is_evil = 0` means non-evil. The supplied code–age mapping is one-to-one: distinct codes map to distinct ages.
