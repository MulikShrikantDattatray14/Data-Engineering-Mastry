## My solution — SQLite

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

`GROUP BY class` creates one group per class. `COUNT(student)` counts the students in each group, and `HAVING` keeps only classes with at least five students.

`WHERE` filters individual rows before grouping, whereas `HAVING` filters groups after aggregation. Using `GROUP BY` does not automatically require `HAVING`; `HAVING` is needed here because the condition uses the aggregate result `COUNT(student)`.

### Step-by-step explanation with one example

We need one row for each class with at least five students. Use the supplied Courses example for every step. Each input row is one student enrolled in one class.

**Starting data**

`Courses`:

| student | class |
| --- | --- |
| A | Math |
| B | English |
| C | Math |
| D | Biology |
| E | Math |
| F | Computer |
| G | Math |
| H | Math |
| I | Math |

**1. Count students in each class**

The threshold applies to a whole class. Group by class and count student values; do not group by student because that would split the class into individual enrollments.

```sql
SELECT class, COUNT(student) AS student_count
FROM Courses
GROUP BY class
ORDER BY class;
```

Result:

| class | student_count |
| --- | --- |
| Biology | 1 |
| Computer | 1 |
| English | 1 |
| Math | 6 |

Math has six students, while Biology, Computer, and English each have one.

**2. Keep only groups meeting the threshold**

HAVING evaluates the class counts after grouping. At least five means >= 5, so a class with exactly five would also qualify.

```sql
SELECT class, COUNT(student) AS student_count
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

Result:

| class | student_count |
| --- | --- |
| Math | 6 |

Only Math survives. WHERE cannot directly filter COUNT(student) because that count is produced after the row-filtering stage.

**3. Assemble the final query**

Remove the diagnostic count from the output while retaining the same grouping and HAVING condition.

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

Final result for this example:

| class |
| --- |
| Math |

**Check the result:** Manual check: students A, C, E, G, H, and I are enrolled in Math: 6 >= 5. The other three classes each have 1 < 5. No output order is required.

## My solution — SQL Server

```sql
SELECT class

```

The same query works in SQLite and SQL Server.

> **Shared SQL processing note:** `FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → row limiting`. SQLite uses `LIMIT/OFFSET`; SQL Server uses `TOP` or `OFFSET/FETCH`. `WHERE` filters rows before grouping, while `HAVING` filters groups after aggregation. ## Official solution

Lecture solution supplied in the GROUP BY/HAVING material:

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

### What this tests

Filtering groups by their row count.

### The approach

Make one group per `class`, count enrolled students, and keep groups with at least five.

### Why this way

`HAVING` checks the number of students in a whole class after `GROUP BY` forms that class's group.

### Common mistakes

`WHERE COUNT(student) >= 5` attempts to use an aggregate before grouping. Counting all rows without grouping cannot give one result per class.
