# 7. SQL Japanese Cities Attributes

## Question and image

Query **all attributes of every Japanese city** in `CITY`. Japan's `COUNTRYCODE` is `JPN` in uppercase. No result order is specified.

**Example 1**

Input — `CITY`:

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |
| 2 | New York | USA | New York | 8400000 |
| 3 | Paris | FRA | Île-de-France | 2100000 |

Expected output:

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |

Tokyo is the only Japanese city in this small sample. The condition must still search by `COUNTRYCODE`, so any other city with code `JPN` would also be returned.

## My solution — SQLite

### Solution 1 — Select all columns

```sql
SELECT *
FROM CITY
WHERE COUNTRYCODE = 'JPN';
```

`*` requests every column in `CITY`. The `WHERE` clause keeps every row whose country code is `JPN`.

### Solution 2 — Name each column (my final query)

```sql
SELECT ID, NAME, COUNTRYCODE, DISTRICT, POPULATION
FROM CITY
WHERE COUNTRYCODE = 'JPN';
```

This names the five attributes required by the supplied table.

### Step-by-step explanation with one example

**Starting data.** One row represents one city. The question asks for **every Japanese city**, with all its attributes.

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |
| 2 | New York | USA | New York | 8400000 |
| 3 | Paris | FRA | Île-de-France | 2100000 |

**1. Filter by the country code.** `COUNTRYCODE = 'JPN'` tests the country of each row:

```sql
SELECT ID, NAME, COUNTRYCODE
FROM CITY
WHERE COUNTRYCODE = 'JPN';
```

| ID | NAME | COUNTRYCODE |
|---:|---|---|
| 1 | Tokyo | JPN |

New York and Paris are excluded because their codes are `USA` and `FRA`. Tokyo is only the example's Japanese city; filtering `NAME = 'Tokyo'` would miss other Japanese cities if they appeared in the table.

**2. Return all five attributes.** Keep the same filter and select `ID`, `NAME`, `COUNTRYCODE`, `DISTRICT`, and `POPULATION`:

```sql
SELECT ID, NAME, COUNTRYCODE, DISTRICT, POPULATION
FROM CITY
WHERE COUNTRYCODE = 'JPN';
```

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |

`SELECT *` also returns all five columns in the supplied schema. The final query lists them explicitly. Neither query needs `ORDER BY` because the prompt does not request an output order.
