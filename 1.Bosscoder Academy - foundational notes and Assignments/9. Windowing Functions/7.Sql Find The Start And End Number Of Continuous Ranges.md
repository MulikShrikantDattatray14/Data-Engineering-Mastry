# 7. SQL Find the Start and End Number of Continuous Ranges

## Question and image

**LeetCode 1285:** [Find the Start and End Number of Continuous Ranges](https://leetcode.com/problems/find-the-start-and-end-number-of-continuous-ranges/)

Write a solution to find the start and end number of continuous ranges in the table Logs.

Return the result table ordered by start_id.

**Example 1:**

Input:

Logs table:

| log_id |
| --- |
| 1 |
| 2 |
| 3 |
| 7 |
| 8 |
| 10 |

Output:

| start_id | end_id |
| --- | --- |
| 1 | 3 |
| 7 | 8 |
| 10 | 10 |

**Example explanation:** IDs 1, 2, and 3 form the range 1–3. IDs 4–6 are missing, so the next range starts at 7 and ends at 8. ID 9 is missing, leaving 10 as a one-number range: 10–10.

## My solution — SQLite

Your final query numbers the log IDs, uses the constant difference between an ID and its row number to identify each continuous range, and takes the smallest and largest ID in each range.

```sql
WITH numbered_logs AS (
    SELECT
        log_id,
        ROW_NUMBER() OVER (ORDER BY log_id) AS rn
    FROM Logs
),
ranges AS (
    SELECT
        log_id - rn AS group_key,
        MIN(log_id) AS start_id,
        MAX(log_id) AS end_id
    FROM numbered_logs
    GROUP BY log_id - rn
)
SELECT start_id, end_id
FROM ranges
ORDER BY start_id ASC;
```

### Step-by-step explanation with one example

**1. Start with the supplied log IDs.** A result row represents one uninterrupted run of IDs. A missing ID ends the current run, and a single ID forms a range whose start and end are equal.

| log_id |
|---:|
| 1 |
| 2 |
| 3 |
| 7 |
| 8 |
| 10 |

**2. Number the rows in ID order.** `ROW_NUMBER() OVER (ORDER BY log_id)` gives the smallest log ID row number 1, the next row number 2, and so on. The outer `ORDER BY` in this inspection query only displays the intermediate rows in that order.

```sql
SELECT
    log_id,
    ROW_NUMBER() OVER (ORDER BY log_id) AS rn
FROM Logs
ORDER BY log_id;
```

| log_id | rn |
|---:|---:|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 7 | 4 |
| 8 | 5 |
| 10 | 6 |

**3. Calculate a key for each continuous run.** Within a run, both `log_id` and `rn` increase by 1, so `log_id - rn` stays constant. After a missing ID, `log_id` jumps while `rn` increases by only 1, changing the key.

```sql
WITH numbered_logs AS (
    SELECT
        log_id,
        ROW_NUMBER() OVER (ORDER BY log_id) AS rn
    FROM Logs
)
SELECT
    log_id,
    rn,
    log_id - rn AS group_key
FROM numbered_logs
ORDER BY log_id;
```

| log_id | rn | group_key |
|---:|---:|---:|
| 1 | 1 | 0 |
| 2 | 2 | 0 |
| 3 | 3 | 0 |
| 7 | 4 | 3 |
| 8 | 5 | 3 |
| 10 | 6 | 4 |

The keys are 0 for IDs 1–3, 3 for IDs 7–8, and 4 for ID 10. `NTILE()` would divide the rows into a chosen number of buckets; it would not detect where IDs are missing.

**4. Find each group's boundaries.** `GROUP BY log_id - rn` combines IDs with the same key. `MIN(log_id)` gives that range's first ID, while `MAX(log_id)` gives its last ID.

```sql
WITH numbered_logs AS (
    SELECT
        log_id,
        ROW_NUMBER() OVER (ORDER BY log_id) AS rn
    FROM Logs
),
ranges AS (
    SELECT
        log_id - rn AS group_key,
        MIN(log_id) AS start_id,
        MAX(log_id) AS end_id
    FROM numbered_logs
    GROUP BY log_id - rn
)
SELECT group_key, start_id, end_id
FROM ranges
ORDER BY start_id ASC;
```

| group_key | start_id | end_id |
|---:|---:|---:|
| 0 | 1 | 3 |
| 3 | 7 | 8 |
| 4 | 10 | 10 |

**5. Return only the required columns.** The final query removes the helper `group_key` column and orders by `start_id ASC`.

| start_id | end_id |
|---:|---:|
| 1 | 3 |
| 7 | 8 |
| 10 | 10 |

**Manual check:** IDs 1, 2, and 3 are continuous; 4–6 are absent. IDs 7 and 8 are continuous; 9 is absent. ID 10 is a one-number range. The complete query produced these three rows on the supplied sample in SQLite; a single-ID case also produced equal start and end values.
