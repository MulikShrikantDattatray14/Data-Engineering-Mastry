# 6. SQL The Most Recent Orders for Each Product

## Question and image

**LeetCode 1549:** [The Most Recent Orders for Each Product](https://leetcode.com/problems/the-most-recent-orders-for-each-product/)

Write a solution to find the most recent order(s) of each product.

Return the result table ordered by product_name in ascending order and in case of a tie by the product_id in ascending order. If there is still a tie, order them by order_id in ascending order.

Orders table:

| 2 | 2020-07-30 | 2 | 2 |
| 3 | 2020-08-29 | 3 | 3 |

| 8 | 2020-08-03 | 1 | 2 |

| product_id | product_name | price |
| --- | --- | --- |
| 1 | keyboard | 120 |

| 3 | screen | 600 |
| 4 | hard disk | 450 |

Output:

| product_name | product_id | order_id | order_date |

| keyboard | 1 | 6 | 2020-08-01 |
| keyboard | 1 | 7 | 2020-08-01 |
| mouse | 2 | 8 | 2020-08-03 |

- Mouse's most recent order is order 8 on 2020-08-03.
- Screen's most recent order is order 3 on 2020-08-29.
- The hard disk was never ordered, so it has no output row.

## My solution — SQLite

Your final query joins orders to product names, ranks order dates separately for each product, and keeps every order on that product's most recent date.

```sql
WITH cte AS (
    SELECT
        P.product_name,
        O.product_id,
        O.order_id,
        O.order_date,
        DENSE_RANK() OVER (
            PARTITION BY O.product_id
            ORDER BY O.order_date DESC
        ) AS date_rank
    FROM Orders AS O
    JOIN Products AS P
        ON O.product_id = P.product_id
)
SELECT product_name, product_id, order_id, order_date
FROM cte
WHERE date_rank = 1
ORDER BY product_name ASC, product_id ASC, order_id ASC;
```

### Step-by-step explanation with one example

**1. Start with the supplied orders and products.** An output row represents an individual order on its product's latest order date. `Customers` is unnecessary because none of its columns appear in the result or determine which date is latest.

**2. Join `Orders` to `Products`.** `O.product_id = P.product_id` supplies a product name for every order. The inner join keeps the ten orders and omits the hard disk because it has no order. The query below adds a display order only to make the intermediate table easy to inspect.

```sql
SELECT
    P.product_name,
    O.product_id,
    O.order_id,
    O.order_date
FROM Orders AS O
JOIN Products AS P
    ON O.product_id = P.product_id
ORDER BY O.product_id ASC, O.order_date DESC, O.order_id ASC;
```

|---|---:|---:|---|

| mouse | 2 | 5 | 2020-06-10 |

**3. Rank dates within each product.** `PARTITION BY O.product_id` starts a new ranking for each product. `ORDER BY O.order_date DESC` puts the latest date first. `DENSE_RANK()` gives orders on the same date the same rank, so the two keyboard orders from 2020-08-01 both receive 1.

```sql
SELECT
    P.product_name,
    O.product_id,
    O.order_id,
    O.order_date,
    DENSE_RANK() OVER (
        PARTITION BY O.product_id
        ORDER BY O.order_date DESC
    ) AS date_rank
FROM Orders AS O
JOIN Products AS P
    ON O.product_id = P.product_id
ORDER BY O.product_id ASC, O.order_date DESC, O.order_id ASC;
```

| product_name | product_id | order_id | order_date | date_rank |
|---|---:|---:|---|---:|
| keyboard | 1 | 6 | 2020-08-01 | 1 |
| keyboard | 1 | 7 | 2020-08-01 | 1 |

`ROW_NUMBER()` would give the tied keyboard orders different numbers and lose one if only row 1 were kept. `DENSE_RANK()` keeps both.

**4. Keep the latest date and sort the output.** The CTE exposes `date_rank` to the outer query. `WHERE date_rank = 1` keeps keyboard orders 6 and 7, mouse order 8, and screen order 3. The final `ORDER BY` sorts by product name, then product ID, then order ID; it is separate from the date order used to calculate ranks.

## My solution — SQL Server

The same query works in SQL Server without syntax changes.

```sql
WITH cte AS (
    SELECT
        P.product_name,
        O.product_id,
        O.order_id,
        O.order_date,
        DENSE_RANK() OVER (
            PARTITION BY O.product_id
            ORDER BY O.order_date DESC
        ) AS date_rank

    JOIN Products AS P
        ON O.product_id = P.product_id
)
SELECT product_name, product_id, order_id, order_date
FROM cte
```
