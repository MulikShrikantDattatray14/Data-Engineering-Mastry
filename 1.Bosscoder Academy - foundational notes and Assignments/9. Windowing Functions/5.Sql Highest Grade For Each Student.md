# 5. SQL Highest Grade for Each Student

## Question and image

[**1112. Highest Grade For Each Student**](https://leetcode.com/problems/highest-grade-for-each-student/)

For each student, find the row with their highest `grade` and its corresponding `course_id`. If the student earned that grade in multiple courses, choose the **smallest `course_id`**.

Return `student_id`, `course_id`, and `grade`, ordered by `student_id` ascending.

**Example 1 — input:**

Enrollments:

| student_id | course_id | grade |
|---:|---:|---:|
| 2 | 2 | 95 |
| 2 | 3 | 95 |
| 1 | 1 | 90 |
| 1 | 2 | 99 |
| 3 | 1 | 80 |
| 3 | 2 | 75 |
| 3 | 3 | 82 |

**Output:**

| student_id | course_id | grade |
|---:|---:|---:|
| 1 | 2 | 99 |
| 2 | 2 | 95 |
| 3 | 3 | 82 |

**Explanation:** Student 2 has two courses with grade 95, so course 2 wins the tie because its ID is smaller than course 3.

## Schema

**Enrollments**

| Column Name | Type | Meaning |
|---|---|---|
| student_id | int | Student ID. |
| course_id | int | Course ID. |
| grade | int | Student's grade in the course; never NULL. |

`(student_id, course_id)` is the composite primary key.

## My solution — SQLite

Your `ROW_NUMBER()` approach selects one enrollment per student. The final `ORDER BY student_id ASC` was added to your submitted query because the question explicitly requires that output order.

```sql
WITH cte AS (
    SELECT
        student_id,
        course_id,
        grade,
        ROW_NUMBER() OVER (
            PARTITION BY student_id
            ORDER BY grade DESC, course_id ASC
        ) AS rn
    FROM Enrollments
)
SELECT student_id, course_id, grade
FROM cte
WHERE rn = 1
ORDER BY student_id ASC;
```

### Step-by-step explanation with one example

**1. Start with the supplied enrollments.** One final row is needed for each student: the course with their highest grade, using the smallest course ID if that highest grade is tied.

| student_id | course_id | grade |
|---:|---:|---:|
| 2 | 2 | 95 |
| 2 | 3 | 95 |
| 1 | 1 | 90 |
| 1 | 2 | 99 |
| 3 | 1 | 80 |
| 3 | 2 | 75 |
| 3 | 3 | 82 |

**2. Number each student's courses in the desired preference order.** `PARTITION BY student_id` restarts numbering at 1 for each student. `grade DESC` places the highest grade first, and `course_id ASC` places the smallest course ID first when grades tie. This inspection query orders the displayed intermediate rows by student and row number; the `ORDER BY` inside `OVER` determines the numbering.

```sql
SELECT
    student_id,
    course_id,
    grade,
    ROW_NUMBER() OVER (
        PARTITION BY student_id
        ORDER BY grade DESC, course_id ASC
    ) AS rn
FROM Enrollments
ORDER BY student_id ASC, rn ASC;
```

| student_id | course_id | grade | rn |
|---:|---:|---:|---:|
| 1 | 2 | 99 | 1 |
| 1 | 1 | 90 | 2 |
| 2 | 2 | 95 | 1 |
| 2 | 3 | 95 | 2 |
| 3 | 3 | 82 | 1 |
| 3 | 1 | 80 | 2 |
| 3 | 2 | 75 | 3 |

For student 2, both courses have grade 95. Course 2 gets `rn = 1` because 2 is smaller than course 3's ID.

**3. Filter after calculating `rn`.** The CTE makes the row number available to an outer query. `WHERE rn = 1` then keeps one preferred enrollment for each student and removes every row numbered 2 or higher.

```sql
WITH cte AS (
    SELECT
        student_id,
        course_id,
        grade,
        ROW_NUMBER() OVER (
            PARTITION BY student_id
            ORDER BY grade DESC, course_id ASC
        ) AS rn
    FROM Enrollments
)
SELECT student_id, course_id, grade, rn
FROM cte
WHERE rn = 1
ORDER BY student_id ASC;
```

| student_id | course_id | grade | rn |
|---:|---:|---:|---:|
| 1 | 2 | 99 | 1 |
| 2 | 2 | 95 | 1 |
| 3 | 3 | 82 | 1 |

**4. Return the requested columns and order.** The final query drops the helper `rn` column and sorts by `student_id ASC`. The `ORDER BY` inside the window expression chose each student's preferred course; the final `ORDER BY` controls the presentation order of the result.

| student_id | course_id | grade |
|---:|---:|---:|
| 1 | 2 | 99 |
| 2 | 2 | 95 |
| 3 | 3 | 82 |

**Manual check:** Student 1's highest grade is 99 in course 2. Student 2's highest grade is 95 in both courses 2 and 3, so course 2 wins. Student 3's highest grade is 82 in course 3. The final query produced these three rows in SQLite on the supplied sample.
