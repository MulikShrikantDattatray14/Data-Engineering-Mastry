# 14. Freight cost summary by shipping country

## Question and image

Using the Northwind database, the logistics team wants a freight summary per destination country. Work only from the `Orders` table (one row per order). For each `ShipCountry`, report how many orders shipped there, the total freight billed, and the average freight per order.

Return exactly four columns:

- `ShipCountry`: the destination country.
- `OrderCount`: number of orders shipped to that country.
- `TotalFreight`: sum of `Freight` for those orders, rounded to **2 decimal places**.
- `AvgFreight`: average `Freight` per order, rounded to **2 decimal places**.

Sort by `TotalFreight` in **descending** order; break ties by `ShipCountry` in **ascending** order.

**Expected output:** `ShipCountry`, `OrderCount`, `TotalFreight`, `AvgFreight` · 21 rows · order matters.

## My solution — SQLite

```sql
select ShipCountry , count( Orders.OrderID) as OrderCount , round (sum(Freight),2) as TotalFreight , round(sum(Freight)/count( Orders.OrderID),2) as AvgFreight
from Orders
group by ShipCountry
order by TotalFreight desc , ShipCountry asc
```

### Step-by-step explanation with one example

Use this small illustrative dataset throughout. It uses the question's actual table and column names; only columns needed for this explanation are shown. These are teaching rows, not the complete database or its expected row count. Every query result below was executed in SQLite on these same rows.

**Starting data**

`Orders`:

| OrderID | ShipCountry | Freight |
| --- | --- | --- |
| 1 | Brazil | 10.5 |
| 2 | Brazil | 20 |
| 3 | Canada | 30.5 |
| 4 | India | 5 |

**1. Count orders and total freight per destination**

Each Orders row already represents one order, so no join is needed. Group by ShipCountry and calculate both the number of orders and their summed Freight.

```sql
SELECT ShipCountry, COUNT(Orders.OrderID) AS OrderCount, SUM(Freight) AS FreightSum
FROM Orders
GROUP BY ShipCountry;
```

Result:

| ShipCountry | OrderCount | FreightSum |
| --- | --- | --- |
| Brazil | 2 | 30.5 |
| Canada | 1 | 30.5 |
| India | 1 | 5 |

Brazil has two orders totaling 30.5. Canada has one order totaling 30.5. India has one order totaling 5.

**2. Divide total freight by the order count**

The saved approach calculates an average as SUM(Freight) / COUNT(OrderID). The example stores Freight as REAL, so fractional results are retained.

```sql
SELECT ShipCountry, COUNT(Orders.OrderID) AS OrderCount,
       SUM(Freight) AS TotalFreight,
       SUM(Freight) / COUNT(Orders.OrderID) AS AvgFreight
FROM Orders
GROUP BY ShipCountry;
```

Result:

| ShipCountry | OrderCount | TotalFreight | AvgFreight |
| --- | --- | --- | --- |
| Brazil | 2 | 30.5 | 15.25 |
| Canada | 1 | 30.5 | 30.5 |
| India | 1 | 5 | 5 |

Brazil's average is 30.5 / 2 = 15.25. For Canada and India, the single order's freight is also the average. The final query rounds and sorts these grouped values.

**3. Assemble the final query**

Combine the steps using the saved solution. The query below preserves the original logic.

```sql
select ShipCountry , count( Orders.OrderID) as OrderCount , round (sum(Freight),2) as TotalFreight , round(sum(Freight)/count( Orders.OrderID),2) as AvgFreight
from Orders
group by ShipCountry
order by TotalFreight desc , ShipCountry asc
```

Final result for this example:

| ShipCountry | OrderCount | TotalFreight | AvgFreight |
| --- | --- | --- | --- |
| Brazil | 2 | 30.5 | 15.25 |
| Canada | 1 | 30.5 | 30.5 |
| India | 1 | 5 | 5 |

**Check the result:** The four orders are accounted for as 2 + 1 + 1. Brazil and Canada tie on TotalFreight, so Brazil comes first alphabetically; India follows.

The saved formula counts every non-NULL OrderID in its denominator. With NULL Freight values it differs from AVG(Freight), which excludes NULL freight values from its denominator. This example uses non-NULL REAL Freight; the original query is preserved.

## My solution — SQL Server

```sql
select ShipCountry , count( Orders.OrderID) as OrderCount , round (sum(Freight),2) as TotalFreight , round(sum(Freight)/count( Orders.OrderID),2) as AvgFreight
from Orders
group by ShipCountry
order by TotalFreight desc , ShipCountry asc
```

## Official solution

```sql
SELECT ShipCountry,
       COUNT(*) AS OrderCount,
       ROUND(SUM(Freight), 2) AS TotalFreight,
       ROUND(AVG(Freight), 2) AS AvgFreight
FROM Orders
GROUP BY ShipCountry
ORDER BY TotalFreight DESC, ShipCountry ASC;
```

### What this tests

Calculating several aggregates per group and rounding numeric results.

### The approach

Group Orders by ShipCountry; count orders, sum Freight, and average Freight; round both freight measures; sort total freight descending and country ascending.

### Why this way

One grouped query calculates all three measures without combining separate aggregate queries.

### Common mistakes

Missing or incorrect grouping, omitting rounding, or adding unnecessary filters that exclude orders.
