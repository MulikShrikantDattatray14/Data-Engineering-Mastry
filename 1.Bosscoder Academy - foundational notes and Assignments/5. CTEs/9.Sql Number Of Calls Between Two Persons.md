# 9. SQL Number Of Calls Between Two Persons

## Question and image

**9. Sql Number Of Calls Between Two Persons**

Table: Calls

| Column Name | Type |
|---|---|
| from_id | int |
| to_id | int |
| duration | int |

This table does not have a primary key (column with unique values), it may contain duplicates.

This table contains the duration of a phone call between `from_id` and `to_id`.

`from_id != to_id`

Write a solution to report the number of calls and the total call duration between each pair of distinct persons (`person1`, `person2`) where `person1 < person2`.

**Example 1:**

Example:

Input:

Calls table:

| from_id | to_id | duration |
|---|---|---|
| 1 | 2 | 59 |
| 2 | 1 | 11 |
| 1 | 3 | 20 |
| 3 | 4 | 100 |
| 3 | 4 | 200 |
| 3 | 4 | 200 |
| 4 | 3 | 499 |

Output:

| person1 | person2 | call_count | total_duration |
|---|---|---|---|
| 1 | 2 | 2 | 70 |
| 1 | 3 | 1 | 20 |
| 3 | 4 | 4 | 999 |

*Explanation:*

Users 1 and 2 had 2 calls and the total duration is 70 (59 + 11).

Users 1 and 3 had 1 call and the total duration is 20.

Users 3 and 4 had 4 calls and the total duration is 999 (100 + 200 + 200 + 499).

## Schema

**Calls**  
from_id, to_id, duration

- `from_id` - int
- `to_id` - int
- `duration` - int
- The table has no primary key and may contain duplicate rows.
- `from_id` and `to_id` are always different.

## My solution — SQLite

```sql
SELECT
    CASE
        WHEN from_id < to_id THEN from_id
        ELSE to_id
    END AS person1,
    CASE
        WHEN from_id < to_id THEN to_id
        ELSE from_id
    END AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY person1, person2;
```

### Step-by-step explanation with one example

Use the supplied example throughout. Each result below is produced from those same rows; the final query preserves your saved approach.

**Starting data**

`Calls`:

| from_id | to_id | duration |
| --- | --- | --- |
| 1 | 2 | 59 |
| 2 | 1 | 11 |
| 1 | 3 | 20 |
| 3 | 4 | 100 |
| 3 | 4 | 200 |
| 3 | 4 | 200 |
| 4 | 3 | 499 |

**1. Put the smaller person ID first on every call**

Calls in both directions belong to the same pair. CASE chooses the smaller ID as person1 and the larger as person2 without removing any call.

```sql
SELECT
    CASE WHEN from_id < to_id THEN from_id ELSE to_id END AS person1,
    CASE WHEN from_id < to_id THEN to_id ELSE from_id END AS person2,
    duration
FROM Calls;
```

Result:

| person1 | person2 | duration |
| --- | --- | --- |
| 1 | 2 | 59 |
| 1 | 2 | 11 |
| 1 | 3 | 20 |
| 3 | 4 | 100 |
| 3 | 4 | 200 |
| 3 | 4 | 200 |
| 3 | 4 | 499 |

Both (1, 2) and (2, 1) become (1, 2). The (4, 3) call becomes (3, 4). The two identical 200-duration calls remain as two rows.

**2. Count calls for each normalized pair**

Grouping the normalized IDs collects both directions. COUNT(*) counts every call row, including duplicate-looking records.

```sql
WITH normalized AS (
SELECT
    CASE WHEN from_id < to_id THEN from_id ELSE to_id END AS person1,
    CASE WHEN from_id < to_id THEN to_id ELSE from_id END AS person2,
    duration
FROM Calls
)
SELECT person1, person2, COUNT(*) AS call_count
FROM normalized
GROUP BY person1, person2;
```

Result:

| person1 | person2 | call_count |
| --- | --- | --- |
| 1 | 2 | 2 |
| 1 | 3 | 1 |
| 3 | 4 | 4 |

The diagnostic CTE only exposes the same CASE expressions used directly in your saved query. There are seven calls in total: 2 + 1 + 4.

**3. Assemble the final query**

Use the original CASE expressions, group by their SQLite aliases, and add SUM(duration) alongside COUNT(*) to return both measures per pair.

```sql
SELECT
    CASE
        WHEN from_id < to_id THEN from_id
        ELSE to_id
    END AS person1,
    CASE
        WHEN from_id < to_id THEN to_id
        ELSE from_id
    END AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY person1, person2;
```

Final result for this example:

| person1 | person2 | call_count | total_duration |
| --- | --- | --- | --- |
| 1 | 2 | 2 | 70 |
| 1 | 3 | 1 | 20 |
| 3 | 4 | 4 | 999 |

**Check the result:** Pair (1, 2): 59 + 11 = 70; pair (1, 3): 20; pair (3, 4): 100 + 200 + 200 + 499 = 999. No DISTINCT is needed because each row represents a call.

## My solution — SQL Server

```sql
SELECT
    CASE
        WHEN from_id < to_id THEN from_id
        ELSE to_id
    END AS person1,
    CASE
        WHEN from_id < to_id THEN to_id
        ELSE from_id
    END AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY
    CASE
        WHEN from_id < to_id THEN from_id
        ELSE to_id
    END,
    CASE
        WHEN from_id < to_id THEN to_id
        ELSE from_id
    END;
```
