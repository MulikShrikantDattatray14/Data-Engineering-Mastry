Write a solution to find the number of times each student attended each exam.

## My solution — SQLite

```sql
SELECT
    S.student_id,
    S.student_name,
    Sub.subject_name,
    COUNT(E.subject_name) AS attended_exams
FROM Subjects AS Sub
CROSS JOIN Students AS S
LEFT JOIN Examinations AS E
    ON E.student_id = S.student_id
   AND E.subject_name = Sub.subject_name
GROUP BY
    S.student_id,
    S.student_name,
    Sub.subject_name
ORDER BY
    S.student_id,
    Sub.subject_name;
```

**Key learnings**

- `CROSS JOIN` creates every student-subject combination. With four students and three subjects, it creates twelve required rows before examination attendance is attached.
- A `CROSS JOIN` has no `ON` condition because it deliberately pairs every row from one table with every row from the other table.
- `LEFT JOIN Examinations` preserves student-subject combinations that have no matching examination record.
- The examination match requires both keys: the same `student_id` and the same `subject_name`.
- `COUNT(E.subject_name)` counts only matched examination rows because `COUNT(column)` ignores `NULL`. Therefore an unmatched student-subject pair returns `0`.
- `COUNT(*)` would incorrectly count the placeholder row produced by the `LEFT JOIN`, causing an unattended exam to show `1`.
- Grouping by the student and subject columns produces one output row for each student-subject combination.

**3. Assemble the final query**

Group the joined rows back into one row per student-subject pair. COUNT(E.subject_name) ignores NULL placeholders and counts actual attendance, then ORDER BY applies the required ordering.

```sql
SELECT
    S.student_id,
    S.student_name,
    Sub.subject_name,
    COUNT(E.subject_name) AS attended_exams
FROM Subjects AS Sub
CROSS JOIN Students AS S
LEFT JOIN Examinations AS E
    ON E.student_id = S.student_id
   AND E.subject_name = Sub.subject_name
GROUP BY
    S.student_id,
    S.student_name,
    Sub.subject_name
ORDER BY
    S.student_id,
    Sub.subject_name;
```
