# 5. SQL Find Immediate Delivery II

## Question and image

**5. Sql Find Immediate Delivery Ii**

Table: Delivery

| Column Name | Type |
|---|---|
| delivery_id | int |
| customer_id | int |
| order_date | date |
| customer_pref_delivery_date | date |

`delivery_id` is the column of unique values of this table.

The table holds information about food delivery to customers that make orders at some date and specify a preferred delivery date (on the same order date or after it).

If the customer's preferred delivery date is the same as the order date, then the order is called immediate; otherwise, it is called scheduled.

The first order of a customer is the order with the earliest order date that the customer made. It is guaranteed that a customer has precisely one first order.

Write a solution to find the percentage of immediate orders in the first orders of all customers rounded to 2 decimals.

The result format is in the following example.

**Example 1:**

Input:

Delivery table:

| delivery_id | customer_id | order_date | customer_pref_delivery_date |
|---|---|---|---|
| 1 | 1 | 2019-08-01 | 2019-08-02 |
| 2 | 2 | 2019-08-02 | 2019-08-02 |
| 3 | 1 | 2019-08-11 | 2019-08-12 |
| 4 | 3 | 2019-08-24 | 2019-08-24 |
| 5 | 3 | 2019-08-21 | 2019-08-22 |
| 6 | 2 | 2019-08-11 | 2019-08-13 |
| 7 | 4 | 2019-08-09 | 2019-08-09 |

Output:

| immediate_percentage |
|---|
| 50.00 |

Explanation:

The customer id 1 has a first order with delivery id 1 and it is scheduled.
The customer id 2 has a first order with delivery id 2 and it is immediate.

The customer id 3 has a first order with delivery id 5 and it is scheduled.

The customer id 4 has a first order with delivery id 7 and it is immediate.

Hence, half the customers have immediate first orders.

## Schema

**Delivery**  
delivery_id, customer_id, order_date, customer_pref_delivery_date

- `delivery_id` - int, unique
- `customer_id` - int
- `order_date` - date
- `customer_pref_delivery_date` - date on or after `order_date`
- Every customer has precisely one first order.

## My solution — SQLite

```sql
WITH customer_count AS (
    SELECT
        COUNT(DISTINCT customer_id) AS total_customers
    FROM Delivery
),
first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
),
immediate_orders AS (
    SELECT
        COUNT(*) AS immediate_first_orders
    FROM Delivery AS D
    JOIN first_order_of_each_customer AS F
        ON D.customer_id = F.customer_id
       AND D.order_date = F.first_order_date
    WHERE D.order_date = D.customer_pref_delivery_date
)
SELECT
    ROUND(
        immediate_first_orders * 100.0 / total_customers,
        2
    ) AS immediate_percentage
FROM customer_count
CROSS JOIN immediate_orders;
```

### Step-by-step explanation with one example

Use the supplied example throughout. Each result below is produced from those same rows; the final query preserves your saved approach.

**Starting data**

`Delivery`:

| delivery_id | customer_id | order_date | customer_pref_delivery_date |
| --- | --- | --- | --- |
| 1 | 1 | 2019-08-01 | 2019-08-02 |
| 2 | 2 | 2019-08-02 | 2019-08-02 |
| 3 | 1 | 2019-08-11 | 2019-08-12 |
| 4 | 3 | 2019-08-24 | 2019-08-24 |
| 5 | 3 | 2019-08-21 | 2019-08-22 |
| 6 | 2 | 2019-08-11 | 2019-08-13 |
| 7 | 4 | 2019-08-09 | 2019-08-09 |

**1. Count customers for the denominator**

Only the first order of each customer is considered, so the denominator is the number of distinct customers rather than all seven deliveries.

```sql
WITH customer_count AS (
    SELECT
        COUNT(DISTINCT customer_id) AS total_customers
    FROM Delivery
)
SELECT * FROM customer_count;
```

Result:

| total_customers |
| --- |
| 4 |

There are four customers and therefore four first orders.

**2. Find each customer's earliest order date**

MIN(order_date) identifies the first date within each customer group. The prompt guarantees one first order per customer.

```sql
WITH first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
)
SELECT * FROM first_order_of_each_customer ORDER BY customer_id;
```

Result:

| customer_id | first_order_date |
| --- | --- |
| 1 | 2019-08-01 |
| 2 | 2019-08-02 |
| 3 | 2019-08-21 |
| 4 | 2019-08-09 |

Customer 3's first order is 2019-08-21, even though their later 2019-08-24 delivery appears earlier in the input table.

**3. Retrieve the complete first-order rows**

The grouped dates do not include the preferred delivery date. Join back using BOTH customer_id and the earliest date to retrieve the correct delivery.

```sql
WITH first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
)
SELECT D.delivery_id, D.customer_id, D.order_date,
       D.customer_pref_delivery_date
FROM Delivery AS D
JOIN first_order_of_each_customer AS F
  ON D.customer_id = F.customer_id
 AND D.order_date = F.first_order_date
ORDER BY D.customer_id;
```

Result:

| delivery_id | customer_id | order_date | customer_pref_delivery_date |
| --- | --- | --- | --- |
| 1 | 1 | 2019-08-01 | 2019-08-02 |
| 2 | 2 | 2019-08-02 | 2019-08-02 |
| 5 | 3 | 2019-08-21 | 2019-08-22 |
| 7 | 4 | 2019-08-09 | 2019-08-09 |

Only deliveries 1, 2, 5, and 7 remain. Delivery 4 is immediate but is not customer 3's first order, so it must not contribute.

**4. Keep first orders that are immediate**

An immediate first order has the same order date and preferred delivery date.

```sql
WITH first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
)
SELECT D.delivery_id, D.customer_id
FROM Delivery AS D
JOIN first_order_of_each_customer AS F
  ON D.customer_id = F.customer_id
 AND D.order_date = F.first_order_date
WHERE D.order_date = D.customer_pref_delivery_date
ORDER BY D.customer_id;
```

Result:

| delivery_id | customer_id |
| --- | --- |
| 2 | 2 |
| 7 | 4 |

Customers 2 and 4 qualify. The immediate_orders CTE counts these two rows.

**5. Reduce immediate first orders to one count**

The numerator CTE returns a single row, which can be combined with the one-row customer_count CTE.

```sql
WITH customer_count AS (
    SELECT
        COUNT(DISTINCT customer_id) AS total_customers
    FROM Delivery
),
first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
),
immediate_orders AS (
    SELECT
        COUNT(*) AS immediate_first_orders
    FROM Delivery AS D
    JOIN first_order_of_each_customer AS F
        ON D.customer_id = F.customer_id
       AND D.order_date = F.first_order_date
    WHERE D.order_date = D.customer_pref_delivery_date
)
SELECT * FROM immediate_orders;
```

Result:

| immediate_first_orders |
| --- |
| 2 |

**6. Assemble the final query**

CROSS JOIN the two one-row counts, then calculate 2 * 100.0 / 4 and round to two decimal places.

```sql
WITH customer_count AS (
    SELECT
        COUNT(DISTINCT customer_id) AS total_customers
    FROM Delivery
),
first_order_of_each_customer AS (
    SELECT
        customer_id,
        MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
),
immediate_orders AS (
    SELECT
        COUNT(*) AS immediate_first_orders
    FROM Delivery AS D
    JOIN first_order_of_each_customer AS F
        ON D.customer_id = F.customer_id
       AND D.order_date = F.first_order_date
    WHERE D.order_date = D.customer_pref_delivery_date
)
SELECT
    ROUND(
        immediate_first_orders * 100.0 / total_customers,
        2
    ) AS immediate_percentage
FROM customer_count
CROSS JOIN immediate_orders;
```

Final result for this example:

| immediate_percentage |
| --- |
| 50 |
