# 3. SQL Find Total Time Spent By Each Employee

## Question and image

**3. Sql Find Total Time Spent By Each Employee**

Table: Employees

| Column Name | Type |
|---|---|
| emp_id | int |
| event_day | date |
| in_time | int |
| out_time | int |

`(emp_id, event_day, in_time)` is the primary key (combinations of columns with unique values) of this table.

The table shows the employees' entries and exits in an office.

`event_day` is the day at which this event happened, `in_time` is the minute at which the employee entered the office, and `out_time` is the minute at which they left the office.

`in_time` and `out_time` are between 1 and 1440.

It is guaranteed that no two events on the same day intersect in time, and `in_time < out_time`.

Write a solution to calculate the total time in minutes spent by each employee on each day at the office. Note that within one day, an employee can enter and leave more than once. The time spent in the office for a single entry is `out_time - in_time`.

Return the result table ordered by `emp_id` and day.

**Example 1:**

Input:

Employees table:

| emp_id | event_day | in_time | out_time |
|---|---|---|---|
| 1 | 2020-11-28 | 4 | 32 |
| 1 | 2020-11-28 | 55 | 200 |
| 1 | 2020-12-03 | 1 | 42 |
| 2 | 2020-11-28 | 3 | 33 |
| 2 | 2020-12-09 | 47 | 74 |

Output:

| day | emp_id | total_time |
|---|---|---|
| 2020-11-28 | 1 | 173 |
| 2020-12-03 | 1 | 41 |
| 2020-11-28 | 2 | 30 |
| 2020-12-09 | 2 | 27 |

Explanation:

Employee 1 has three events: two on day 2020-11-28 with a total of (32 - 4) + (200 - 55) = 173, and one on day 2020-12-03 with a total of (42 - 1) = 41.

Employee 2 has two events: one on day 2020-11-28 with a total of (33 - 3) = 30, and one on day 2020-12-09 with a total of (74 - 47) = 27.

## Schema

**Employees**  
emp_id, event_day, in_time, out_time

- `emp_id` — integer
- `event_day` — date
- `in_time` — integer between 1 and 1440
- `out_time` — integer between 1 and 1440
- (`emp_id`, `event_day`, `in_time`) is the primary key.
- `in_time < out_time`, and events on the same day do not overlap.

## My solution — SQLite

```sql
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id
ORDER BY emp_id ASC, day ASC;
```

### Key learnings

- The duration of one office visit is calculated directly as `out_time - in_time`; no separate `DIFF()` function is needed.
- An employee may have multiple visits on the same day, so `SUM(out_time - in_time)` adds all visit durations for that employee-day group.
- Grouping by both `event_day` and `emp_id` creates one result row for each employee on each day.
- `event_day AS day` provides the exact output column name required by the question.
- `ORDER BY emp_id ASC, day ASC` sorts first by employee and then chronologically within each employee's rows.

### Step-by-step explanation with one example

Use the supplied example throughout. Each query below runs against these same starting rows; intermediate SELECT statements do not modify the tables.

**Starting data**

`Employees`:

| emp_id | event_day | in_time | out_time |
| --- | --- | --- | --- |
| 1 | 2020-11-28 | 4 | 32 |
| 1 | 2020-11-28 | 55 | 200 |
| 1 | 2020-12-03 | 1 | 42 |
| 2 | 2020-11-28 | 3 | 33 |
| 2 | 2020-12-09 | 47 | 74 |

**1. Calculate the duration of every visit**

A row is one visit, while the requested result is one employee on one day. Calculate each visit before adding visits together.

```sql
SELECT emp_id, event_day, in_time, out_time,
       out_time - in_time AS visit_minutes
FROM Employees
ORDER BY emp_id, event_day, in_time;
```

Result:

| emp_id | event_day | in_time | out_time | visit_minutes |
| --- | --- | --- | --- | --- |
| 1 | 2020-11-28 | 4 | 32 | 28 |
| 1 | 2020-11-28 | 55 | 200 | 145 |
| 1 | 2020-12-03 | 1 | 42 | 41 |
| 2 | 2020-11-28 | 3 | 33 | 30 |
| 2 | 2020-12-09 | 47 | 74 | 27 |

Employee 1 has visits of 28 and 145 minutes on November 28. Those two rows belong to the same employee-day group.

**2. Add visits for each employee and day**

Both emp_id and event_day identify a result group; grouping by only one would combine different employees or different days.

```sql
SELECT event_day AS day, emp_id, COUNT(*) AS visits,
       SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id
ORDER BY emp_id ASC, day ASC;
```

Result:

| day | emp_id | visits | total_time |
| --- | --- | --- | --- |
| 2020-11-28 | 1 | 2 | 173 |
| 2020-12-03 | 1 | 1 | 41 |
| 2020-11-28 | 2 | 1 | 30 |
| 2020-12-09 | 2 | 1 | 27 |

Five visits become four employee-day rows. The visits count is displayed only to make the grouping visible.

**3. Assemble the final query**

Combine the steps using the saved solution. The query below preserves the original logic.

```sql
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id
ORDER BY emp_id ASC, day ASC;
```

Final result for this example:

| day | emp_id | total_time |
| --- | --- | --- |
| 2020-11-28 | 1 | 173 |
| 2020-12-03 | 1 | 41 |
| 2020-11-28 | 2 | 30 |
| 2020-12-09 | 2 | 27 |

**Check the result:** For employee 1 on November 28, (32 - 4) + (200 - 55) = 173. The other totals are 41, 30, and 27. The final query keeps the required three columns and orders by employee, then day.

## My solution — SQL Server

```sql
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id
ORDER BY emp_id ASC, day ASC;
```

The same query works in SQLite and SQL Server.
> **Shared SQL processing note:** `FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → row limiting`. SQLite uses `LIMIT/OFFSET`; SQL Server uses `TOP` or `OFFSET/FETCH`. `WHERE` filters rows before grouping, while `HAVING` filters groups after aggregation.
