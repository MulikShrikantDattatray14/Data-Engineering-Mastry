# 7. SQL Japanese Cities Attributes

## Question and image

Query **all attributes of every Japanese city** in `CITY`. Japan's `COUNTRYCODE` is `JPN` in uppercase. No result order is specified.

**Example 1**

Input — `CITY`:

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |
| 2 | New York | USA | New York | 8400000 |
| 3 | Paris | FRA | Île-de-France | 2100000 |

Expected output:

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Tokyo | JPN | Tokyo | 9000000 |

Tokyo is the only Japanese city in this small sample. The condition must still search by `COUNTRYCODE`, so any other city with code `JPN` would also be returned.
