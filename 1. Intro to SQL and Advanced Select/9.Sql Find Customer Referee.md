# 9. SQL Find Customer Referee

## Question and image

Return the names of customers who were **not referred by customer 2**, including customers with **no referee**. A missing `referee_id` is `NULL`. No output order is specified.

**Example 1**

Input — `Customer`:

| id | name | referee_id |
|---:|---|---:|
| 1 | Will | NULL |
| 2 | Jane | NULL |
| 3 | Alex | 2 |
| 4 | Bill | NULL |
| 5 | Zack | 1 |
| 6 | Mark | 2 |

Expected output:

| name |
|---|
| Will |
| Jane |
| Bill |
| Zack |

Will, Jane, and Bill have no referee. Zack was referred by customer 1. Alex and Mark were referred by customer 2, so they are excluded.
