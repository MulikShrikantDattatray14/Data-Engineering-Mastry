# PNP Q046. Same-brand products where one costs at least twice the other

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![MEDIUM](<../../_badges/medium.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 46, pp. 79–81. **Difficulty:** Medium.

**Business scenario.** The pricing team is reviewing price ladders. When one brand sells two products in the same sub-category and one costs at least twice the other, shoppers either see a clear good-better-best ladder or a gap with nothing in the middle. The team wants every such pair listed once, cheaper product on the left, so they can decide where a mid-priced pack is missing.

**Task.** Find every pair of products with the same Brand and the same Sub_Category where the pricier product's Sale_Price is at least 2 times the cheaper one's. Return each pair once. Products with no brand are not part of any brand ladder. Sort by price ratio, highest first.

**Expected output (as supplied):**

```text
Brand
Sub_Category
cheaper_product , cheaper_price
pricier_product , pricier_price
price_ratio : pricier price divided by cheaper price, 2 decimals
```

The source is a text-based PDF; no separate question image was supplied.

## My solution — SQLite

**Learner's final submitted query (preserved verbatim):**

```sql
WITH Products_2 AS (

    -- CTE 1: Clean the source data
    SELECT *
    FROM Products
    WHERE Brand IS NOT NULL
      AND TRIM(Brand) <> ''
      AND Sub_Category IS NOT NULL
      AND TRIM(Sub_Category) <> ''

),

product_pairs AS (

    -- CTE 2: Generate unique pairs and arrange by price
    SELECT
        P1.Brand,
        P1.Sub_Category,

        CASE
            WHEN P1.Sale_Price <= P2.Sale_Price
            THEN P1.Product
            ELSE P2.Product
        END AS cheaper_product,

        CASE
            WHEN P1.Sale_Price <= P2.Sale_Price
            THEN P1.Sale_Price
            ELSE P2.Sale_Price
        END AS cheaper_price,

        CASE
            WHEN P1.Sale_Price > P2.Sale_Price
            THEN P1.Product
            ELSE P2.Product
        END AS pricier_product,

        CASE
            WHEN P1.Sale_Price > P2.Sale_Price
            THEN P1.Sale_Price
            ELSE P2.Sale_Price
        END AS pricier_price

        /*
        Alternative approach: Calculate price_ratio directly
        in this CTE instead of creating a separate CTE.

        CASE
            WHEN P1.Sale_Price <= P2.Sale_Price
            THEN ROUND(P2.Sale_Price * 1.0 / P1.Sale_Price, 2)
            ELSE ROUND(P1.Sale_Price * 1.0 / P2.Sale_Price, 2)
        END AS price_ratio
        */

    FROM Products_2 AS P1

    INNER JOIN Products_2 AS P2
        ON P1.Brand = P2.Brand
       AND P1.Sub_Category = P2.Sub_Category
       AND P1.ProductID < P2.ProductID

),

price_ratios AS (

    -- CTE 3: Calculate the price ratio
    SELECT
        *,
        ROUND(
            pricier_price * 1.0 / cheaper_price,
            2
        ) AS price_ratio

    FROM product_pairs

)

-- Main query: Keep only ratios greater than or equal to 2.0
SELECT *
FROM price_ratios
WHERE price_ratio >= 2.0;
```

**Review note:** The query applies the correct inclusive threshold (`price_ratio >= 2.0`) and preserves the alternative ratio calculation as a comment in the second CTE. The original question also requires results sorted by price ratio, highest first; this submitted version does not yet include an `ORDER BY price_ratio DESC` clause. The learner query is retained unchanged pending that final ordering decision and the remaining record-completion checks. Execution against the actual PrepNPlaced dataset has not been performed.
