## My solution — SQLite

Your final subquery solution:

```sql
SELECT E1.emp_id, E1.emp_name
FROM employees AS E1
WHERE E1.emp_id NOT IN (
    SELECT E2.manager_id
    FROM employees AS E2
    WHERE E2.manager_id IS NOT NULL
);
```

## Official solution

**Source:** [Advanced SQL 100 Query Questions, Vol. 1](<../Source Materials/Advanced_SQL_100_Query_Questions_Vol1 (2).pdf>), question 14, PDF p. 4. The source uses MySQL 8.

```sql
SELECT e.emp_id, e.emp_name
FROM employees e
WHERE NOT EXISTS (SELECT 1 FROM employees r WHERE r.manager_id = e.emp_id);
```

**What this tests.** Finding employees with no direct reports.

**The approach.** For each employee `e`, the correlated subquery looks for another employee `r` whose `manager_id` equals `e.emp_id`. `NOT EXISTS` keeps `e` only when there is no such row.

**Why this works.** The absence of a matching report means nobody lists that employee as their manager. `NOT EXISTS` also avoids the `NULL` issue that arises with an unfiltered `NOT IN` subquery.

**Your alternative.** Your `NOT IN` query returns the same employees because it removes `NULL` manager IDs from the subquery first.

**Common mistakes.** Testing the outer employee's `manager_id` instead of their `emp_id`; or allowing `NULL` values into the `NOT IN` list.
