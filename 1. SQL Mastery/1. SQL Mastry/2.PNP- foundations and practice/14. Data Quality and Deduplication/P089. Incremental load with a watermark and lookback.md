# PNP Q089. Incremental load with a watermark and lookback

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EXPERT](<../../_badges/expert.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 89, pp. 175–177. **Difficulty:** Expert.

**Business scenario.** The analytics warehouse keeps a copy of Orders that is rebuilt from scratch every night. The full reload now takes too long and blocks the morning dashboards. The data engineering team wants an incremental job: pull only recent orders, insert the new ones, update the ones that changed, and leave everything else alone. The job must be safe to rerun after a failure, and it must report what it did so the scheduler can log it.

**Task.** Write one nightly load from Orders into a target table orders_target with the same columns and primary key plus an etl_updated_at timestamp. The batch is every source order with OrderDate on or after the target's latest OrderDate minus a 21-day lookback, plus any source order with a NULL OrderDate . Insert orders the target does not have. Update orders whose values differ. Do not touch identical rows. Return one row per action with its row count. For the demo, create the target as a TEMP table and seed it as the previous night's run would have left it.

**Expected output (as supplied):**

```text
action : inserted , updated or unchanged , always all three, in that order
rows : number of batch rows that got that action
```

The source is a text-based PDF; no separate question image was supplied.

### Sample input and expected output

*Illustrative example; the target's latest OrderDate is 2026-01-11, so the 21-day lookback starts on 2025-12-21. Order 4 is older and remains untouched. Assume all unshown fields agree.*

Input — source `Orders`:

| OrderID | OrderDate | Total_Order_Amount |
|---:|---|---:|
| 1 | 2026-01-10 | 100 |
| 2 | 2026-01-11 | 200 |
| 3 | NULL | 50 |
| 4 | 2025-12-01 | 30 |

Input — seeded `orders_target`:

| OrderID | OrderDate | Total_Order_Amount |
|---:|---|---:|
| 1 | 2026-01-10 | 100 |
| 2 | 2026-01-11 | 150 |
| 4 | 2025-12-01 | 30 |

Expected output:

| action | rows |
|---|---:|
| inserted | 1 |
| updated | 1 |
| unchanged | 1 |
