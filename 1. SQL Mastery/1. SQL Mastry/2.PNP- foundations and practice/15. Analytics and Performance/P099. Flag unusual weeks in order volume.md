# PNP Q099. Flag unusual weeks in order volume

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EXPERT](<../../_badges/expert.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 99, pp. 206–210. **Difficulty:** Expert.

**Business scenario.** The data platform team gets a Monday alert when last week's order count looks wrong. The alert has two jobs: catch a broken load (a week that is far too low because a feed failed) and catch a real event (a sale that tripled volume). The current rule, "alert if orders drop 30% week on week", fires every holiday and misses slow drifts. They want a rule that adapts to each period's normal level and spread.

**Task.** Build a weekly order-count series with no missing weeks. For each week, compute the mean and sample standard deviation of the previous eight weeks (not including the week itself), a z-score for the week, and a flag when the absolute z-score is 3 or more. Return only complete weeks. Sort flagged weeks first, then newest first.

**Expected output (as supplied):**

```text
week_start : Monday of the ISO week
orders : orders placed that week (0 for a week with none)
trailing_mean : mean weekly orders over the 8 previous weeks, 2 dp
trailing_stddev : sample standard deviation over the same 8 weeks, 2 dp
z_score : (orders - trailing_mean) / trailing_stddev , 2 dp; NULL until 8 prior weeks exist or when the spread is 0
is_anomaly : true when |z_score| >= 3 , NULL when there is no score
```

The source is a text-based PDF; no separate question image was supplied.
