# P005 · Exclude the start of the next quarter

[![Previous](../previous.svg)](01.md) <kbd>Next</kbd>  · **2 of 2**

The next quarter is excluded while all March 31 timestamps remain eligible.

## SQL added or changed

```sql
where OrderDate>= '2025-01-01' and OrderDate < '2025-04-01'
```

## Input to this step

**Keep orders from the start of the quarter · 3 rows**

<details>
<summary>Full SQLite query for this step</summary>

```sql
select OrderID, CustomerID, OrderDate,Total_Order_Amount
from Orders
where OrderDate>= '2025-01-01' and OrderDate < '2025-04-01'
order by OrderDate asc , OrderID asc
```
