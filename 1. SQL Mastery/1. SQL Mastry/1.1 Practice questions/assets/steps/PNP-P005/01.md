# P005 · Keep orders from the start of the quarter

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 2**

The first day belongs to the quarter. Orders is the only source because each output row is an order, and OrderDate determines eligibility while OrderID and amount are already present.

## SQL added or changed

```sql
select OrderID, CustomerID, OrderDate,Total_Order_Amount
from Orders
where OrderDate>= '2025-01-01'
order by OrderDate asc , OrderID asc
```
