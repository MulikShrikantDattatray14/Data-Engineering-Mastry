# P014 · Keep only 2025 orders

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

Both the monthly counts and the totals must use only 2025 orders. Orders is the only source because OrderDate identifies the 2025 month and Total_Order_Amount belongs to each order.

## SQL added or changed

```sql
SELECT OrderID, OrderDate, Total_Order_Amount
FROM Orders
WHERE strftime('%Y', OrderDate) = '2025'
ORDER BY OrderID;
```
