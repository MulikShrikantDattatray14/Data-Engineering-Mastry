# P014 · Add the monthly total and ensure chronological order

[![Previous](../previous.svg)](03.md) <kbd>Next</kbd>  · **4 of 4**

The count and sum describe the same order group. The explicit sort guarantees January precedes March.

## SQL added or changed

```sql
count(*) AS orders,
       sum(Total_Order_Amount) AS order_value
```

## Input to this step

**Group and count orders · 2 rows**

| 🟦 order_month | 🟦 orders |
| --- | --- |
| 2025-01-01 | 2 |
| 2025-03-01 | 1 |

## Result · 2 rows

| 🟦 order_month | 🟦 orders | 🟦 order_value |
| --- | --- | --- |
| 2025-01-01 | 2 | 150 |
| 2025-03-01 | 1 | 200 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT date(OrderDate, 'start of month') AS order_month,
       count(*) AS orders,
       sum(Total_Order_Amount) AS order_value
FROM Orders
WHERE strftime('%Y', OrderDate) = '2025'
GROUP BY strftime('%m', OrderDate)
ORDER BY strftime('%m', OrderDate) ASC;
```

</details>
