# P014 · Give each order its month label

[![Previous](../previous.svg)](🟦 01.md) [![Next](../next.svg)](🟦 03.md)  · **🟦 2 of 4**

The first order in a month might have happened after the first. The label represents the calendar month.

## SQL added or changed

```sql
SELECT OrderID, OrderDate, Total_Order_Amount,
       date(OrderDate, 'start of month') AS order_month
```

## Input to this step

**Keep only 2025 orders · 🟦 3 rows**

| 🟦 OrderID | 🟦 OrderDate | 🟦 Total_Order_Amount |
| --- | --- | --- |
| 🟦 1 | 🟦 2025-01-01 | 🟦 100 |
| 🟦 2 | 🟦 2025-01-31 | 🟦 50 |
| 🟦 3 | 🟦 2025-03-01 | 🟦 200 |

## Result · 🟦 3 rows

| 🟦 OrderID | 🟦 OrderDate | 🟦 Total_Order_Amount | 🟦 order_month |
| --- | --- | --- | --- |
| 🟦 1 | 🟦 2025-01-01 | 🟦 100 | 🟦 2025-01-01 |
| 🟦 2 | 🟦 2025-01-31 | 🟦 50 | 🟦 2025-01-01 |
| 🟦 3 | 🟦 2025-03-01 | 🟦 200 | 🟦 2025-03-01 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT OrderID, OrderDate, Total_Order_Amount,
       date(OrderDate, 'start of month') AS order_month
FROM Orders
WHERE strftime('%Y', OrderDate) = '2025'
ORDER BY OrderID;
```

</details>
