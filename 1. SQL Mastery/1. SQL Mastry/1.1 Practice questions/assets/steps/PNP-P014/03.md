# P014 · Group and count orders

[![Previous](../previous.svg)](🟦 02.md) [![Next](../next.svg)](04.md)  · **🟦 3 of 4**

The year filter means a month number identifies one month in 2025. A month with no orders does not form a group.

## SQL added or changed

```sql
SELECT date(OrderDate, 'start of month') AS order_month,
       count(*) AS orders
-- …
GROUP BY strftime('%m', OrderDate)
ORDER BY strftime('%m', OrderDate) ASC;
```

## Input to this step

**Give each order its month label · 🟦 3 rows**

| 🟦 OrderID | 🟦 OrderDate | 🟦 Total_Order_Amount | 🟦 order_month |
| --- | --- | --- | --- |
| 🟦 1 | 🟦 2025-01-01 | 🟦 100 | 🟦 2025-01-01 |
| 🟦 2 | 🟦 2025-01-31 | 🟦 50 | 🟦 2025-01-01 |
| 🟦 3 | 🟦 2025-03-01 | 🟦 200 | 🟦 2025-03-01 |

## Result · 🟦 2 rows

| 🟦 order_month | 🟦 orders |
| --- | --- |
| 🟦 2025-01-01 | 🟦 2 |
| 🟦 2025-03-01 | 🟦 1 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT date(OrderDate, 'start of month') AS order_month,
       count(*) AS orders
FROM Orders
WHERE strftime('%Y', OrderDate) = '2025'
GROUP BY strftime('%m', OrderDate)
ORDER BY strftime('%m', OrderDate) ASC;
```
