# P001 · Sort the directory

[![Previous](../previous.svg)](03.md) <kbd>Next</kbd>  · **4 of 4**

The output now has exactly one row per usable brand, alphabetically ordered from Adidas to Puma.

## SQL added or changed

```sql
ORDER BY TRIM(Brand) ASC
```

## Input to this step

**Keep each cleaned brand once · 3 rows**

| 🟦 Brand |
| --- |
| Nike |
| Adidas |
| Puma |

## Result · 3 rows

| 🟦 Brand |
| --- |
| Adidas |
| Nike |
| Puma |

<details>
<summary>Full SQLite query for this step</summary>

```sql
select distinct trim(Brand) as Brand
from Products
where trim(Brand)is not null and length(trim(Brand))>0
order by trim(Brand) asc
```

</details>
