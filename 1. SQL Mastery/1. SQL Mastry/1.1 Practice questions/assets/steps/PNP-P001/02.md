# P001 · Remove missing and empty names

Filtering removes products 🟦 3, 🟦 4 and 🟦 5. 🟦 Nike and 🟦 Adidas still appear twice.

## SQL added or changed

```sql
WHERE TRIM(Brand) IS NOT NULL AND LENGTH(TRIM(Brand)) > 0
```
