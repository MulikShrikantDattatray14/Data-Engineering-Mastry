# P001 · Clean the stored brand names

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

TRIM turns the padded 🟦 Nike entry into 🟦 Nike. A string of three spaces becomes an empty string. All eight product rows remain. Products is the only source because each directory entry comes from a product row; TRIM changes the brand text without changing which products are listed.

## SQL added or changed

```sql
TRIM(Brand) AS CleanBrand
```

## Input to this step

**🟦 Products · 🟦 8 rows**

| 🟦 ProductID | 🟦 Brand |
| --- | --- |
| 🟦 1 | 🟦 Nike |
| 🟦 2 | 🟦 &#x27; Nike &#x27; |
| 🟦 3 | 🟦 NULL |
| 🟦 4 | 🟦 &#x27;&#x27; |
| 🟦 5 | 🟦 &#x27;   &#x27; |
| 🟦 6 | 🟦 Adidas |
| 🟦 7 | 🟦 Puma |
| 🟦 8 | 🟦 Adidas |

## Result · 🟦 8 rows

| 🟦 ProductID | 🟦 Brand | 🟦 CleanBrand |
| --- | --- | --- |
| 🟦 1 | 🟦 Nike | 🟦 Nike |
| 🟦 2 | 🟦 &#x27; Nike &#x27; | 🟦 Nike |
| 🟦 3 | 🟦 NULL | 🟦 NULL |
| 🟦 4 | 🟦 &#x27;&#x27; | 🟦 &#x27;&#x27; |
| 🟦 5 | 🟦 &#x27;   &#x27; | 🟦 &#x27;&#x27; |
| 🟦 6 | 🟦 Adidas | 🟦 Adidas |
| 🟦 7 | 🟦 Puma | 🟦 Puma |
| 🟦 8 | 🟦 Adidas | 🟦 Adidas |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT ProductID, Brand, TRIM(Brand) AS CleanBrand FROM Products ORDER BY ProductID;
```

</details>
