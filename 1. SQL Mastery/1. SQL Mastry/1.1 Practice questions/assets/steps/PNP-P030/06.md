# P030 · Which rows belong in the denominator?

[![Previous](../previous.svg)](05.md) <kbd>Next</kbd>  · **6 of 6**

The scalar subquery reads every row of `customer_order_counts`. It supplies the same denominator for both result rows. This is the denominator query after the same `WITH` clause.

## SQL added or changed

```sql
SELECT
    customer_type,
    COUNT(total_orders) AS customers,
    ROUND(
        COUNT(total_orders) * 100.0
        / (SELECT COUNT(*) FROM customer_order_counts),
        2
    ) AS pct_of_customers
FROM customer_order_counts
GROUP BY customer_type
ORDER BY customer_type;
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_order_counts AS (
    SELECT
        CustomerID,
        COUNT(OrderID) AS total_orders,
        CASE
            WHEN COUNT(OrderID) = 1 THEN 'One-time'
            ELSE 'Repeat'
        END AS customer_type
    FROM Orders
    WHERE CustomerID IS NOT NULL
    GROUP BY CustomerID
)

SELECT
    customer_type,
    COUNT(total_orders) AS customers,
    ROUND(
        COUNT(total_orders) * 100.0
        / (SELECT COUNT(*) FROM customer_order_counts),
        2
    ) AS pct_of_customers
FROM customer_order_counts
GROUP BY customer_type
ORDER BY customer_type;
```
