# P030 · Calculate each customer type’s percentage and sort

[![Previous](../previous.svg)](05.md) <kbd>Next</kbd>  · **6 of 6**

The outer query counts customer rows within each type and divides by the three customers from the denominator branch. 🟦 One-time gives 🟦 2 ÷ 🟦 3 × 100 = 🟦 66.67%, and 🟦 Repeat gives 🟦 1 ÷ 🟦 3 × 100 = 🟦 33.33%. Sorting by customer_type puts 🟦 One-time first.

## SQL added or changed

```sql
SELECT
    customer_type,
    COUNT(total_orders) AS customers,
    ROUND(
        COUNT(total_orders) * 100.0
        / (SELECT COUNT(*) FROM customer_order_counts),
        2
    ) AS pct_of_customers
FROM customer_order_counts
GROUP BY customer_type
ORDER BY customer_type;
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_order_counts AS (
    SELECT
        CustomerID,
        COUNT(OrderID) AS total_orders,
        CASE
            WHEN COUNT(OrderID) = 1 THEN 'One-time'
            ELSE 'Repeat'
        END AS customer_type
    FROM Orders
    WHERE CustomerID IS NOT NULL
    GROUP BY CustomerID
)

SELECT
    customer_type,
    COUNT(total_orders) AS customers,
    ROUND(
        COUNT(total_orders) * 100.0
        / (SELECT COUNT(*) FROM customer_order_counts),
        2
    ) AS pct_of_customers
FROM customer_order_counts
GROUP BY customer_type
ORDER BY customer_type;
```
