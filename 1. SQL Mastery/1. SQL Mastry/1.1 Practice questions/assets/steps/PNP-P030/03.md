# P030 · Which label does the CTE give each customer?

[![Previous](../previous.svg)](🟦 02.md) [![Next](../next.svg)](04.md)  · **3 of 6**

The `CASE` expression uses each group’s order count. A value of **🟦 1** gives `🟦 One-time`. Two or more gives `🟦 Repeat`. The final learner query calculates the count and the label in the same CTE.

## SQL added or changed

```sql
WITH customer_order_counts AS (
    SELECT
        CustomerID,
        COUNT(OrderID) AS total_orders,
        CASE
            WHEN COUNT(OrderID) = 1 THEN 'One-time'
            ELSE 'Repeat'
        END AS customer_type
-- …
)
SELECT CustomerID, total_orders, customer_type
FROM customer_order_counts
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_order_counts AS (
    SELECT
        CustomerID,
        COUNT(OrderID) AS total_orders,
        CASE
            WHEN COUNT(OrderID) = 1 THEN 'One-time'
            ELSE 'Repeat'
        END AS customer_type
    FROM Orders
    WHERE CustomerID IS NOT NULL
    GROUP BY CustomerID
)
SELECT CustomerID, total_orders, customer_type
FROM customer_order_counts
ORDER BY CustomerID;
```
