# P030 · How many orders did each customer place?

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 6**

Group the four eligible orders by 🟦 `CustomerID`. Within each group, count its order IDs. The result has one row for each of the three identified customers.

## SQL added or changed

```sql
SELECT CustomerID, COUNT(OrderID) AS total_orders
-- …
GROUP BY CustomerID
ORDER BY CustomerID;
```

## Input to this step

**Which orders supply the report? · 🟦 4 rows**

| 🟦 OrderID | 🟦 CustomerID |
| --- | --- |
| 🟦 1 | 🟦 10 |
| 🟦 2 | 🟦 20 |
| 🟦 3 | 🟦 20 |
| 🟦 4 | 🟦 30 |

## Result · 🟦 3 rows

| 🟦 CustomerID | 🟦 total_orders |
| --- | --- |
| 🟦 10 | 🟦 1 |
| 🟦 20 | 🟦 2 |
| 🟦 30 | 🟦 1 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT CustomerID, COUNT(OrderID) AS total_orders
FROM Orders
WHERE CustomerID IS NOT NULL
GROUP BY CustomerID
ORDER BY CustomerID;
```

</details>
