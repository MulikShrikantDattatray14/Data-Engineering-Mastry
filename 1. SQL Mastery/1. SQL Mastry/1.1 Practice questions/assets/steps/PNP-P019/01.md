# P019 · Attach the product name to each order line

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

The task covers products that appear on sale lines. Each detail row supplies the product ID, order ID and quantity needed to count sales.

## SQL added or changed

```sql
SELECT O.OrderDetailID, O.OrderID, O.ProductID, P.Product, O.Quantity
FROM OrderDetails AS O
LEFT JOIN Products AS P ON O.ProductID = P.ProductID
ORDER BY O.OrderDetailID;
```
