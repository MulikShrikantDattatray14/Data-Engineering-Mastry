# P027 · Why do SUM and AVG read only known amounts?

[![Previous](../previous.svg)](05.md) [![Next](../next.svg)](07.md)  · **6 of 8**

The ten amounts of 100 sum to 1000 and average 100. The metrics use one value per order.

## SQL added or changed

```sql
SELECT
    COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown') AS state,
    COUNT(DISTINCT Orders.CustomerID) AS customers,
    COUNT(Orders.OrderID) AS orders,
    SUM(Orders.Total_Order_Amount) AS order_value,
    AVG(Orders.Total_Order_Amount) AS avg_order_value
FROM Orders
LEFT JOIN Customers ON Customers.CustomerID = Orders.CustomerID
```
