# P027 · Why use HAVING for the 10-order minimum?

[![Previous](../previous.svg)](06.md) [![Next](../next.svg)](08.md)  · **7 of 8**

Goa has nine orders and drops out. The four ten-order groups survive, including Kerala because eligibility counts order IDs even when amounts are missing.

## SQL added or changed

```sql
HAVING COUNT(Orders.OrderID) >= 10;
```

<summary>Full SQLite query for this step</summary>

```sql
SELECT
    COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown') AS state,
    COUNT(DISTINCT Orders.CustomerID) AS customers,
    COUNT(Orders.OrderID) AS orders,
    SUM(Orders.Total_Order_Amount) AS order_value,
    AVG(Orders.Total_Order_Amount) AS avg_order_value
FROM Orders
LEFT JOIN Customers ON Customers.CustomerID = Orders.CustomerID
GROUP BY COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown')
HAVING COUNT(Orders.OrderID) >= 10;
```
