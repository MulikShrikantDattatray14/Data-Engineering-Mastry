# P027 · Why label the state before GROUP BY?

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 8**

The saved expression normalizes a missing or blank state to Unknown. In this sample, all ten state labels remain Karnataka.

## SQL added or changed

```sql
SELECT Orders.OrderID, Orders.CustomerID, COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown') AS state, Orders.Total_Order_Amount FROM Orders LEFT JOIN Customers ON Customers.CustomerID = Orders.CustomerID ORDER BY Orders.OrderID;
```
