# P027 · Why LEFT JOIN Customers?

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 8**

Both buyers have a matching customer row, so all ten purchases acquire the state Karnataka.

## SQL added or changed

```sql
SELECT o.OrderID, o.CustomerID AS ordered_by, o.Total_Order_Amount,
       c.CustomerID AS matched_customer, c.State
FROM Orders AS o
LEFT JOIN Customers AS c ON c.CustomerID = o.CustomerID
ORDER BY o.OrderID;
```
