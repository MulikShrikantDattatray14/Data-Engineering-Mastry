# P027 · Why count buyers and orders separately?

[![Previous](../previous.svg)](04.md) [![Next](../next.svg)](06.md)  · **5 of 8**

Two distinct customer IDs occur across ten orders: each buyer placed five.

## SQL added or changed

```sql
SELECT COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown') AS state, COUNT(DISTINCT Orders.CustomerID) AS customers, COUNT(Orders.OrderID) AS orders FROM Orders LEFT JOIN Customers ON Customers.CustomerID = Orders.CustomerID
```
