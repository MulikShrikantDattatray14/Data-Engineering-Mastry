# P027 · Why group by the displayed state?

[![Previous](../previous.svg)](03.md) [![Next](../next.svg)](05.md)  · **4 of 8**

All ten labelled orders share the same state and become one group.

## SQL added or changed

```sql
SELECT COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown') AS state, COUNT(*) AS group_rows FROM Orders LEFT JOIN Customers ON Customers.CustomerID = Orders.CustomerID
GROUP BY COALESCE(NULLIF(TRIM(Customers.State), ''), 'Unknown');
```
