# PNP P032 · Products priced above their category average · Why attach the same benchmark to each product row?

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 5**

The outer query still starts from required_table, so its three rows remain one per Beverages product. The scalar subquery reads the one-row avg_sale_price CTE and repeats 200.0 beside each candidate; no join is needed because the benchmark is a single scalar for the selected category.

## SQL added or changed

```sql
(SELECT category_avg_price FROM avg_sale_price) AS category_avg_price
```

<summary>Full SQLite query for this step</summary>

```sql
WITH required_table AS (
SELECT
    ProductID,
    Product,
    CategoryID,
    Sale_Price
FROM Products
WHERE CategoryID = 5009
),
avg_sale_price AS (
SELECT
    AVG(Sale_Price) AS category_avg_price
FROM required_table
)
SELECT ProductID, Product, CategoryID, Sale_Price,
       (SELECT category_avg_price FROM avg_sale_price) AS category_avg_price
FROM required_table
ORDER BY ProductID;
```
