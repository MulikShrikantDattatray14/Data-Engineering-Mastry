# PNP P032 · Products priced above their category average · Why does Products supply the rows for this review?

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 5**

Start from 🟦 Products because the report needs one candidate row for each catalogue product. The saved query's first CTE filters that source to Beverages (CategoryID 5009), leaving Tea, Coffee and Juice; Bread is outside the requested category and is removed before the benchmark is calculated.

## SQL added or changed

```sql
required_table AS (
    SELECT ProductID, Product, CategoryID, Sale_Price
    FROM Products
    WHERE CategoryID = 5009
)
```

<summary>Full SQLite query for this step</summary>

```sql
WITH required_table AS (
SELECT
    ProductID,
    Product,
    CategoryID,
    Sale_Price
FROM Products
WHERE CategoryID = 5009
)
SELECT ProductID, Product, CategoryID, Sale_Price
FROM required_table
ORDER BY ProductID;
```
