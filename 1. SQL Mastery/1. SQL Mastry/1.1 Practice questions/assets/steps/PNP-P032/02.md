# PNP P032 · Products priced above their category average · Why does the average CTE return one row?

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 5**

The average is calculated from the three eligible Beverages prices, including products that will not qualify. One row in avg_sale_price represents the single category-wide benchmark (100 + 200 + 300) ÷ 3 = 200.00; it is not one row per product.

## SQL added or changed

```sql
avg_sale_price AS (
    SELECT AVG(Sale_Price) AS category_avg_price
    FROM required_table
)
```

## Input to this step

**Why does Products supply the rows for this review? · 3 rows**

| 🟦 ProductID | 🟦 Product | 🟦 CategoryID | 🟦 Sale_Price |
| --- | --- | --- | --- |
| 🟦 1 | 🟦 Tea | 🟦 5009 | 🟦 100 |
| 🟦 2 | 🟦 Coffee | 🟦 5009 | 🟦 200 |
| 🟦 3 | 🟦 Juice | 🟦 5009 | 🟦 300 |

## Result · 1 row

| 🟦 category_avg_price |
| --- |
| 🟦 200.0 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
WITH required_table AS (
SELECT
    ProductID,
    Product,
    CategoryID,
    Sale_Price
FROM Products
WHERE CategoryID = 5009
),
avg_sale_price AS (
SELECT
    AVG(Sale_Price) AS category_avg_price
FROM required_table
)
SELECT category_avg_price
FROM avg_sale_price;
```

</details>
