<summary>Full SQLite query for this step</summary>

```sql
WITH required_table AS (
    SELECT
        ProductID,
        Product,
        CategoryID,
        Sale_Price
    FROM Products
    WHERE CategoryID = 5009
),

avg_sale_price AS (
    SELECT
        AVG(Sale_Price) AS category_avg_price
    FROM required_table
)

SELECT
    ProductID,
    Product,
    CategoryID,
    Sale_Price,
    (SELECT category_avg_price FROM avg_sale_price) AS category_avg_price
FROM required_table
WHERE Sale_Price > (
    SELECT category_avg_price
    FROM avg_sale_price
)
ORDER BY
    CategoryID ASC,
    Sale_Price DESC;
```
