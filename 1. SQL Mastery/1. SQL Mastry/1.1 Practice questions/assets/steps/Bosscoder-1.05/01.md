# Bosscoder-1.05 · Start with one row per set of side lengths

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

FROM TRIANGLES supplies one row per candidate triangle because the output needs one classification for each input triple. All three side lengths are already on that row, so the single source is sufficient; no join is needed. Read TRIANGLES and calculate the label in SELECT.

## SQL added or changed

```sql
SELECT A, B, C FROM TRIANGLES;
```
