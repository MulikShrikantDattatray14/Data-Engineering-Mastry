# Bosscoder-1.05 · Check the equal pair and return the requested column

[![Previous](../previous.svg)](03.md) <kbd>Next</kbd>  · **4 of 4**

Your final branch tests each possible equal pair while requiring the third side to differ. All possible classifications are covered for non-NULL side lengths.

## SQL added or changed

```sql
SELECT
-- …
        WHEN (A + B <= C) OR (A + C <= B) OR (B + C <= A)
            THEN 'Not A Triangle'
        WHEN A = B AND B = C AND C = A
            THEN 'Equilateral'
        WHEN A != B AND B != C AND C != A
            THEN 'Scalene'
        WHEN (A = B AND B != C)
          OR (B = C AND C != A)
          OR (C = A AND A != B)
            THEN 'Isosceles'
    END AS TriangleType
```
