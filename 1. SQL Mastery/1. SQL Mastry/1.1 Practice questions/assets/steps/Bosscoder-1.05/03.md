# Bosscoder-1.05 · Check all equal, then all different

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 4**

For valid rows, all equal sides produce Equilateral. All three pairwise inequalities produce Scalene. A CASE stops at its first true branch.

## SQL added or changed

```sql
CASE
           WHEN A+B <= C OR A+C <= B OR B+C <= A THEN 'Not A Triangle'
           WHEN A=B AND B=C AND C=A THEN 'Equilateral'
           WHEN A!=B AND B!=C AND C!=A THEN 'Scalene'
           ELSE 'Continue'
       END AS check_result
```
