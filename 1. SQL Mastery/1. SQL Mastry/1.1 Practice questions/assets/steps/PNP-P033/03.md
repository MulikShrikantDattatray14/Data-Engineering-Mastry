# PNP P033 · Products that have never been ordered · Why keep only rows with no order-detail match?

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 4**

Filter the joined result with OD.OrderDetailID IS NULL. OrderDetailID is the non-null primary key of an actual order-detail row, so NULL identifies a product for which the LEFT JOIN found no order row. Pen is removed because row 10 matched; Cup survives because its right-side key is NULL. A product with multiple matches would have all of its repeated joined rows removed.

## SQL added or changed

```sql
WHERE OD.OrderDetailID IS NULL
```

<summary>Full SQLite query for this step</summary>

```sql
SELECT P.ProductID, P.Product, P.Brand, P.CategoryID, P.Sale_Price
FROM Products AS P
LEFT JOIN OrderDetails AS OD
    ON P.ProductID = OD.ProductID
WHERE OD.OrderDetailID IS NULL;
```
