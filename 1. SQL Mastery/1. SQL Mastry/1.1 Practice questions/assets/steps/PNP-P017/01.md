# P017 · Calculate the reporting window

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

The CTE reads order dates to produce one pair of bounds. The main query starts from individual orders because it needs one result per qualifying order. Subtract six days from the latest date to get seven inclusive calendar dates.

## SQL added or changed

```sql
WITH reporting_window AS (
    SELECT
        date(MAX(OrderDate)) AS latest_order_date,
        date(MAX(OrderDate), '-6 days') AS window_start
    FROM Orders
)
SELECT latest_order_date, window_start FROM reporting_window;
```
