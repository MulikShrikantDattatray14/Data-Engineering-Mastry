# P017 · Calculate the reporting window

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 5**

Orders supplies OrderDate to the reporting_window CTE; its single row represents the latest date and inclusive window bounds, not report orders. The outer query starts from individual Orders rows because it needs one result per qualifying order. Subtract six days from the latest date to get seven inclusive calendar dates.

## SQL added or changed

```sql
WITH reporting_window AS (
    SELECT
        date(MAX(OrderDate)) AS latest_order_date,
        date(MAX(OrderDate), '-6 days') AS window_start
    FROM Orders
)
SELECT latest_order_date, window_start FROM reporting_window;
```
