# P017 · Keep orders within the window

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 4**

Each subquery returns one value and BETWEEN includes both endpoints. This query assumes ISO date-only text (YYYY-MM-DD), so the order date can be compared directly. With timestamps, use the earlier timestamp-safe version above.

## SQL added or changed

```sql
WITH reporting_window AS (
    SELECT
        date(MAX(OrderDate)) AS latest_order_date,
        date(MAX(OrderDate), '-6 days') AS window_start
    FROM Orders
)
-- …
WHERE (o.OrderDate) BETWEEN
    (SELECT window_start FROM reporting_window)
    AND
    (SELECT latest_order_date FROM reporting_window)
```

<summary>Full SQLite query for this step</summary>

```sql
WITH reporting_window AS (
    SELECT
        date(MAX(OrderDate)) AS latest_order_date,
        date(MAX(OrderDate), '-6 days') AS window_start
    FROM Orders
)
SELECT o.OrderID, o.OrderDate, p.PaymentType, s.CompanyName
FROM Orders AS o
LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID
LEFT JOIN Shippers AS s ON o.ShipperID = s.ShipperID
WHERE (o.OrderDate) BETWEEN
    (SELECT window_start FROM reporting_window)
    AND
    (SELECT latest_order_date FROM reporting_window)
ORDER BY o.OrderID;
```
