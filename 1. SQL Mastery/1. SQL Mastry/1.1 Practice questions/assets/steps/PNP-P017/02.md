# P017 · Look up each order’s payment type

[![Previous](../previous.svg)](🟪 01.md) [![Next](../next.svg)](🟦 03.md)  · **🟦 2 of 5**

Orders supplies the purchase rows and both lookup IDs. Orders 🟪 1 and 🟦 2 match 🟩 UPI. LEFT JOIN also keeps order 🟦 3, whose payment ID is 🟪 NULL.

## SQL added or changed

```sql
FROM Orders AS o
LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID
```

| --- | --- |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT o.OrderID, o.OrderDate, o.PaymentID, o.ShipperID,
       p.PaymentID AS matched_payment_id, p.PaymentType
FROM Orders AS o
LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID
ORDER BY o.OrderID;
```
