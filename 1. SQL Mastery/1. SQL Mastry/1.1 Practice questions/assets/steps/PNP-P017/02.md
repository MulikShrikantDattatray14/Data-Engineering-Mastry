# P017 · Join the lookup tables

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 4**

The report needs an entry for each order in the date window, including orders with missing labels. Each order already carries both lookup IDs.

## SQL added or changed

```sql
SELECT o.OrderID, o.OrderDate, p.PaymentType, s.CompanyName
FROM Orders AS o
LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID
LEFT JOIN Shippers AS s ON o.ShipperID = s.ShipperID
ORDER BY o.OrderID;
```
