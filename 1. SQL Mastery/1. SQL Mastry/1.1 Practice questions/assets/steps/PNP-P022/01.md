# P022 · Define and check one row per order

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 2**

Several detail rows can belong to one order. Count the lines, count each distinct product once, and add the quantities. All three metrics come from OrderDetails.

## SQL added or changed

```sql
select OrderID,count(OrderID)  as line_items, count(distinct(ProductID)) as distinct_products,
sum(Quantity) as total_units
from OrderDetails
group by OrderID
order by OrderID;
```
