# P015 · Group the rows and count matched products

[![Previous](../previous.svg)](🟦 01.md) [![Next](../next.svg)](03.md)  · **🟪 2 of 3**

COUNT(ProductID) counts non-🟩 NULL product IDs. COUNT(*) would count 🟦 Toys' unmatched join row and incorrectly report one product.

## SQL added or changed

```sql
SELECT c.CategoryID, c.CategoryName, COUNT(p.ProductID) AS product_count
-- …
GROUP BY c.CategoryID
ORDER BY c.CategoryID;
```

## Input to this step

**Attach matching products to every category · 3 rows**

| 🟦 CategoryID | 🟦 CategoryName | 🟩 ProductID |
| --- | --- | --- |
| 🟦 1 | 🟦 Snacks | 🟩 10 |
| 🟦 1 | 🟦 Snacks | 🟩 11 |
| 🟦 2 | 🟦 Toys | 🟩 NULL |

## Result · 🟪 2 rows

| 🟦 CategoryID | 🟦 CategoryName | 🟩 product_count |
| --- | --- | --- |
| 🟦 1 | 🟦 Snacks | 🟩 2 |
| 🟦 2 | 🟦 Toys | 🟩 0 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT c.CategoryID, c.CategoryName, COUNT(p.ProductID) AS product_count
FROM Category AS c
LEFT JOIN Products AS p ON c.CategoryID = p.CategoryID
GROUP BY c.CategoryID
ORDER BY c.CategoryID;
```

</details>
