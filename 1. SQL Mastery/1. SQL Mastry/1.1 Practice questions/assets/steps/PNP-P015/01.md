# P015 · Attach matching products to every category

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

Snacks contributes two matched rows. Toys gets one unmatched row. Category supplies the requested all-category population, so it must start the report; adding Products with LEFT JOIN counts matches while preserving Toys.

## SQL added or changed

```sql
SELECT c.CategoryID, c.CategoryName, p.ProductID
FROM Category AS c
LEFT JOIN Products AS p ON c.CategoryID = p.CategoryID
ORDER BY c.CategoryID, p.ProductID;
```

**🟦 Category · 2 rows**

| --- | --- |
| 1 | Snacks |
| 2 | Toys |

**🟩 Products · 2 rows**

| 🟩 ProductID | 🟩 CategoryID |
