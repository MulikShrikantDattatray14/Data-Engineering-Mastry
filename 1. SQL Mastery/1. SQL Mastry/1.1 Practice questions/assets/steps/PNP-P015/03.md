# P015 · Sort the report

[![Previous](../previous.svg)](02.md) <kbd>Next</kbd>  · **3 of 3**

This puts empty categories first and resolves ties consistently.

## SQL added or changed

```sql
ORDER BY COUNT(p.ProductID) ASC, c.CategoryID ASC;
```

| --- | --- | --- |
| 🟦 2 | 🟦 Toys | 🟩 0 |
| 🟦 1 | 🟦 Snacks | 🟩 2 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT c.CategoryID, c.CategoryName, COUNT(p.ProductID) AS product_count
FROM Category AS c
LEFT JOIN Products AS p ON c.CategoryID = p.CategoryID
GROUP BY c.CategoryID
ORDER BY COUNT(p.ProductID) ASC, c.CategoryID ASC;
```

</details>
