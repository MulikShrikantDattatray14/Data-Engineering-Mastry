# P021 · Build one row per customer ID that placed an order

<kbd>Previous</kbd> [![Next](../next.svg)](🟪 02.md)  · **🟪 1 of 🟪 3**

These are the candidate counts before the cutoff. The learner's COALESCE also supplies the fallback when a matched customer's name has a NULL part. The CTE starts from Orders because only customer IDs with at least one purchase are candidates for the ranking; its one row per customer summarizes those orders before the outer query.

## SQL added or changed

```sql
WITH customer_counts AS (
    SELECT
        o.CustomerID,
        COALESCE(c.FirstName || ' ' || c.LastName, 'Unknown customer') AS customer_name,
        COUNT(o.OrderID) AS orders_placed
    FROM Orders AS o
    LEFT JOIN Customers AS c ON o.CustomerID = c.CustomerID
    GROUP BY o.CustomerID, c.FirstName, c.LastName
)
SELECT * FROM customer_counts
ORDER BY orders_placed DESC, CustomerID ASC;
```
