# P021 · Keep everyone who meets the cutoff and sort

[![Previous](../previous.svg)](02.md) <kbd>Next</kbd>  · **3 of 3**

The >= comparison includes everyone tied at the cutoff. CustomerID controls the display order of ties.

## SQL added or changed

```sql
SELECT CustomerID, customer_name, orders_placed
FROM customer_counts
WHERE orders_placed >= COALESCE(
    (
        SELECT orders_placed
        FROM customer_counts
        ORDER BY orders_placed DESC
        LIMIT 1 OFFSET 4
    ),
    0
)
ORDER BY orders_placed DESC, CustomerID ASC;
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_counts AS (
    SELECT
        o.CustomerID,
        COALESCE(c.FirstName || ' ' || c.LastName, 'Unknown customer') AS customer_name,
        COUNT(o.OrderID) AS orders_placed
    FROM Orders AS o
    LEFT JOIN Customers AS c ON o.CustomerID = c.CustomerID
    GROUP BY o.CustomerID, c.FirstName, c.LastName
)
SELECT CustomerID, customer_name, orders_placed
FROM customer_counts
WHERE orders_placed >= COALESCE(
    (
        SELECT orders_placed
        FROM customer_counts
        ORDER BY orders_placed DESC
        LIMIT 1 OFFSET 4
    ),
    0
)
ORDER BY orders_placed DESC, CustomerID ASC;
```
