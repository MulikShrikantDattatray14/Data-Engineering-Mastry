# Bosscoder-1.03 · Combine the rules

[![Previous](../previous.svg)](04.md) <kbd>Next</kbd>  · **🟦 5 of 🟦 5**

Use CASE to check 🟦 Root first, 🟦 Leaf second, then return 🟦 Inner for the remaining nodes. Apply ORDER BY N to produce the required ordering.

## SQL added or changed

```sql
SELECT N,
       CASE
           WHEN P IS NULL THEN 'Root'
           WHEN N NOT IN (
               SELECT P
               FROM BST
               WHERE P IS NOT NULL
           ) THEN 'Leaf'
           ELSE 'Inner'
       END AS NodeType
FROM BST
```
