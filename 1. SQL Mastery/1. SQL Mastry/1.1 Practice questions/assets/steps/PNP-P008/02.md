# P008 · Add the Mid range

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 3**

Mid includes fractional prices below 700.

## SQL added or changed

```sql
WHEN Sale_Price >= 200 AND Sale_Price < 700 THEN 'Mid'
```

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT ProductID, Product, Sale_Price,
       CASE
           WHEN Sale_Price < 200 THEN 'Budget'
           WHEN Sale_Price >= 200 AND Sale_Price < 700 THEN 'Mid'
       END AS price_band
FROM Products
ORDER BY ProductID ASC;
```
