# P008 · Label prices below 200

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

Budget ends immediately before 200. Products is the only source because its ID, name and Sale_Price supply the product and its price-band label; no lookup is needed.

## SQL added or changed

```sql
SELECT ProductID, Product, Sale_Price,
       CASE
           WHEN Sale_Price < 200 THEN 'Budget'
       END AS price_band
FROM Products
ORDER BY ProductID ASC;
```
