# P013 · Group and count the customer rows

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

The five 🟦 Karnataka customers form one group; 🟦 Maharashtra forms another with just one customer. Customers is the only source because each customer row already carries State; grouping by that field needs no lookup.

## SQL added or changed

```sql
SELECT State, COUNT(CustomerID) AS customer_count FROM Customers GROUP BY State ORDER BY State;
```

## Input to this step

**🟦 Customers · 🟦 6 rows**

| 🟦 CustomerID | 🟦 State |
| --- | --- |
| 🟦 1 | 🟦 Karnataka |
| 🟦 2 | 🟦 Karnataka |
| 🟦 3 | 🟦 Karnataka |
| 🟦 4 | 🟦 Karnataka |
| 🟦 5 | 🟦 Karnataka |
| 🟦 6 | 🟦 Maharashtra |

## Result · 🟦 2 rows

| 🟦 State | 🟦 customer_count |
| --- | --- |
| 🟦 Karnataka | 🟦 5 |
| 🟦 Maharashtra | 🟦 1 |
