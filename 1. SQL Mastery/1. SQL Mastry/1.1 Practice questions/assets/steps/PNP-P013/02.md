# P013 · Filter whole groups and label the missing state

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 3**

The threshold is a condition on a whole group. Filtering missing states in WHERE would remove their rows before they can contribute to the Unknown group.

## SQL added or changed

```sql
select 
CASE
    WHEN State IS NOT NULL THEN State
    ELSE 'Unknown'
END AS State

, count(CustomerID) as customer_count
from Customers
group by state
having count(CustomerID)>=5
ORDER BY State ASC
```

## Input to this step

**Group and count the customer rows · 2 rows**

| 🟦 State | 🟦 customer_count |
| --- | --- |
| 🟦 Karnataka | 🟦 5 |
| 🟦 Maharashtra | 🟦 1 |
