# P013 · Apply the requested sort

[![Previous](../previous.svg)](02.md) <kbd>Next</kbd>  · **3 of 3**

Delhi has the highest count. 🟦 Karnataka and Unknown tie, so 🟦 Karnataka comes first alphabetically. The preview happened to display the same order on these rows.

## SQL added or changed

```sql
order by  count(CustomerID) desc, State asc
```

## Input to this step

**Filter whole groups and label the missing state · 1 row**

| 🟦 State | 🟦 customer_count |
| --- | --- |
| 🟦 Karnataka | 🟦 5 |

## Result · 1 row

| 🟦 State | 🟦 customer_count |
| --- | --- |
| 🟦 Karnataka | 🟦 5 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
select 
CASE
    WHEN State IS NOT NULL THEN State
    ELSE 'Unknown'
END AS State

, count(CustomerID) as customer_count
from Customers
group by state
having count(CustomerID)>=5
order by  count(CustomerID) desc, State asc
```

</details>
