# P026 · Why count orders once but add every unit?

[![Previous](../previous.svg)](06.md) [![Next](../next.svg)](08.md)  · **7 of 8**

Count different order IDs only once per category but sum the quantity and extended list price on every line. The unmatched category has zero units. The purple value uses OrderDetails.Quantity and Products.Sale_Price.

<summary>Full SQLite query for this step</summary>

```sql
SELECT
    CASE
        WHEN c.CategoryID IS NULL AND p.ProductID IS NULL
            THEN 'Unknown product'
        WHEN c.CategoryID IS NULL AND p.ProductID IS NOT NULL
            THEN 'Unmapped'
        WHEN c.CategoryID IS NOT NULL
            THEN c.CategoryName
    END AS category_name,
    COUNT(DISTINCT od.OrderID) AS orders,
    COALESCE(SUM(od.Quantity), 0) AS units_sold,
    CASE
        WHEN COUNT(od.OrderDetailID) = 0 THEN 0
        ELSE SUM(p.Sale_Price * od.Quantity)
    END AS list_price_value
FROM OrderDetails AS od
LEFT JOIN Products AS p
    ON od.ProductID = p.ProductID
FULL OUTER JOIN Category AS c
    ON c.CategoryID = p.CategoryID
GROUP BY c.CategoryID, category_name;
```
