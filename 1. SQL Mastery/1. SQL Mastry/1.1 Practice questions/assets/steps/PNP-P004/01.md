# P004 · Assign the issue to each customer

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 2**

Each customer needs the first applicable label. Customers is the only source because the task assigns an email issue to each person and both identity and Email are already on each customer row.

## SQL added or changed

```sql
SELECT CustomerID, FirstName, LastName, Email,
       (CASE
          WHEN Email IS NULL OR LENGTH(Email) == 0 THEN 'Missing'
          WHEN Email LIKE '% %' THEN 'Contains a space'
          WHEN Email NOT LIKE '%_@_%._%' THEN 'Not in name@domain.tld form'
        END) AS issue
FROM Customers
ORDER BY CustomerID ASC;
```
