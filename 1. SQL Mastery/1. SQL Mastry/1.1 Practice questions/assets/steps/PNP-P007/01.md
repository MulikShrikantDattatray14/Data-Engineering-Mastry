# P007 · Calculate the discount amount

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

Every product must remain in the output. Products is the only source because both prices and product identity are on the same catalogue row; each row can be evaluated independently.

## SQL added or changed

```sql
select 
ProductID,
Product,
 Market_Price,
Sale_Price,
(
case
when Market_Price is null or Market_Price =0 then Null
else (Market_Price - Sale_Price)
end 
) as discount_amount
from Products
order by ProductID
```
