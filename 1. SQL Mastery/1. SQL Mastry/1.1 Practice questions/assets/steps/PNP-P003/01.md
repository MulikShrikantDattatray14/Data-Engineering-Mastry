# P003 · Check the displayed value and the matching value

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 🟦 3**

Case-insensitive matching can coexist with original display case. Customers is the only source because the report returns customer rows and City already lives on each customer; trim and case-normalize for matching without another lookup.

## SQL added or changed

```sql
SELECT CustomerID, City AS OriginalCity, TRIM(City) AS City,
       TRIM(LOWER(City)) AS MatchCity
FROM Customers
ORDER BY CustomerID;
```
