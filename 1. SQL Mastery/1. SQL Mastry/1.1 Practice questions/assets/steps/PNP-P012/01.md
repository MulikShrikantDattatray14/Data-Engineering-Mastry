# P012 · Get one row per category

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

Each input row is a product and each output row is a category. All the fields come from Products, so this query reads a single table.

## SQL added or changed

```sql
SELECT CategoryID, COUNT(ProductID) AS products
FROM Products
GROUP BY CategoryID
ORDER BY CategoryID;
```
