# P034 · Calculate shares and sort

[![Previous](../previous.svg)](05.md) <kbd>Next</kbd> · **6 of 6**

The exact learner query calculates units × 100 / 14, rounds to two decimals, returns 0.00 for a zero denominator and sorts descending by units. Alpha and Beta tie, so their relative order is not guaranteed.

**SQL added**
```sql
ROUND(units_supplied * 100.0 / total_quantity, 2)
ORDER BY units_supplied DESC
```
**Result · 4 rows**

| SupplierID | CompanyName | units_supplied | pct_of_units |
|---:|---|---:|---:|
| 1 | Alpha | 5 | 35.71 |
| 2 | Beta | 5 | 35.71 |
| 99 | Unknown supplier | 4 | 28.57 |
| 3 | Gamma | 0 | 0.00 |

Reconciliation: 5 + 5 + 4 + 0 = 14. Rounded shares sum to 99.99%; unrounded shares sum to 100%.


<details><summary>Exact saved learner SQLite query · final cumulative SQL</summary>

```sql
WITH sum_quantity AS (
    SELECT
        COALESCE(SUM(Quantity), 0) AS total_quantity
    FROM OrderDetails
)

SELECT
    COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
    COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName,
    COALESCE(SUM(OD.Quantity), 0) AS units_supplied,
    CASE
        WHEN (SELECT total_quantity FROM sum_quantity) = 0
            THEN 0.00
        ELSE ROUND(
            COALESCE(SUM(OD.Quantity), 0) * 100.0 /
            (SELECT total_quantity FROM sum_quantity),
            2
        )
    END AS pct_of_units
FROM Suppliers AS S
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
GROUP BY
    COALESCE(S.SupplierID, OD.SupplierID),
    COALESCE(S.CompanyName, 'Unknown supplier')
ORDER BY
    units_supplied DESC;
```
