# P034 · Prepare the independent denominator

[![Previous](../previous.svg)](04.md) [![Next](../next.svg)](06.md) · **5 of 6**

The sum_quantity CTE is an independent one-row aggregate over every OrderDetails row. Its row represents the grand total, not a supplier. The outer query still starts with four supplier groups; a scalar subquery attaches the same denominator to each. This branch can be prepared independently.

**SQL added**
```sql
WITH sum_quantity AS (
 SELECT COALESCE(SUM(Quantity), 0) AS total_quantity
 FROM OrderDetails
)
```
**CTE result · 1 row:** total_quantity = 2 + 3 + 5 + 4 = 14.

**Outer grouped rows with denominator · 4 rows**

| SupplierID | CompanyName | units_supplied | total_quantity |
|---:|---|---:|---:|
| 1 | Alpha | 5 | 14 |
| 2 | Beta | 5 | 14 |
| 99 | Unknown supplier | 4 | 14 |
| 3 | Gamma | 0 | 14 |
