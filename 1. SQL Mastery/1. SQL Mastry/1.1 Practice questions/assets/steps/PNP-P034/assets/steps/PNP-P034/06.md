# P034 · Calculate each share and sort

[![Previous](../previous.svg)](05.md) <kbd>Next</kbd> · **6 of 6**

The exact saved learner query calculates each supplier group's units × 100 ÷ 14 and rounds to two decimals. CASE returns 0.00 when the denominator is zero. Descending units places 5-unit groups first; Alpha and Beta tie, so their relative order is intentionally not asserted.

## SQL added or changed

```sql
CASE
    WHEN (SELECT total_quantity FROM sum_quantity) = 0 THEN 0.00
    ELSE ROUND(
        COALESCE(SUM(OD.Quantity), 0) * 100.0 /
        (SELECT total_quantity FROM sum_quantity), 2
    )
END AS pct_of_units
ORDER BY units_supplied DESC
```

## Input to this step

Four supplier groups, each paired with 🟦 total_quantity = 14.

## Result · 4 rows

| 🟪 SupplierID | 🟪 CompanyName | 🟦 units_supplied | 🟪 pct_of_units |
|---:|---|---:|---:|
| 🟪 1 | 🟩 Alpha | 🟦 5 | 🟪 35.71 |
| 🟪 2 | 🟩 Beta | 🟦 5 | 🟪 35.71 |
| 🟪 99 | 🟪 Unknown supplier | 🟦 4 | 🟪 28.57 |
| 🟩 3 | 🟩 Gamma | 🟦 0 | 🟪 0.00 |

Shares: 5/14×100 = 35.71%; 5/14×100 = 35.71%; 4/14×100 = 28.57%; 0/14×100 = 0.00%. The units reconcile: 5 + 5 + 4 + 0 = 14. Rounded shares total 99.99% due to rounding; the unrounded shares total 100%.

<details><summary>Exact saved learner SQLite query</summary>

```sql
WITH sum_quantity AS (
    SELECT
        COALESCE(SUM(Quantity), 0) AS total_quantity
    FROM OrderDetails
)

SELECT
    COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
    COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName,
    COALESCE(SUM(OD.Quantity), 0) AS units_supplied,
    CASE
        WHEN (SELECT total_quantity FROM sum_quantity) = 0
            THEN 0.00
        ELSE ROUND(
            COALESCE(SUM(OD.Quantity), 0) * 100.0 /
            (SELECT total_quantity FROM sum_quantity),
            2
        )
    END AS pct_of_units
FROM Suppliers AS S
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
GROUP BY
    COALESCE(S.SupplierID, OD.SupplierID),
    COALESCE(S.CompanyName, 'Unknown supplier')
ORDER BY
    units_supplied DESC;
```

</details>
