# P034 · Aggregate detail quantities by resolved supplier

[![Previous](../previous.svg)](03.md) [![Next](../next.svg)](05.md) · **4 of 6**

Group by the resolved identity and label. Alpha's two detail rows contribute 2 + 3 = 5; Beta contributes 5; unknown ID 99 contributes 4. Gamma's preserved row has NULL Quantity, so SUM is NULL and the learner's outer COALESCE displays zero. Five detail/join rows become four supplier groups.

## SQL added or changed

```sql
COALESCE(SUM(OD.Quantity), 0) AS units_supplied
GROUP BY COALESCE(S.SupplierID, OD.SupplierID),
         COALESCE(S.CompanyName, 'Unknown supplier')
```

## Input to this step

Five resolved rows from stage 3.

| 🟪 SupplierID | 🟪 CompanyName | 🟦 units_supplied |

The group count is four. The supplier master is the driving population, while the FULL OUTER JOIN adds the unknown detail identity. The denominator branch is independent and can be prepared separately; it does not determine these four groups.

<details><summary>Full SQL for this stage</summary>

```sql
SELECT COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
       COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName,
       COALESCE(SUM(OD.Quantity), 0) AS units_supplied
FROM Suppliers AS S
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
GROUP BY COALESCE(S.SupplierID, OD.SupplierID),
         COALESCE(S.CompanyName, 'Unknown supplier')
ORDER BY units_supplied DESC;
```

</details>
