# P034 · Start with every supplier

<kbd>Previous</kbd> [![Next](../next.svg)](02.md) · **1 of 6**

🟩 `Suppliers` is the first `FROM` source because the report must include every supplier on file, even when it has no order lines. It supplies the required starting population: Alpha, Beta and Gamma.

## SQL added or changed

```sql
FROM Suppliers AS S
```

## Input to this step

**🟩 Suppliers · 3 rows**

| 🟩 SupplierID | 🟩 CompanyName |
|---:|---|
| 🟩 1 | 🟩 Alpha |
| 🟩 2 | 🟩 Beta |
| 🟩 3 | 🟩 Gamma |

## Result · 3 rows

| 🟩 SupplierID | 🟩 CompanyName |
|---:|---|
| 🟩 1 | 🟩 Alpha |
| 🟩 2 | 🟩 Beta |
| 🟩 3 | 🟩 Gamma |

No rows are added or removed. Gamma is deliberately retained as part of the report population even though it has no matching detail yet.

<details><summary>Full SQL for this stage</summary>

```sql
SELECT S.SupplierID, S.CompanyName
FROM Suppliers AS S
ORDER BY S.SupplierID;
```

</details>
