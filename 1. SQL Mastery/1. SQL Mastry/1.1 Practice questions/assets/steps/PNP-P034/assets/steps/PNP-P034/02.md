# P034 · Preserve unmatched rows from both sources

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md) · **2 of 6**

Add 🟦 `OrderDetails` second because its `SupplierID` supplies the quantity-bearing rows and reveals IDs absent from the supplier master. Both keys are available directly. FULL OUTER JOIN preserves both sides: Alpha's two detail rows repeat its supplier values; ID 99 survives with NULL supplier fields; Gamma survives with NULL detail fields.

## SQL added or changed

```sql
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
```

## Input to this step

**🟩 Suppliers · 3 rows** (stage 1) and **🟦 OrderDetails · 4 rows**

| 🟦 OrderDetailID | 🟦 SupplierID | 🟦 Quantity |
|---:|---:|---:|
| 🟦 1 | 🟦 1 | 🟦 2 |
| 🟦 2 | 🟦 1 | 🟦 3 |
| 🟦 3 | 🟦 2 | 🟦 5 |
| 🟦 4 | 🟦 99 | 🟦 4 |

## Result · 5 rows

| 🟩 SupplierID | 🟩 CompanyName | 🟦 OrderDetailID | 🟦 OD.SupplierID | 🟦 Quantity |
|---:|---|---:|---:|---:|
| 🟩 1 | 🟩 Alpha | 🟦 1 | 🟦 1 | 🟦 2 |
| 🟩 1 | 🟩 Alpha | 🟦 2 | 🟦 1 | 🟦 3 |
| 🟩 2 | 🟩 Beta | 🟦 3 | 🟦 2 | 🟦 5 |
| 🟩 NULL | 🟩 NULL | 🟦 4 | 🟦 99 | 🟦 4 |
| 🟩 3 | 🟩 Gamma | 🟦 NULL | 🟦 NULL | 🟦 NULL |

Five rows result from three supplier rows plus four detail rows, with two matched supplier/detail pairs for Alpha, one for Beta, one unmatched detail, and one unmatched supplier. The two Alpha matches repeat supplier attributes; they are not duplicate detail rows.

<details><summary>Full SQL for this stage</summary>

```sql
SELECT S.SupplierID AS supplier_id, S.CompanyName AS company_name,
       OD.OrderDetailID, OD.SupplierID AS order_supplier_id, OD.Quantity
FROM Suppliers AS S
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
ORDER BY COALESCE(S.SupplierID, OD.SupplierID), OD.OrderDetailID;
```

</details>
