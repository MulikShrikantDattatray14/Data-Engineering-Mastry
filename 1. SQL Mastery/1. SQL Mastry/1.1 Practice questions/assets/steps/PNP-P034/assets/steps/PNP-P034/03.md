# P034 · Resolve the supplier identity and label

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md) · **3 of 6**

The join leaves two possible ID columns. `COALESCE` takes the master ID when present, otherwise the detail ID; the name fallback labels ID 99. This projection changes values, not membership: all five joined rows remain. The NULLs for Gamma's detail columns remain source-colored 🟦 NULLs.

## SQL added or changed

```sql
COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName
```

## Input to this step

The five joined rows from stage 2.

## Result · 5 rows

| 🟪 SupplierID | 🟪 CompanyName | 🟦 OrderDetailID | 🟦 Quantity |
|---:|---|---:|---:|
| 🟪 1 | 🟩 Alpha | 🟦 1 | 🟦 2 |
| 🟪 1 | 🟩 Alpha | 🟦 2 | 🟦 3 |
| 🟪 2 | 🟩 Beta | 🟦 3 | 🟦 5 |
| 🟪 99 | 🟪 Unknown supplier | 🟦 4 | 🟦 4 |

The unmatched detail row now has a usable identity and display label. Gamma remains present with no detail values.

<details><summary>Full SQL for this stage</summary>

```sql
SELECT COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
       COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName,
       OD.OrderDetailID, OD.Quantity
FROM Suppliers AS S
FULL OUTER JOIN OrderDetails AS OD
    ON S.SupplierID = OD.SupplierID
ORDER BY COALESCE(S.SupplierID, OD.SupplierID), OD.OrderDetailID;
```

</details>
