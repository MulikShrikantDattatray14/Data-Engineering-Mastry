# P034 · Prepare the all-detail denominator

[![Previous](../previous.svg)](04.md) [![Next](../next.svg)](06.md) · **5 of 6**

The `sum_quantity` CTE is an independent one-row aggregate over 🟦 `OrderDetails`. Its single row represents the grand total, not a supplier. The outer query still starts from the four supplier groups created by the grouped FULL OUTER JOIN. A scalar subquery attaches the same denominator to each group. This branch can be computed independently from the supplier lookup.

## SQL added or changed

```sql
WITH sum_quantity AS (
    SELECT COALESCE(SUM(Quantity), 0) AS total_quantity
    FROM OrderDetails
)
-- scalar lookup:
(SELECT total_quantity FROM sum_quantity)
```

## Input to this step

**🟦 OrderDetails · 4 rows**

| 🟦 OrderDetailID | 🟦 SupplierID | 🟦 Quantity |
|---:|---:|---:|
| 🟦 1 | 🟦 1 | 🟦 2 |
| 🟦 2 | 🟦 1 | 🟦 3 |
| 🟦 3 | 🟦 2 | 🟦 5 |
| 🟦 4 | 🟦 99 | 🟦 4 |

## CTE result · 1 row

| 🟦 total_quantity |
|---:|
| 🟦 14 |

Arithmetic: 2 + 3 + 5 + 4 = 14. The unknown supplier's four units are included. This one-row CTE is not the outer query's row source; it is a scalar denominator lookup.

## Outer grouped input with denominator · 4 rows

| 🟪 SupplierID | 🟪 CompanyName | 🟦 units_supplied | 🟦 total_quantity |
|---:|---|---:|---:|
| 🟪 1 | 🟩 Alpha | 🟦 5 | 🟦 14 |
| 🟪 2 | 🟩 Beta | 🟦 5 | 🟦 14 |
| 🟪 99 | 🟪 Unknown supplier | 🟦 4 | 🟦 14 |
| 🟩 3 | 🟩 Gamma | 🟦 0 | 🟦 14 |

The four supplier groups remain four; the same denominator is repeated as a scalar value.

<details><summary>Full SQL for this stage</summary>

```sql
WITH sum_quantity AS (
    SELECT COALESCE(SUM(Quantity), 0) AS total_quantity
    FROM OrderDetails
)
SELECT SupplierID, CompanyName, units_supplied,
       (SELECT total_quantity FROM sum_quantity) AS total_quantity
FROM (
    SELECT COALESCE(S.SupplierID, OD.SupplierID) AS SupplierID,
           COALESCE(S.CompanyName, 'Unknown supplier') AS CompanyName,
           COALESCE(SUM(OD.Quantity), 0) AS units_supplied
    FROM Suppliers AS S
    FULL OUTER JOIN OrderDetails AS OD ON S.SupplierID = OD.SupplierID
    GROUP BY COALESCE(S.SupplierID, OD.SupplierID),
             COALESCE(S.CompanyName, 'Unknown supplier')
) AS supplier_totals
ORDER BY units_supplied DESC;
```

</details>
