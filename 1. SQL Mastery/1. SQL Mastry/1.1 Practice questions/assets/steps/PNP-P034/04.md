# P034 · Aggregate quantities by supplier

[![Previous](../previous.svg)](03.md) [![Next](../next.svg)](05.md) · **4 of 6**

Group by resolved SupplierID and CompanyName. The two Alpha details contribute 2 + 3 = 5; Beta 5; unknown ID 99 contributes 4. Gamma's SUM is NULL, converted to zero by COALESCE. Five rows become four groups.

**SQL added**
```sql
COALESCE(SUM(OD.Quantity), 0) AS units_supplied
GROUP BY COALESCE(S.SupplierID, OD.SupplierID),
         COALESCE(S.CompanyName, 'Unknown supplier')
```
**Result · 4 rows**

| SupplierID | CompanyName | units_supplied |
|---:|---|---:|
| 1 | Alpha | 5 |
| 2 | Beta | 5 |
| 99 | Unknown supplier | 4 |
| 3 | Gamma | 0 |
