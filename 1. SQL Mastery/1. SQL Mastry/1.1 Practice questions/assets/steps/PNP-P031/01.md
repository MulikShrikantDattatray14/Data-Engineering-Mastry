# P031 · Start with the orders

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 6**

`Orders` is the first `FROM` source because the report must retain each ordering customer’s purchase amount as the starting row before forming customer totals. It supplies both the customer ID and spend; order 10 contributes 300 for customer 1.

## SQL added or changed

```sql
FROM Orders AS o
```

## Input to this step

**🟦 Orders · 3 rows**

| 🟦 OrderID | 🟦 CustomerID | 🟦 Total_Order_Amount |
| --- | --- | --- |
| 🟦 10 | 🟦 1 | 🟦 300 |
| 🟦 11 | 🟦 2 | 🟦 100 |
| 🟦 12 | 🟦 3 | 🟦 200 |

## Result · 3 rows

| 🟦 OrderID | 🟦 CustomerID | 🟦 Total_Order_Amount |
| --- | --- | --- |
| 🟦 10 | 🟦 1 | 🟦 300 |
| 🟦 11 | 🟦 2 | 🟦 100 |
| 🟦 12 | 🟦 3 | 🟦 200 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT o.OrderID, o.CustomerID, o.Total_Order_Amount
FROM Orders AS o
ORDER BY o.OrderID;
```

</details>
