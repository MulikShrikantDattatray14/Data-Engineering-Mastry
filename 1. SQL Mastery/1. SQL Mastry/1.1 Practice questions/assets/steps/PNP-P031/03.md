# P031 · Sum each customer’s orders

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 6**

The `customer_spend` CTE is prepared from the original `Orders` and `Customers` tables, not from the preceding joined stage. `FROM Orders AS o` supplies every order amount; `LEFT JOIN Customers` on `CustomerID` adds names and keeps unmatched orders. `GROUP BY` produces one row per `CustomerID`/name group (including a `NULL`-ID group if present), so multiple orders contribute to one total. Order 10 contributes 300 for Asha.

## SQL added or changed

```sql
SUM(o.Total_Order_Amount) AS total_spend
-- one group per ordering ID and matched name
GROUP BY o.CustomerID, c.FirstName, c.LastName
```

<details>
<summary>Full SQLite query for this step</summary>

```sql
WITH customer_spend AS (
    SELECT
        o.CustomerID,
        COALESCE(c.FirstName || ' ' || c.LastName, 'Unknown') AS customer_name,
        SUM(o.Total_Order_Amount) AS total_spend
    FROM Orders AS o
    LEFT JOIN Customers AS c ON o.CustomerID = c.CustomerID
    GROUP BY o.CustomerID, c.FirstName, c.LastName
)
SELECT CustomerID, customer_name, total_spend
FROM customer_spend ORDER BY CustomerID;
```
