# P031 · Attach the customer average

[![Previous](../previous.svg)](03.md) [![Next](../next.svg)](05.md)  · **4 of 6**

`customer_spend` contains one row per `CustomerID`/name group, including a `NULL`-ID group if present. The outer `FROM customer_spend AS cs` starts from those totals; the scalar subquery reads all three sample totals (300 + 100 + 200) ÷ 3 = 200 and attaches that benchmark to every group. The locked query includes a `NULL`-ID group in the average, unlike the course answer.

## SQL added or changed

```sql
(SELECT AVG(total_spend) FROM customer_spend) AS avg_customer_spend
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_spend AS (
    SELECT
        o.CustomerID,
        COALESCE(c.FirstName || ' ' || c.LastName, 'Unknown') AS customer_name,
        SUM(o.Total_Order_Amount) AS total_spend
    FROM Orders AS o
    LEFT JOIN Customers AS c ON o.CustomerID = c.CustomerID
    GROUP BY o.CustomerID, c.FirstName, c.LastName
),
spend_with_avg AS (
    SELECT
        cs.*,
        (SELECT AVG(total_spend) FROM customer_spend) AS avg_customer_spend
    FROM customer_spend AS cs
)
SELECT * FROM spend_with_avg ORDER BY CustomerID;
```
