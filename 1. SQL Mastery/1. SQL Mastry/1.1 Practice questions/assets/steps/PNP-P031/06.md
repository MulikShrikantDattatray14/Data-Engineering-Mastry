# P031 · Calculate the percentage and sort

[![Previous](../previous.svg)](05.md) <kbd>Next</kbd>  · **6 of 6**

Asha is 100 above the 200 average. Her percentage is 50.0. NULLIF guards the division and descending spend puts the highest qualifying total first.

## SQL added or changed

```sql
100.0 * (total_spend - avg_customer_spend)
    / NULLIF(avg_customer_spend, 0) AS pct_above_avg
-- final sort
ORDER BY total_spend DESC
```

<summary>Full SQLite query for this step</summary>

```sql
WITH customer_spend AS (
    SELECT
        o.CustomerID,
        COALESCE(c.FirstName || ' ' || c.LastName, 'Unknown') AS customer_name,
        SUM(o.Total_Order_Amount) AS total_spend
    FROM Orders AS o
    LEFT JOIN Customers AS c ON o.CustomerID = c.CustomerID
    GROUP BY o.CustomerID, c.FirstName, c.LastName
),
spend_with_avg AS (
    SELECT
        cs.*,
        (SELECT AVG(total_spend) FROM customer_spend) AS avg_customer_spend
    FROM customer_spend AS cs
)
SELECT
    CustomerID,
    customer_name,
    total_spend,
    avg_customer_spend,
    100.0 * (total_spend - avg_customer_spend)
        / NULLIF(avg_customer_spend, 0) AS pct_above_avg
FROM spend_with_avg
WHERE total_spend > avg_customer_spend
ORDER BY total_spend DESC;
```
