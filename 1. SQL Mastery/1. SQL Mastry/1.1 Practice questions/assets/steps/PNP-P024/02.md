# P024 · Keep suppliers with any issue

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 4**

Supplier 1 passes both checks and leaves the issue report. Suppliers 2 and 3 remain.

## SQL added or changed

```sql
SELECT SupplierID, CompanyName, Country, Email FROM Suppliers
WHERE Country IS NULL
   OR TRIM(LOWER(Country)) != 'india'
   OR TRIM(Email) IS NULL
   OR LENGTH(TRIM(Email)) = 0;
```
