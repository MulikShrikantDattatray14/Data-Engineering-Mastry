# Q047 · Why count distinct products?

[![Previous](../previous.svg)](03.md) [![Next](../next.svg)](05.md) · **4 of 8**

The joined row grain is one row per order line, or one NULL-extended row for an unsold product. Product 1 therefore appears twice. Counting rows would overstate products listed and products sold. Count distinct product IDs on the correct side of the join.

## SQL added or changed

```sql
COUNT(DISTINCT P.ProductID) AS products_listed,
COUNT(DISTINCT OD.ProductID) AS products_sold
```

## Input to this step

The joined rows from step 3, grouped by the normalized brand label.

## Result · 🟪 3 brand groups

| 🟪 Brand | 🟩 distinct catalogue products | 🟦 distinct products with order lines |
|---|---:|---:|
| Nova | 3 (1, 2, 3) | 2 (1, 2) |
| Unbranded | 3 (4, 5, 6) | 2 (4, 5) |
| Solo | 2 (7, 8) | 0 |

Product 1 has two order lines but contributes only one to each distinct product count. Product 3 and product 6 count as listed, but not sold.

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT COALESCE(P.Brand, 'Unbranded') AS Brand,
       COUNT(DISTINCT P.ProductID) AS products_listed,
       COUNT(DISTINCT OD.ProductID) AS products_sold
FROM Products AS P
LEFT JOIN OrderDetails AS OD
    ON P.ProductID = OD.ProductID
GROUP BY COALESCE(P.Brand, 'Unbranded')
ORDER BY Brand;
```

</details>
