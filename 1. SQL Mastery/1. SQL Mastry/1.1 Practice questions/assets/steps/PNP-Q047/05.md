# Q047 · Why sum units and line values?

[![Previous](../previous.svg)](04.md) [![Next](../next.svg)](06.md) · **5 of 8**

Product counts use DISTINCT IDs, but units and value must include every order line. Product 1's two lines each contribute quantity and value. A line-level value is quantity multiplied by the sale price for the matched catalogue product.

## SQL added or changed

```sql
COALESCE(SUM(OD.Quantity), 0) AS units_sold,
COALESCE(SUM(P.Sale_Price * OD.Quantity), 0) AS list_price_value
```

## Input to this step

| 🟩 ProductID | 🟪 Brand | 🟩 Sale_Price | 🟦 OrderDetailID | 🟦 Quantity |
|---:|---|---:|---:|---:|
| 1 | Nova | 10 | 10 | 2 |
| 1 | Nova | 10 | 11 | 1 |
| 2 | Nova | 20 | 12 | 1 |
| 3 | Nova | 30 | NULL | NULL |
| 4 | Unbranded | 5 | 13 | 2 |
| 5 | Unbranded | 6 | 14 | 1 |
| 6 | Unbranded | 7 | NULL | NULL |
| 7 | Solo | 8 | NULL | NULL |
| 8 | Solo | 9 | NULL | NULL |

## Result · 🟪 3 brand groups

| 🟪 Brand | 🟦 units_sold | 🟪 line-value arithmetic | 🟪 list_price_value |
|---|---:|---|---:|
| Nova | 4 | 2×10 + 1×10 + 1×20 | 50 |
| Unbranded | 3 | 2×5 + 1×6 | 16 |
| Solo | 0 | no order lines | 0 |

`SUM` ignores the NULL-extended rows. For a brand with no order lines, SUM returns NULL, so COALESCE supplies the requested zero.

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT COALESCE(P.Brand, 'Unbranded') AS Brand,
       COUNT(DISTINCT P.ProductID) AS products_listed,
       COUNT(DISTINCT OD.ProductID) AS products_sold,
       COALESCE(SUM(OD.Quantity), 0) AS units_sold,
       COALESCE(SUM(P.Sale_Price * OD.Quantity), 0) AS list_price_value
FROM Products AS P
LEFT JOIN OrderDetails AS OD
    ON P.ProductID = OD.ProductID
GROUP BY COALESCE(P.Brand, 'Unbranded');
```

</details>
