# Q047 · Why normalize the brand label?

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md) · **3 of 8**

The submitted learner expression maps SQL NULL to the display label Unbranded. Apply it before grouping so products with missing brands land in one display group. This sample contains NULL values, not empty strings.

## SQL added or changed

```sql
COALESCE(P.Brand, 'Unbranded') AS Brand
```

## Input to this step

The ten joined rows from step 2. The repeated product 1 rows remain separate order-line rows; the brand label is calculated on each row.

## Result · 🟪 9 rows

| 🟩 ProductID | 🟩 Source Brand | 🟪 Brand label | 🟦 OrderDetailID | 🟦 Quantity |
|---:|---|---|---:|---:|
| 1 | Nova | Nova | 10 | 2 |
| 1 | Nova | Nova | 11 | 1 |
| 2 | Nova | Nova | 12 | 1 |
| 3 | Nova | Nova | NULL | NULL |
| 4 | NULL | Unbranded | 13 | 2 |
| 5 | NULL | Unbranded | 14 | 1 |
| 6 | NULL | Unbranded | NULL | NULL |
| 7 | Solo | Solo | NULL | NULL |
| 8 | Solo | Solo | NULL | NULL |

The official expression is broader: `COALESCE(NULLIF(TRIM(P.Brand), ''), 'Unbranded')`. It also converts empty and whitespace-only strings. The learner query is preserved as submitted; do not silently replace it.

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT P.ProductID, P.Brand AS source_brand,
       COALESCE(P.Brand, 'Unbranded') AS Brand,
       OD.OrderDetailID, OD.Quantity
FROM Products AS P
LEFT JOIN OrderDetails AS OD
    ON P.ProductID = OD.ProductID
ORDER BY P.ProductID, OD.OrderDetailID;
```

</details>
