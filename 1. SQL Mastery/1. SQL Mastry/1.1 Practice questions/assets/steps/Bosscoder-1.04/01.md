# Bosscoder-1.04 · Turn `store1` into rows

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 4**

The text `'store1'` becomes the output store label, while the value in column `store1` becomes `price`.

## SQL added or changed

```sql
SELECT product_id,
       'store1' AS store,
       store1 AS price
FROM Products
WHERE store1 IS NOT NULL;
```
