# Bosscoder-1.04 · Stack the branch results with `UNION ALL`

[![Previous](../previous.svg)](03.md) <kbd>Next</kbd>  · **4 of 4**

It retains all two `🟦 store1` rows, one `🟦 store2` row, and two `🟦 store3` rows: five output rows in total. The final `ORDER BY store ASC` arranges the stores as `🟦 store1`, `🟦 store2`, `🟦 store3`.

## SQL added or changed

```sql
SELECT product_id,
       'store1' AS store,
       store1 AS price
FROM Products
WHERE store1 IS NOT NULL

UNION ALL

SELECT product_id,
       'store2' AS store,
       store2 AS price
FROM Products
WHERE store2 IS NOT NULL

UNION ALL

-- …

ORDER BY store ASC;
```
