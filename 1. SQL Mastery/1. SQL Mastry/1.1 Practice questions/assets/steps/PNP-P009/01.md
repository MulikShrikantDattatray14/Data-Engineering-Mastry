# P009 · Summarize 🟦 Category

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

Each distinct 🟦 Active value is one category branch row, including 🟦 NULL. The two active categories share one group. 🟦 Category is this branch's source because its rows are the category population; the branch counts each raw 🟦 Active value without pairing it to Payments.

## SQL added or changed

```sql
SELECT 'Category' AS source_table,
       'Active' AS flag_column, CAST(Active AS TEXT) AS raw_value , count(*) as row_count
from Category
Group by Active
```
