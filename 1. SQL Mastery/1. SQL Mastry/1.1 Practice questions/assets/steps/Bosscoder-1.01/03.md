The output requires only `customer_id`, so the final `SELECT` drops the helper columns `year` and `revenue` from display:

## SQL added or changed

```sql
SELECT customer_id
```

## Input to this step

**Keep only positive revenue · 2 rows**

| 🟦 customer_id | 🟦 year | 🟦 revenue |

| 🟦 1 | 🟦 2021 | 🟦 30 |
| 🟦 4 | 🟦 2021 | 🟦 20 |

## Result · 2 rows

| 🟦 customer_id |
| --- |
| 🟦 1 |
| 🟦 4 |

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT customer_id
FROM Customers
WHERE year = 2021 AND revenue > 0;
```
