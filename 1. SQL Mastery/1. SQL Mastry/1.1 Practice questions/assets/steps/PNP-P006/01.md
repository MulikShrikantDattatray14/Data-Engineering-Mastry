# P006 · Compare the two prices on each row

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

The comparison can be true, false, or unknown. Products is the only source because Sale_Price and Market_Price sit on each product row, so the full-price comparison needs no join.

## SQL added or changed

```sql
SELECT ProductID, Product, Sale_Price, Market_Price,
       Market_Price = Sale_Price AS prices_match
FROM Products
ORDER BY ProductID;
```
