# P028 · Why do both scalar subqueries read all five orders?

[![Previous](../previous.svg)](05.md) [![Next](../next.svg)](07.md)  · **6 of 8**

Both scalar subqueries read Orders independently of the payment groups. The common denominators are five orders and 100 + 200 + 300 + 50 + 150 = 800 in value.

## SQL added or changed

```sql
SELECT COUNT(*) AS all_orders, SUM(Total_Order_Amount) AS all_order_value FROM Orders;
```

## Input to this step

**🟦 Orders · 5 rows**

| 🟦 OrderID | 🟦 PaymentID | 🟦 Total_Order_Amount |
| --- | --- | --- |
| 10 | 1 | 100 |
| 11 | 1 | 200 |
| 12 | 2 | 300 |
| 13 | 99 | 50 |
| 14 | NULL | 150 |

## Result · 1 row

| 🟦 all_orders | 🟦 all_order_value |
| --- | --- |
| 5 | 800 |
