# P028 · Why count order IDs and add order amounts?

[![Previous](../previous.svg)](04.md) [![Next](../next.svg)](06.md)  · **5 of 8**

UPI has two orders and Card has one; each group contributes a total value of 300.

## SQL added or changed

```sql
SELECT COALESCE(p.PaymentType, 'Unknown') AS payment_type, COUNT(DISTINCT o.OrderID) AS orders, SUM(o.Total_Order_Amount) AS order_value FROM Orders AS o LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID GROUP BY payment_type;
```
