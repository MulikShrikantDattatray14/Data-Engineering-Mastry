# P028 · Why LEFT JOIN on PaymentID?

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 8**

Orders 10 and 11 receive UPI; order 12 receives Card. The left join would retain an order without a lookup match.

## SQL added or changed

```sql
SELECT o.OrderID, o.PaymentID AS ordering_payment_id, p.PaymentID AS matched_payment_id, p.PaymentType, o.Total_Order_Amount FROM Orders AS o LEFT JOIN Payments AS p ON o.PaymentID = p.PaymentID ORDER BY o.OrderID;
```
