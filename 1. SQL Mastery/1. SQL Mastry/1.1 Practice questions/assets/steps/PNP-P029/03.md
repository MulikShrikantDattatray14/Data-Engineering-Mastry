# P029 · Why add Shippers with a LEFT JOIN?

[![Previous](../previous.svg)](02.md) [![Next](../next.svg)](04.md)  · **3 of 6**

Orders already carries ShipperID. Add Shippers second to look up its company name. Every order stays on the left, including an order with an unrecognised shipper ID.

## SQL added or changed

```sql
SELECT o.OrderID, o.ShipperID AS ordering_shipper_id, o.Total_Order_Amount,
       s.ShipperID AS matched_shipper_id, s.CompanyName
FROM Orders AS o
LEFT JOIN Shippers AS s
    ON o.ShipperID = s.ShipperID
ORDER BY o.OrderID;
```
