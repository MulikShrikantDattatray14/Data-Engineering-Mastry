# P029 · Why prepare OrderDetails_2 first?

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 6**

One order can have several detail lines. Sum the quantities for each OrderID so the summary can match an order at most once.

## SQL added or changed

```sql
WITH OrderDetails_2 AS (
    SELECT OrderID, SUM(Quantity) AS total_units
    FROM OrderDetails
    GROUP BY OrderID
)
SELECT OrderID, total_units
FROM OrderDetails_2
ORDER BY OrderID;
```

## Input to this step

**🟥 OrderDetails · 4 rows**

| 🟥 OrderDetailID | 🟥 OrderID | 🟥 Quantity |
| --- | --- | --- |
| 1 | 10 | 2 |
| 2 | 10 | 3 |
| 3 | 11 | 4 |
| 4 | 12 | 1 |

## Result · 3 rows

| 🟥 OrderID | 🟥 total_units |
| --- | --- |
| 10 | 5 |
| 11 | 4 |
| 12 | 1 |
