# P029 · Why prepare OrderDetails_2 first?

<kbd>Previous</kbd> [![Next](../next.svg)](🟥 02.md)  · **🟥 1 of 6**

OrderDetails supplies every detail line because each line contributes quantity. Grouping by OrderID makes one CTE row per order; Orders supplies the outer report’s starting rows.

## SQL added or changed

```sql
WITH OrderDetails_2 AS (
    SELECT OrderID, SUM(Quantity) AS total_units
    FROM OrderDetails
    GROUP BY OrderID
)
SELECT OrderID, total_units
FROM OrderDetails_2
ORDER BY OrderID;
```
