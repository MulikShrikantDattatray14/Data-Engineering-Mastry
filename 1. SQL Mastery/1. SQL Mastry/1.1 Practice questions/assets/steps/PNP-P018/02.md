# P018 · Match only orders inside the window

[![Previous](../previous.svg)](01.md) [![Next](../next.svg)](03.md)  · **2 of 4**

Start the outer report from Customers because every registered customer is a candidate, even Cia with no order. Add Orders second with a LEFT JOIN on CustomerID; that key is already on both sides, so no lookup dependency is missing. Keep the date-range condition in ON to restrict matches rather than filter customers. Asha matches order 10 on March 31 and stays with a match. Ben’s order 11 (December 1) falls outside the window, so his row survives with NULL order columns; Cia has no order and also survives with NULLs. The later anti-match filter removes Asha and keeps Ben and Cia

## SQL added or changed

```sql
SELECT Customers.CustomerID, Orders.OrderID AS matched_order_id, Orders.OrderDate AS matched_order_date
FROM Customers
LEFT JOIN Orders
    ON Orders.CustomerID = Customers.CustomerID
   AND date(Orders.OrderDate) BETWEEN
       (SELECT window_start FROM reporting_window)
       AND (SELECT latest_order_date FROM reporting_window)
ORDER BY Customers.CustomerID;
```

WITH reporting_window AS (

           date(MAX(OrderDate), '-89 days') AS window_start
    FROM Orders

    ON Orders.CustomerID = Customers.CustomerID
   AND date(Orders.OrderDate) BETWEEN
