# P018 · Calculate the 90-day window

<kbd>Previous</kbd> [![Next](../next.svg)](🟩 02.md)  · **🟩 1 of 4**

The date window depends on the most recent transaction. The CTE returns one pair of dates for the whole report. Subtract 89 days because the latest date counts as one of the 90. Orders supplies the OrderDate values for this date-bound CTE; its one row is the latest date and the inclusive window bounds, not the outer customer population.

## SQL added or changed

```sql
WITH reporting_window AS (
    SELECT date(MAX(OrderDate)) AS latest_order_date,
           date(MAX(OrderDate), '-89 days') AS window_start
    FROM Orders
)
SELECT latest_order_date, window_start FROM reporting_window;
```

**🟩 Orders · 🟩 2 rows**
