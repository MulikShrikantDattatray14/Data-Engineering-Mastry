# P020 · Keep November 2025 orders

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 2**

The reporting period depends on when the order was placed. Order 🟦 3 was shipped in November but placed in October. Order 🟦 2 stays even though it has no shipping or delivery date. Orders is the only source because the date filter and all three date/ID fields belong to each order; the report measures elapsed time on order rows.

## SQL added or changed

```sql
SELECT OrderID, OrderDate, ShipDate, DeliveryDate
FROM Orders
WHERE strftime("%m", OrderDate) = '11' AND strftime("%Y", OrderDate) = '2025'
ORDER BY OrderDate ASC, `OrderID` ASC;
```

## Input to this step

| 🟦 2 | 🟦 2025-11-02 | 🟦 NULL | 🟦 NULL |
| 🟦 3 | 🟦 2025-10-31 | 🟦 2025-11-01 | 🟦 2025-11-04 |
