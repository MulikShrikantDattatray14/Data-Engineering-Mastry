# P020 · Calculate the calendar-day differences and sort

[![Previous](../previous.svg)](🟦 01.md) <kbd>Next</kbd>  · **🟦 2 of 🟦 2**

Subtracting raw date strings in SQLite can subtract just their leading years. The inner date calls discard time, so crossing midnight counts as one calendar day. Each missing date affects only its own metric. The ID breaks order-date ties.

## SQL added or changed

```sql
SELECT OrderID, OrderDate, ShipDate, DeliveryDate,
       CAST(julianday(date(ShipDate)) - julianday(date(OrderDate)) AS INTEGER) AS days_to_ship,
       CAST(julianday(date(DeliveryDate)) - julianday(date(OrderDate)) AS INTEGER) AS days_to_deliver
```

<details>
<summary>Full SQLite query for this step</summary>

```sql
SELECT OrderID, OrderDate, ShipDate, DeliveryDate,
       CAST(julianday(date(ShipDate)) - julianday(date(OrderDate)) AS INTEGER) AS days_to_ship,
       CAST(julianday(date(DeliveryDate)) - julianday(date(OrderDate)) AS INTEGER) AS days_to_deliver
FROM Orders
WHERE strftime("%m", OrderDate) = '11' AND strftime("%Y", OrderDate) = '2025'
ORDER BY OrderDate ASC, `OrderID` ASC;
```

</details>
