# P016 · Match each order to its customer

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **🟪 1 of 3**

Both sample orders match 🟦 Anu, so both remain before the date filter. Customers is the chosen starting source because it supplies the call-sheet name and city; INNER JOIN Orders keeps only orders for known customers, as this report requests.

## SQL added or changed

```sql
SELECT o.OrderID, c.CustomerID, c.FirstName, c.LastName, c.City, o.OrderDate, o.Total_Order_Amount
FROM Customers AS c
INNER JOIN Orders AS o ON c.CustomerID = o.CustomerID
ORDER BY o.OrderID;
```
