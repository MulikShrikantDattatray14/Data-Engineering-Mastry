# P016 · Format and sort the call sheet

[![Previous](../previous.svg)](02.md) <kbd>Next</kbd>  · **3 of 3**

The support team needs readable customer names and cities. The ID breaks ties when orders have the same date.

## SQL added or changed

```sql
select o.OrderID, o.OrderDate, (c.FirstName||" "|| c.LastName) as customer_name, trim(c.City) as City, o.Total_Order_Amount
-- …
where strftime('%Y', OrderDate) = '2025' and strftime('%m', OrderDate)='12'
order by o.OrderDate asc,o.OrderID asc;
```

<summary>Full SQLite query for this step</summary>

```sql
select o.OrderID, o.OrderDate, (c.FirstName||" "|| c.LastName) as customer_name, trim(c.City) as City, o.Total_Order_Amount
from Customers as c
inner join Orders as o on c.CustomerID = o.CustomerID
where strftime('%Y', OrderDate) = '2025' and strftime('%m', OrderDate)='12'
order by o.OrderDate asc,o.OrderID asc;
```
