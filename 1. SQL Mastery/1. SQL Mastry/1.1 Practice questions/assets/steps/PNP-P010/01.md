# P010 · Count orders and distinct customers

<kbd>Previous</kbd> [![Next](../next.svg)](02.md)  · **1 of 3**

Order volume and customer reach count different things. Orders is the only source because the report's headline measures all describe transactions and each row already supplies order ID, customer ID, amount and date.

## SQL added or changed

```sql
SELECT COUNT(OrderID) AS total_orders,
       COUNT(DISTINCT CustomerID) AS ordering_customers
FROM Orders;
```
