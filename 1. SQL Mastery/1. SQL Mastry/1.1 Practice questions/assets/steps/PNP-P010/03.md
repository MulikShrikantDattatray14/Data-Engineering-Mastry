# P010 · Add the first and last dates

[![Previous](../previous.svg)](02.md) <kbd>Next</kbd>  · **3 of 3**

The date bounds must describe the entire set of orders.

## SQL added or changed

```sql
SELECT COUNT(OrderID) AS total_orders,
       COUNT(DISTINCT CustomerID) AS ordering_customers,
       SUM(Total_Order_Amount) AS total_order_value,
       ROUND(AVG(Total_Order_Amount), 2) AS avg_order_value,
       MIN(OrderDate) AS first_order_date,
       MAX(OrderDate) AS last_order_date
```
