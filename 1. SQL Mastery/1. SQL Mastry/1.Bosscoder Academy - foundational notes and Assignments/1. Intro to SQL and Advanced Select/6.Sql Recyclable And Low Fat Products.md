# 6. SQL Recyclable And Low Fat Products

## Question and image

Find the `product_id` values of products that are **both** low fat and recyclable. The two flags contain `Y` for yes and `N` for no. No output order is specified.

**Example 1**

Input — `Products`:

| product_id | low_fats | recyclable |
|---:|---|---|
| 0 | Y | N |
| 1 | Y | Y |
| 2 | N | Y |
| 3 | Y | Y |
| 4 | N | N |

Expected output:

| product_id |
|---:|
| 1 |
| 3 |

Only products 1 and 3 have `Y` in both columns.

## Schema

`Products`:

| Column Name | Type |
|---|---|
| product_id | int |
| low_fats | enum (`Y`, `N`) |
| recyclable | enum (`Y`, `N`) |

`product_id` is the primary key. `low_fats = 'Y'` means the product is low fat; `recyclable = 'Y'` means it is recyclable.

## My solution — SQLite

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

### Step-by-step explanation with one example

**Starting data.** One input row represents one product. The result needs only the IDs of products satisfying both flags.

| product_id | low_fats | recyclable |
|---:|---|---|
| 0 | Y | N |
| 1 | Y | Y |
| 2 | N | Y |
| 3 | Y | Y |
| 4 | N | N |

**1. Check the low-fat flag.** A row passes `low_fats = 'Y'` only if that product is low fat.

```sql
SELECT product_id, low_fats, recyclable
FROM Products
WHERE low_fats = 'Y';
```

| product_id | low_fats | recyclable |
|---:|---|---|
| 0 | Y | N |
| 1 | Y | Y |
| 3 | Y | Y |

Products 2 and 4 fail this first test. Product 0 remains for now even though it is not recyclable.

**2. Require the recyclable flag too.** `AND` means **both conditions must be true on the same row**.

```sql
SELECT product_id, low_fats, recyclable
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

| product_id | low_fats | recyclable |
|---:|---|---|
| 1 | Y | Y |
| 3 | Y | Y |

Product 0 now fails because its `recyclable` flag is `N`. Product 2 was recyclable, but its low-fat flag was `N`, so it cannot return either.

**3. Show only the requested column.** The flags are useful for checking the logic, but the required output contains just `product_id`:

```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y' AND recyclable = 'Y';
```

| product_id |
|---:|
| 1 |
| 3 |

`product_id` is already unique, so no `DISTINCT` is needed. The prompt does not request an order, so the final query does not need `ORDER BY`.
