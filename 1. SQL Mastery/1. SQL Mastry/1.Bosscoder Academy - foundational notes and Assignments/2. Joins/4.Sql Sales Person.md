## Question and image

Find the names of all salespersons who **did not have any orders** related to the company named `RED`. Return the result in any order.

**Example 1**

Input — `SalesPerson`:

| sales_id | name | salary | commission_rate | hire_date |
|---:|---|---:|---:|---|
| 1 | John | 100000 | 6 | 4/1/2006 |
| 2 | Amy | 12000 | 5 | 5/1/2010 |
| 3 | Mark | 65000 | 12 | 12/25/2008 |
| 4 | Pam | 25000 | 25 | 1/1/2005 |
| 5 | Alex | 5000 | 10 | 2/3/2007 |

Input — `Company`:

| com_id | name | city |
|---:|---|---|
| 1 | RED | Boston |
| 2 | ORANGE | New York |
| 3 | YELLOW | Boston |
| 4 | GREEN | Austin |

Input — `Orders`:

| order_id | order_date | com_id | sales_id | amount |
|---:|---|---:|---:|---:|
| 1 | 1/1/2014 | 3 | 4 | 10000 |
| 2 | 2/1/2014 | 4 | 5 | 5000 |
| 3 | 3/1/2014 | 1 | 1 | 50000 |
| 4 | 4/1/2014 | 1 | 4 | 25000 |

Expected output:

| name |
|---|
| Amy |
| Mark |
| Alex |

John and Pam have orders with `RED`. The other salespersons have no `RED` orders, including those with no orders at all.

## Schema

`SalesPerson`:

| Column Name | Type |
|---|---|
| sales_id | int |
| name | varchar |
| salary | int |
| commission_rate | int |
| hire_date | date |

`sales_id` is the primary key. Each row identifies one salesperson and their salary, commission rate, and hire date.

`Company`:

| Column Name | Type |
|---|---|
| com_id | int |
| name | varchar |
| city | varchar |

`com_id` is the primary key. Each row identifies a company and city.

`Orders`:

| Column Name | Type |
|---|---|
| order_id | int |
| order_date | date |
| com_id | int |
| sales_id | int |
| amount | int |

`order_id` is the primary key. `com_id` references `Company.com_id`; `sales_id` references `SalesPerson.sales_id`. Each row records an order's company, salesperson, date, and amount.
