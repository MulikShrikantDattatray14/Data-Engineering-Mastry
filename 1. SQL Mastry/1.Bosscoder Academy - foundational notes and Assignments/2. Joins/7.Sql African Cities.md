# 7. SQL African Cities

## Question and image

Given `CITY` and `COUNTRY`, return the names of cities whose country has `CONTINENT = 'Africa'`. Match `CITY.COUNTRYCODE` with `COUNTRY.CODE`. No output order is specified.

**Example 1**

Input — `CITY`:

| ID | NAME | COUNTRYCODE | DISTRICT | POPULATION |
|---:|---|---|---|---:|
| 1 | Nairobi | KEN | Nairobi | 4397073 |
| 2 | Cairo | EGY | Cairo | 9500000 |
| 3 | Mumbai | IND | Maharashtra | 20411000 |
| 4 | Lagos | NGA | Lagos | 14000000 |

Input — `COUNTRY` (columns used in this example):

| CODE | NAME | CONTINENT | REGION |
|---|---|---|---|
| KEN | Kenya | Africa | Eastern Africa |
| EGY | Egypt | Africa | Northern Africa |
| IND | India | Asia | Southern Asia |
| NGA | Nigeria | Africa | Western Africa |

Expected output:

| NAME |
|---|
| Nairobi |
| Cairo |
| Lagos |

Mumbai belongs to India, whose continent is Asia. The other three cities belong to African countries.

## My solution — SQLite

```sql
SELECT CITY.NAME
FROM CITY
INNER JOIN COUNTRY
    ON CITY.COUNTRYCODE = COUNTRY.CODE
WHERE CONTINENT = 'Africa';
```

### Step-by-step explanation with one example

**Starting data.** `CITY` tells us a city's country code, while `COUNTRY` tells us the continent for each country code.

| CITY.NAME | CITY.COUNTRYCODE |
|---|---|
| Nairobi | KEN |
| Cairo | EGY |
| Mumbai | IND |
| Lagos | NGA |

| COUNTRY.CODE | COUNTRY.NAME | COUNTRY.CONTINENT |
|---|---|---|
| KEN | Kenya | Africa |
| EGY | Egypt | Africa |
| IND | India | Asia |
| NGA | Nigeria | Africa |

**1. Match each city to its country.** `ON CITY.COUNTRYCODE = COUNTRY.CODE` connects, for example, Nairobi's `KEN` to Kenya's `KEN`. Inspect the joined rows before filtering:

```sql
SELECT CITY.NAME AS city_name,
       CITY.COUNTRYCODE,
       COUNTRY.NAME AS country_name,
       COUNTRY.CONTINENT
FROM CITY
INNER JOIN COUNTRY
    ON CITY.COUNTRYCODE = COUNTRY.CODE;
```

| city_name | COUNTRYCODE | country_name | CONTINENT |
|---|---|---|---|
| Nairobi | KEN | Kenya | Africa |
| Cairo | EGY | Egypt | Africa |
| Mumbai | IND | India | Asia |
| Lagos | NGA | Nigeria | Africa |

Both tables contain `NAME`, so `CITY.NAME` identifies the requested city name; `COUNTRY.NAME` would return Kenya, Egypt, India, and Nigeria instead. `INNER JOIN` keeps matching city–country pairs.

**2. Keep only countries in Africa.** Add `WHERE COUNTRY.CONTINENT = 'Africa'`. Mumbai's joined country is India, whose continent is Asia, so that row is excluded:

```sql
SELECT CITY.NAME AS city_name, COUNTRY.CONTINENT
FROM CITY
INNER JOIN COUNTRY
    ON CITY.COUNTRYCODE = COUNTRY.CODE
WHERE COUNTRY.CONTINENT = 'Africa';
```

| city_name | CONTINENT |
|---|---|
| Nairobi | Africa |
| Cairo | Africa |
| Lagos | Africa |

**3. Return only the city name.** The user's final query selects `CITY.NAME`, giving:

| NAME |
|---|
| Nairobi |
| Cairo |
| Lagos |

`CONTINENT` is unambiguous here because only `COUNTRY` has that column. Writing `COUNTRY.CONTINENT` is also valid and makes its source explicit. The prompt does not require an `ORDER BY`, so output order may differ.
