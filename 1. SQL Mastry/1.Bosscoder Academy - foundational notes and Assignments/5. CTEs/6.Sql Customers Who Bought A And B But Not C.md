# 6. SQL Customers Who Bought A And B But Not C

## Question and image

**6. Sql Customers Who Bought A And B But Not C**

Table: Customers

| Column Name | Type |
|---|---|
| customer_id | int |
| customer_name | varchar |

`customer_id` is the column with unique values for this table.

`customer_name` is the name of the customer.

Table: Orders

| Column Name | Type |
|---|---|
| order_id | int |
| customer_id | int |
| product_name | varchar |

`order_id` is the column with unique values for this table.

`customer_id` is the id of the customer who bought the product `product_name`.

Write a solution to report the `customer_id` and `customer_name` of customers who bought products `"A"`, `"B"` but did not buy the product `"C"` since we want to recommend them to purchase this product.

Return the result table ordered by `customer_id`.

Output:

| customer_id | customer_name |

Explanation: Only the `customer_id` with id 3 bought the product A and B but not the product C.

## My solution — SQLite

```sql
WITH needed_customer AS (
    SELECT
        customer_id
    FROM Orders
    GROUP BY customer_id
    HAVING
        SUM(CASE WHEN product_name = 'A' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'B' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'C' THEN 1 ELSE 0 END) = 0
)
SELECT
    customer_id,
    customer_name
FROM Customers
WHERE customer_id IN (
    SELECT customer_id
    FROM needed_customer
)
ORDER BY customer_id ASC;
```

**1. Flag the three products separately on every order**

We need evidence that A and B were purchased and evidence that C was never purchased. Keep all orders while calculating these flags.

```sql
SELECT order_id, customer_id, product_name,
       CASE WHEN product_name = 'A' THEN 1 ELSE 0 END AS bought_A,
       CASE WHEN product_name = 'B' THEN 1 ELSE 0 END AS bought_B,
       CASE WHEN product_name = 'C' THEN 1 ELSE 0 END AS bought_C
FROM Orders
ORDER BY order_id;
```

Result:

| order_id | customer_id | product_name | bought_A | bought_B | bought_C |
| --- | --- | --- | --- | --- | --- |
| 10 | 1 | A | 1 | 0 | 0 |
| 20 | 1 | B | 0 | 1 | 0 |
| 30 | 1 | D | 0 | 0 | 0 |
| 40 | 1 | C | 0 | 0 | 1 |
| 50 | 2 | A | 1 | 0 | 0 |
| 60 | 3 | A | 1 | 0 | 0 |
| 70 | 3 | B | 0 | 1 | 0 |
| 80 | 3 | D | 0 | 0 | 0 |
| 90 | 4 | C | 0 | 0 | 1 |

An order for D contributes zero to all three flags, but stays harmlessly in the group. Removing C orders before grouping would hide the evidence needed to exclude customer 1.

**2. Add the flags per customer**

One summary row per customer shows how many A, B, and C orders that customer has.

```sql
SELECT customer_id,
       SUM(CASE WHEN product_name = 'A' THEN 1 ELSE 0 END) AS A_count,
       SUM(CASE WHEN product_name = 'B' THEN 1 ELSE 0 END) AS B_count,
       SUM(CASE WHEN product_name = 'C' THEN 1 ELSE 0 END) AS C_count
FROM Orders
GROUP BY customer_id
ORDER BY customer_id;
```

Result:

| customer_id | A_count | B_count | C_count |
| --- | --- | --- | --- |
| 1 | 1 | 1 | 1 |
| 2 | 1 | 0 | 0 |
| 3 | 1 | 1 | 0 |
| 4 | 0 | 0 | 1 |

Customer 1 has A and B but also C. Customer 2 lacks B. Customer 3 has A and B with no C. Customer 4 lacks both A and B.

**3. Filter groups using all three requirements**

HAVING checks the aggregate counts: A > 0, B > 0, and C = 0. These conditions must all hold for the same customer.

```sql
WITH needed_customer AS (
    SELECT
        customer_id
    FROM Orders
    GROUP BY customer_id
    HAVING
        SUM(CASE WHEN product_name = 'A' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'B' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'C' THEN 1 ELSE 0 END) = 0
)
SELECT * FROM needed_customer;
```

Result:

| customer_id |
| --- |
| 3 |

The CTE returns just customer_id 3. Greater than zero allows multiple purchases of A or B.

**4. Assemble the final query**

Use the qualifying IDs to filter Customers, obtain customer_name, and order by customer_id.

```sql
WITH needed_customer AS (
    SELECT
        customer_id
    FROM Orders
    GROUP BY customer_id
    HAVING
        SUM(CASE WHEN product_name = 'A' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'B' THEN 1 ELSE 0 END) > 0
        AND SUM(CASE WHEN product_name = 'C' THEN 1 ELSE 0 END) = 0
)
SELECT
    customer_id,
    customer_name
FROM Customers
WHERE customer_id IN (
    SELECT customer_id
    FROM needed_customer
)
ORDER BY customer_id ASC;
```

Final result for this example:

| customer_id | customer_name |
| --- | --- |
| 3 | Elizabeth |

**Check the result:** Elizabeth bought A, B, and D. D is allowed; C is absent. No other customer satisfies all three conditions.
