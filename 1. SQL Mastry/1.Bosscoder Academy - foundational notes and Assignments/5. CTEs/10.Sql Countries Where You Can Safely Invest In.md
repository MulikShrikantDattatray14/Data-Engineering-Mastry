Each row of this table contains the name of a person and their phone number.

| Column Name | Type |
|---|---|

Table Calls:

| Column Name | Type |
|---|---|
| caller_id | int |
| callee_id | int |
| duration | int |

This table may contain duplicate rows.

Each row of this table contains the caller id, callee id and the duration of the call in minutes. caller_id != callee_id

A telecommunications company wants to invest in new countries. The company intends to invest in the countries where the average call duration of the calls in this country is strictly greater than the global average call duration.

Write a solution to find the countries where this company can invest.

Since Peru is the only country where the average call duration is greater than the global average, it is the only recommended country.

## My solution — SQLite

```sql
WITH global_avg AS (
    SELECT
        (2.0 * SUM(duration))
        / (COUNT(duration) + COUNT(duration)) AS Global_Avg
    FROM Calls
),
country_averages AS (
    SELECT
        c.name AS country,
        AVG(ca.duration) AS country_avg
    FROM Person AS p
    JOIN Country AS c
        ON SUBSTR(p.phone_number, 1, 3) = c.country_code
    JOIN Calls AS ca
        ON p.id = ca.caller_id OR p.id = ca.callee_id
    GROUP BY c.name
)
SELECT
    ca.country
FROM country_averages AS ca
CROSS JOIN global_avg AS ga
WHERE ca.country_avg > ga.Global_Avg;
```

**1. Calculate the global comparison value**

The global average is total duration divided by number of calls. Your formula counts every call twice in both numerator and denominator, which leaves that average unchanged.

```sql
WITH global_avg AS (
    SELECT
        (2.0 * SUM(duration))
        / (COUNT(duration) + COUNT(duration)) AS Global_Avg
    FROM Calls
)
SELECT * FROM global_avg;
```

Result:

| Global_Avg |
| --- |
| 55.7 |

The ten durations sum to 557. The saved expression gives (2.0 * 557) / (10 + 10) = 55.7. The 2.0 ensures decimal arithmetic.

**2. Map each person to a country**

Take the first three phone-number characters and match that text to country_code. Preserve leading zeroes such as 051.

```sql
SELECT p.id, p.name, p.phone_number,
       SUBSTR(p.phone_number, 1, 3) AS country_code,
       c.name AS country
FROM Person AS p
JOIN Country AS c ON SUBSTR(p.phone_number, 1, 3) = c.country_code
ORDER BY p.id;
```

Result:

| id | name | phone_number | country_code | country |
| --- | --- | --- | --- | --- |
| 1 | Moncef | 212-1234567 | 212 | Morocco |
| 2 | Maroua | 212-6523651 | 212 | Morocco |
| 3 | Jonathan | 051-1234567 | 051 | Peru |
| 7 | Meir | 972-1234567 | 972 | Israel |
| 9 | Rachel | 972-0011100 | 972 | Israel |
| 12 | Elvis | 051-7654321 | 051 | Peru |

Jonathan and Elvis map to Peru, Moncef and Maroua to Morocco, and Meir and Rachel to Israel.

**3. Attach calls to both participating people**

The OR join matches a person when they are either caller or callee. Because the IDs differ, each call has two participating people and contributes once to each person's country.

```sql
SELECT p.id AS person_id, c.name AS country,
       ca.caller_id, ca.callee_id, ca.duration
FROM Person AS p
JOIN Country AS c ON SUBSTR(p.phone_number, 1, 3) = c.country_code
JOIN Calls AS ca ON p.id = ca.caller_id OR p.id = ca.callee_id
ORDER BY ca.caller_id, ca.callee_id, ca.duration, p.id;
```

**4. Calculate one average per participating country**

Group the joined participation rows by country. Inspect the sum and count alongside AVG to see precisely which denominator each country uses.

```sql
SELECT c.name AS country,
       SUM(ca.duration) AS total_duration,
       COUNT(ca.duration) AS participation_count,
       AVG(ca.duration) AS country_avg
FROM Person AS p
JOIN Country AS c ON SUBSTR(p.phone_number, 1, 3) = c.country_code
JOIN Calls AS ca ON p.id = ca.caller_id OR p.id = ca.callee_id
GROUP BY c.name
ORDER BY c.name;
```

Result:

| country | total_duration | participation_count | country_avg |
| --- | --- | --- | --- |
| Israel | 75 | 8 | 9.375 |
| Morocco | 165 | 6 | 27.5 |
| Peru | 874 | 6 | 145.66666666666666 |

Israel has 75 / 8 = 9.375, Morocco has 165 / 6 = 27.5, and Peru has 874 / 6 = 145.666.... Germany and Ethiopia have no participating people in the sample and therefore no country average.

**5. Compare each country average to the same global average**

The country_averages CTE has one row per country and global_avg has one row total. CROSS JOIN attaches the same global value to each country for comparison.

```sql
WITH global_avg AS (
    SELECT
        (2.0 * SUM(duration))
        / (COUNT(duration) + COUNT(duration)) AS Global_Avg
    FROM Calls
),
country_averages AS (
    SELECT
        c.name AS country,
        AVG(ca.duration) AS country_avg
    FROM Person AS p
    JOIN Country AS c
        ON SUBSTR(p.phone_number, 1, 3) = c.country_code
    JOIN Calls AS ca
        ON p.id = ca.caller_id OR p.id = ca.callee_id
    GROUP BY c.name
)
SELECT ca.country, ca.country_avg, ga.Global_Avg,
       CASE WHEN ca.country_avg > ga.Global_Avg THEN 'keep' ELSE 'exclude' END AS decision
FROM country_averages AS ca
CROSS JOIN global_avg AS ga
ORDER BY ca.country;
```

Result:

| country | country_avg | Global_Avg | decision |
| --- | --- | --- | --- |
| Israel | 9.375 | 55.7 | exclude |
| Morocco | 27.5 | 55.7 | exclude |
| Peru | 145.66666666666666 | 55.7 | keep |

Only Peru exceeds 55.7. We compare averages with >; we do not divide a country sum by the global average or return only the maximum country.

**6. Assemble the final query**

Apply the strictly-greater-than filter and project only the country name, following the saved two-CTE solution.
