# 5. Distinct billing countries

## Question and image

Finance wants the full list of countries the store has ever billed an invoice to. From the `Invoice` table, return the unique set of `BillingCountry` values.

Output exactly one column named `BillingCountry`, with no duplicates. Sort alphabetically (A to Z).

**Expected output:** `BillingCountry` · 24 rows · order matters.

### Step-by-step explanation with one example

Use this small illustrative dataset throughout. It uses the actual table and column names; only columns relevant to this question are shown. These rows are teaching data, not the complete Chinook database, so the number of results can differ from the prompt's full-database count.

**Starting data**

`Invoice`:

| InvoiceId | BillingCountry |
| --- | --- |
| 1 | USA |
| 2 | Brazil |
| 3 | USA |
| 4 | Canada |
| 5 | Brazil |

**1. Project the country from every invoice**

The source has one row per invoice, so the same country can appear many times. Select the requested column before considering uniqueness.

```sql
SELECT BillingCountry
FROM Invoice;
```

Result:

| BillingCountry |
| --- |
| USA |
| Brazil |
| USA |
| Canada |
| Brazil |

The five values still include USA twice and Brazil twice. Selecting a column alone does not remove duplicate values.

**2. Remove duplicate country values**

DISTINCT applies to the selected BillingCountry value. Because only that column is selected, all invoices with the same country produce one country row.

```sql
SELECT DISTINCT BillingCountry
FROM Invoice;
```

Result:

| BillingCountry |
| --- |
| USA |
| Brazil |
| Canada |

Five invoice rows reduce to three country values. Including InvoiceId in this SELECT would prevent those rows from collapsing because the invoice IDs differ.

**3. Assemble the final query**

Combine the steps using the saved solution. The query below preserves the original logic.

```sql
select distinct BillingCountry
from Invoice
order by BillingCountry asc
```

Final result for this example:

| BillingCountry |
| --- |
| Brazil |
| Canada |
| USA |

**Check the result:** The final ORDER BY returns Brazil, Canada, USA in alphabetical order. There are three unique country values, even though there are five invoices.

## Official solution

```sql
SELECT DISTINCT BillingCountry
FROM Invoice
ORDER BY BillingCountry ASC;
```

### What this tests

Retrieving unique column values and sorting them.

### The approach

Select BillingCountry from Invoice, remove duplicates with DISTINCT, and sort alphabetically.

### Why this way

DISTINCT directly expresses the need for unique values when no grouped calculations are required.

### Common mistakes

Omitting DISTINCT, selecting extra columns, or missing the alphabetical sort.
