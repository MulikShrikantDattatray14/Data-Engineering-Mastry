# 11. Show each customer's assigned support rep

## Question and image

In Chinook, every customer is assigned a support representative via `Customer.SupportRepId`, which points to `Employee.EmployeeId`. The operations team wants a clean roster mapping each customer to the employee who supports them.

Write a query that joins `Customer` to `Employee` and returns **one row per customer** with the customer's full name and their support rep's full name.

Output exactly two columns:

- `customer_name`: the customer's `FirstName` and `LastName` joined by a single space.
- `support_rep_name`: the employee's `FirstName` and `LastName` joined by a single space.

Sort by `customer_name` in **ascending** order.

**Expected output:** `customer_name`, `support_rep_name` · 59 rows · order matters.

## My solution — SQLite

```sql
SELECT
    Customer.FirstName || ' ' || Customer.LastName AS customer_name,
    Employee.FirstName || ' ' || Employee.LastName AS support_rep_name
FROM Customer
JOIN Employee ON Customer.SupportRepId = Employee.EmployeeId
ORDER BY customer_name ASC;
```

**1. Find each customer's assigned employee**

SupportRepId is the relationship key. Match it to EmployeeId; CustomerId identifies the customer and is not the representative relationship.

```sql
SELECT Customer.CustomerId, Customer.FirstName AS CustomerFirstName,
       Customer.LastName AS CustomerLastName, Customer.SupportRepId,
       Employee.EmployeeId, Employee.FirstName AS RepFirstName,
       Employee.LastName AS RepLastName
FROM Customer
JOIN Employee ON Customer.SupportRepId = Employee.EmployeeId
ORDER BY Customer.CustomerId;
```

Result:

| CustomerId | CustomerFirstName | CustomerLastName | SupportRepId | EmployeeId | RepFirstName | RepLastName |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Zoe | Clark | 2 | 2 | Liam | Gray |
| 2 | Ana | Diaz | 1 | 1 | Erin | Cole |
| 3 | Ben | Ali | 2 | 2 | Liam | Gray |

Zoe and Ben both map to employee 2, Liam Gray. Ana maps to employee 1, Erin Cole. Three customers still produce three joined rows.

**2. Build the two full-name columns**

SQLite uses || to concatenate text. The literal space between first and last names makes each full name readable.

```sql
SELECT Customer.FirstName || ' ' || Customer.LastName AS customer_name,
       Employee.FirstName || ' ' || Employee.LastName AS support_rep_name
FROM Customer
JOIN Employee ON Customer.SupportRepId = Employee.EmployeeId;
```

Result:

| customer_name | support_rep_name |
| --- | --- |
| Zoe Clark | Liam Gray |
| Ana Diaz | Erin Cole |
| Ben Ali | Liam Gray |

Each output row now contains the customer name and the assigned support representative name; the final query sorts the customer names.

**3. Assemble the final query**

Combine the steps using the saved solution. The query below preserves the original logic.

```sql
SELECT
    Customer.FirstName || ' ' || Customer.LastName AS customer_name,
    Employee.FirstName || ' ' || Employee.LastName AS support_rep_name
```

| Zoe Clark | Liam Gray |

**Check the result:** Ana Diaz maps to Erin Cole; Ben Ali and Zoe Clark map to Liam Gray. The final three rows are ordered by customer_name.

## Official solution

```sql
SELECT c.FirstName || ' ' || c.LastName AS customer_name,
       e.FirstName || ' ' || e.LastName AS support_rep_name
FROM Customer c
JOIN Employee e ON e.EmployeeId = c.SupportRepId
ORDER BY customer_name ASC;
```

### What this tests

Joining related records, concatenating text, and naming output columns.

### The approach

Join Customer.SupportRepId to Employee.EmployeeId; combine each first and last name with a space; use the requested aliases; sort by customer_name.

### Why this way

The join retrieves each customer's assigned representative in one query. Every customer is guaranteed a matching representative in this question.

### Common mistakes

Joining EmployeeId to CustomerId, omitting the space or using the wrong concatenation syntax, or using incorrect aliases.
