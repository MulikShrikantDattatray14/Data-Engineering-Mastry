# 20. Build employee display names

## Question and image

An internal directory needs a single formatted display name for each employee, combining their courtesy title, first name, and last name with single spaces between the parts (for example, `Ms. Nancy Davolio`). From the **Employees** table, concatenate `TitleOfCourtesy`, `FirstName`, and `LastName` in that order, separated by single spaces.

Return the `EmployeeID` and the assembled `DisplayName`.

Output exactly two columns named `EmployeeID` and `DisplayName`. Sort by `EmployeeID` **ascending**.

**Expected output:** `EmployeeID`, `DisplayName` · 9 rows · order matters.

## My solution — SQLite

```sql
select
    EmployeeID,
    (TitleOfCourtesy || ' ' || FirstName || ' ' || LastName) as DisplayName
from Employees
order by EmployeeID asc;
```

### Step-by-step explanation with one example

Use this small illustrative dataset throughout. It uses the question's actual table and column names; only columns needed for this explanation are shown. These are teaching rows, not the complete database or its expected row count. Every query result below was executed in SQLite on these same rows.

**Starting data**

`Employees`:

| EmployeeID | TitleOfCourtesy | FirstName | LastName |
| --- | --- | --- | --- |
| 3 | Dr. | Mira | Patel |
| 1 | Ms. | Nancy | Davolio |
| 2 | Mr. | Andrew | Fuller |

**1. Join the courtesy title to the first name**

Use || for SQLite text concatenation and insert one literal space between the parts. One employee still produces one row.

```sql
SELECT EmployeeID, TitleOfCourtesy || ' ' || FirstName AS TitleAndFirstName, LastName
FROM Employees
ORDER BY EmployeeID;
```

Result:

| EmployeeID | TitleAndFirstName | LastName |
| --- | --- | --- |
| 1 | Ms. Nancy | Davolio |
| 2 | Mr. Andrew | Fuller |
| 3 | Dr. Mira | Patel |

The partial labels are Ms. Nancy, Mr. Andrew, and Dr. Mira. LastName is still separate so its addition is easy to see.

**2. Append the last name with one more space**

The complete display expression keeps the original courtesy title, first name, and last name in that order.

```sql
SELECT EmployeeID,
       TitleOfCourtesy || ' ' || FirstName || ' ' || LastName AS DisplayName
FROM Employees;
```

Result:

| EmployeeID | DisplayName |
| --- | --- |
| 3 | Dr. Mira Patel |
| 1 | Ms. Nancy Davolio |
| 2 | Mr. Andrew Fuller |

The final query uses the same expression and sorts the employee rows by EmployeeID.

**3. Assemble the final query**

Combine the steps using the saved solution. The query below preserves the original logic.

```sql
select
    EmployeeID,
    (TitleOfCourtesy || ' ' || FirstName || ' ' || LastName) as DisplayName
from Employees
order by EmployeeID asc;
```

Final result for this example:

| EmployeeID | DisplayName |
| --- | --- |
| 1 | Ms. Nancy Davolio |
| 2 | Mr. Andrew Fuller |
| 3 | Dr. Mira Patel |

**Check the result:** Three employees produce three display names, with exactly one separator between the supplied non-NULL parts. The final IDs are 1, 2, 3.

## Official solution

```sql
SELECT
    EmployeeID,
    TitleOfCourtesy || ' ' || FirstName || ' ' || LastName AS DisplayName
FROM Employees
ORDER BY EmployeeID ASC;
```

### What this tests

Combining string columns and literal spaces into one formatted output column.

### The approach

1. Select `EmployeeID` from `Employees`.
2. Concatenate `TitleOfCourtesy`, `FirstName`, and `LastName` in that order, with one literal space between each part.
3. Alias the assembled name as `DisplayName`.
4. Sort by `EmployeeID ASC`.

### Why this way

SQLite uses `||` to concatenate text. Its `+` operator performs numeric addition, so using it for names would give incorrect results. Choose the concatenation syntax supported by the SQL dialect.

### Common mistakes

- Using an arithmetic operator instead of the dialect's string concatenation operator.
- Omitting the literal spaces between name parts.
- Forgetting the required `DisplayName` alias.
