# 4. SQL Second Highest Salary

## Question and image

[**176. Second Highest Salary**](https://leetcode.com/problems/second-highest-salary/)

Find the **second-highest distinct salary** in `Employee`. Return a single column named `SecondHighestSalary`. If the table has no second distinct salary, return one row containing `NULL`.

**Example 1 — input:**

Employee:

| id | salary |
|---:|---:|
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

**Output:**

| SecondHighestSalary |
|---:|
| 200 |

**Example 2 — input:**

Employee:

| id | salary |
|---:|---:|
| 1 | 100 |

**Output:**

| SecondHighestSalary |
|---|
| NULL |

## My solution — SQLite

Both approaches use `DENSE_RANK()` to number **distinct salary values** from highest to lowest. They differ only in how the outer query turns rank 2 into the required single result row.

**Approach 1 — aggregate the rank-2 rows**

```sql
WITH cte AS (
    SELECT
        id,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
)
SELECT MAX(salary) AS SecondHighestSalary
FROM cte
WHERE salary_rank = 2;
```

Here `MAX` does not determine which salary is second-highest; `DENSE_RANK` already does that. Every rank-2 row has the same salary, so `MIN` would give the same value. An aggregate without `GROUP BY` also produces one `NULL` row when no rank-2 rows exist.

**Approach 2 — use `DISTINCT` in a scalar subquery**

```sql
WITH cte AS (
    SELECT
        id,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
)
SELECT (
    SELECT DISTINCT salary
    FROM cte
    WHERE salary_rank = 2
) AS SecondHighestSalary;
```

`DISTINCT` reduces tied rank-2 employees to one salary. The outer `SELECT` has no `FROM`, so it produces exactly one result row; its scalar subquery evaluates to `NULL` if it finds no rank-2 salary.

### Step-by-step explanation with one example

**1. Start with the supplied Employee rows.** The target is one column and one row containing the second-highest *distinct* salary.

| id | salary |
|---:|---:|
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

**2. Rank the salaries from highest to lowest.** `ORDER BY salary DESC` inside `OVER` makes 300 rank 1, 200 rank 2, and 100 rank 3. `DENSE_RANK()` gives equal salaries the same rank without skipping a rank. The final `ORDER BY` in this inspection query only displays the intermediate rows in a readable order.

```sql
SELECT
    id,
    salary,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
FROM Employee
ORDER BY salary DESC;
```

| id | salary | salary_rank |
|---:|---:|---:|
| 3 | 300 | 1 |
| 2 | 200 | 2 |
| 1 | 100 | 3 |

**3. Keep rank 2.** The CTE gives the window result a name so the outer query can filter it. On the same example, only the row with salary 200 remains.

```sql
WITH cte AS (
    SELECT
        id,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
)
SELECT id, salary, salary_rank
FROM cte
WHERE salary_rank = 2;
```

| id | salary | salary_rank |
|---:|---:|---:|
| 2 | 200 | 2 |

**4. Return exactly one value.** In approach 1, `MAX(salary)` reads the remaining salary and returns one 200. In approach 2, the inner `SELECT DISTINCT salary` finds one 200, and the outer `SELECT` returns it as a single column.

| SecondHighestSalary |
|---:|
| 200 |

**5. Check ties and the missing-second-salary case.** If the salaries are 300, 300, 200, 200, 100, both 200 rows have rank 2; `MAX` collapses them to one 200, while `DISTINCT` leaves one 200 for the scalar subquery. If the table contains only salary 100, there is no rank-2 row: approach 1 returns one `NULL` through the aggregate, and approach 2 returns one `NULL` through the empty scalar subquery. A plain `SELECT DISTINCT salary FROM cte WHERE salary_rank = 2` would instead return **no row**, which does not meet the question's requirement.

Both queries were checked in SQLite with the supplied sample, tied salaries, one salary, and an empty `Employee` table.

## My solution — SQL Server

Both approaches use the same syntax in SQL Server.

**Approach 1 — `MAX`**

```sql
WITH cte AS (
    SELECT
        id,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
)
SELECT MAX(salary) AS SecondHighestSalary
FROM cte
WHERE salary_rank = 2;
```

**Approach 2 — `DISTINCT` scalar subquery**

```sql
WITH cte AS (
    SELECT
        id,
        salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
)
SELECT (
    SELECT DISTINCT salary
    FROM cte
    WHERE salary_rank = 2
) AS SecondHighestSalary;
```
