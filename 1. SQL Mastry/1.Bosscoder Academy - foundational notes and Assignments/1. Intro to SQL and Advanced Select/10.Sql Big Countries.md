# 10. SQL Big Countries

## Question and image

A country is **big** when its `area` is at least **3000000** square kilometres **or** its `population` is at least **25000000**. Return the `name`, `population`, and `area` of every big country. No output order is specified.

**Example 1**

Input — `World`:

| name | continent | area | population | gdp |
|---|---|---:|---:|---:|
| Afghanistan | Asia | 652230 | 25500100 | 20343000000 |
| Albania | Europe | 28748 | 2831741 | 12960000000 |
| Algeria | Africa | 2381741 | 37100000 | 188681000000 |
| Andorra | Europe | 468 | 78115 | 3712000000 |
| Angola | Africa | 1246700 | 20609294 | 100990000000 |

Expected output:

| name | population | area |
|---|---:|---:|
| Afghanistan | 25500100 | 652230 |
| Algeria | 37100000 | 2381741 |

Afghanistan and Algeria reach the population threshold. None of the sample countries reaches the area threshold.

## Schema

`World`:

| Column Name | Type |
|---|---|
| name | varchar |
| continent | varchar |
| area | int |
| population | int |
| gdp | bigint |

`name` is the primary key. Each row describes one country's continent, area, population, and GDP.

## My solution — SQLite

```sql
SELECT name, population, area
FROM World
WHERE area >= 3000000 OR population >= 25000000;
```

### Step-by-step explanation with one example

**Starting data.** One row represents one country. The result needs `name`, `population`, and `area` for countries meeting either size threshold.

| name | area | population |
|---|---:|---:|
| Afghanistan | 652230 | 25500100 |
| Albania | 28748 | 2831741 |
| Algeria | 2381741 | 37100000 |
| Andorra | 468 | 78115 |
| Angola | 1246700 | 20609294 |

**1. Check the area threshold.** “At least three million” means `area >= 3000000`.

```sql
SELECT name, area,
       area >= 3000000 AS large_area
FROM World;
```

| name | area | large_area |
|---|---:|---:|
| Afghanistan | 652230 | 0 |
| Albania | 28748 | 0 |
| Algeria | 2381741 | 0 |
| Andorra | 468 | 0 |
| Angola | 1246700 | 0 |

SQLite displays false as `0`. None of the example countries reaches the area threshold, but the area check remains necessary for other inputs.

**2. Check the population threshold.** “At least twenty-five million” means `population >= 25000000`.

```sql
SELECT name, population,
       population >= 25000000 AS large_population
FROM World;
```

| name | population | large_population |
|---|---:|---:|
| Afghanistan | 25500100 | 1 |
| Albania | 2831741 | 0 |
| Algeria | 37100000 | 1 |
| Andorra | 78115 | 0 |
| Angola | 20609294 | 0 |

Afghanistan and Algeria pass. SQLite displays true as `1`.

**3. Combine the tests with OR.** A country is big if **either** threshold passes; it does not need both.

```sql
SELECT name, area, population,
       (area >= 3000000 OR population >= 25000000) AS is_big
FROM World;
```

| name | area | population | is_big |
|---|---:|---:|---:|
| Afghanistan | 652230 | 25500100 | 1 |
| Albania | 28748 | 2831741 | 0 |
| Algeria | 2381741 | 37100000 | 1 |
| Andorra | 468 | 78115 | 0 |
| Angola | 1246700 | 20609294 | 0 |

Even though their areas are below three million, Afghanistan and Algeria qualify through population. A country with **exactly** 3000000 area or **exactly** 25000000 population would also qualify because the comparisons use `>=`.

**4. Return only the requested columns.** `WHERE` keeps the rows whose combined test is true:

```sql
SELECT name, population, area
FROM World
WHERE area >= 3000000 OR population >= 25000000;
```

| name | population | area |
|---|---:|---:|
| Afghanistan | 25500100 | 652230 |
| Algeria | 37100000 | 2381741 |

`name` is unique, so `DISTINCT` is unnecessary. The displayed order follows the sample; no `ORDER BY` is required by the prompt.
