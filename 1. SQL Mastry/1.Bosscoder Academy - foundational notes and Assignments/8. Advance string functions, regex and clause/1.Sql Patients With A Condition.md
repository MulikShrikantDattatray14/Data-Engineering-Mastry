Table: `Patients`

| patient_name | varchar |

patient_id is the primary key (column with unique values) for this table.

'conditions' contains 0 or more code separated by spaces.

This table contains information of the patients in the hospital.

Write a solution to find the patient_id, patient_name, and conditions of the patients who have Type I Diabetes. Type I Diabetes always starts with `DIAB1` prefix.

Return the result table in **any order**.

The result format is in the following example.

**Example 1:**

**Input:**

Patients table:

| patient_id | patient_name | conditions |
|---|---|---|
| 1 | Daniel | YFEV COUGH |
| 2 | Alice | |
| 3 | Bob | DIAB100 MYOP |
| 4 | George | ACNE DIAB100 |
| 5 | Alain | DIAB201 |

**Output:**

| patient_id | patient_name | conditions |
|---|---|---|
| 3 | Bob | DIAB100 MYOP |
| 4 | George | ACNE DIAB100 |

**Explanation:**

Bob and George both have a condition that starts with DIAB1.

## My solution — SQLite

```sql
SELECT patient_id, patient_name, conditions
FROM Patients
WHERE conditions LIKE 'DIAB1%'
   OR conditions LIKE '% DIAB1%';
```

### Step-by-step explanation with one example

We need the details of each patient who has a condition code beginning with `DIAB1`. Keep one result row per qualifying patient. The `conditions` column can contain several codes separated by spaces, so the matching code does not have to be the first one. No grouping is needed, and the question permits any output order.

**1. Read the original patient rows**

Use the supplied sample throughout:

```sql
SELECT patient_id, patient_name, conditions
FROM Patients;
```

| patient_id | patient_name | conditions |
|---|---|---|
| 1 | Daniel | YFEV COUGH |
| 2 | Alice | |
| 3 | Bob | DIAB100 MYOP |
| 4 | George | ACNE DIAB100 |
| 5 | Alain | DIAB201 |

Bob's matching code is first. George's matching code follows `ACNE` and a space. The empty cell for Alice is an empty string in this sample.

**2. Find a matching code at the beginning**

`LIKE 'DIAB1%'` means that the value starts with the literal characters `DIAB1`. The `%` wildcard accepts zero or more following characters, including the rest of the code and any later conditions.

```sql
SELECT patient_id, patient_name, conditions
FROM Patients
WHERE conditions LIKE 'DIAB1%';
```

| patient_id | patient_name | conditions |
|---|---|---|
| 3 | Bob | DIAB100 MYOP |

Bob matches because `DIAB100 MYOP` starts with `DIAB1`. George does not pass this first filter because his complete string starts with `ACNE`.

**3. Find a matching code after a space**

The second pattern, `'% DIAB1%'`, allows earlier text, then requires a literal space followed immediately by `DIAB1`. The final `%` accepts the rest of that code and any following text.

```sql
SELECT patient_id, patient_name, conditions
FROM Patients
WHERE conditions LIKE '% DIAB1%';
```

| patient_id | patient_name | conditions |
|---|---|---|
| 4 | George | ACNE DIAB100 |

George matches the substring ` DIAB1` after `ACNE`. The space marks the beginning of a new condition code. Removing it would also allow `DIAB1` inside an unrelated code such as `XDIAB100`.

**4. Combine the two positions with OR**

A code can begin at the start of the string or after a space. Each side of `OR` must be a complete condition using the column name and `LIKE`.

```sql
SELECT patient_id, patient_name, conditions
FROM Patients
WHERE conditions LIKE 'DIAB1%'
   OR conditions LIKE '% DIAB1%';
```

| patient_id | patient_name | conditions |
|---|---|---|
| 3 | Bob | DIAB100 MYOP |
| 4 | George | ACNE DIAB100 |

`OR` keeps a row when either position matches. If both positions match within the same patient's string, that patient still appears once: this is a filter on the original rows.

**Check the result:** Daniel has no `DIAB1` code, Alice has no codes, and Alain's `DIAB201` starts with `DIAB2`. Bob and George are the two qualifying patients, matching the expected result. The displayed order is for readability; the final query does not require sorting.
