# PNP Q013. States with at least five customers

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EASY](<../../_badges/easy.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 13, pp. 27–28. **Difficulty:** Easy.

**Primary topic:** HAVING. **Also covers:** GROUP BY, NULL group.

**Business scenario.** Regional sales is deciding where to place field representatives. A rep is only worth assigning to a state with at least five registered customers. They want the qualifying states with the biggest first. Customers with no state on file should be visible as their own line so the team can see how many cannot be placed.

**Task.** Count customers per state and keep only states with five or more. Label a missing state as Unknown . Sort by customer count, highest first, then by state.

**Expected output (as supplied):**

```text
State : state name, or Unknown
customer_count : customers registered in that state
```

**Tables required:** Customers.

**SQL concepts named in the source:** GROUP BY, HAVING, WHERE vs HAVING, NULL as a group.

The source is a text-based PDF; no separate question image was supplied.
