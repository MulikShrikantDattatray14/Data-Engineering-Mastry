# PNP Q096. Make a slow order report sargable and index it

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 96, pp. 196–199. **Difficulty:** Expert.

**Primary topic:** Query performance and indexing. **Also covers:** Sargable date ranges, Correlated subquery to join rewrite, Covering indexes, EXPLAIN.

**Business scenario.** The risk operations team manually reviews every order of 2,000 or more placed in the current month. A scheduled query builds their list each morning, with the line count and units so a reviewer can spot an odd basket at a glance. It was fast when the business was small. Now that Orders holds years of history it is one of the slowest jobs on the warehouse, and the platform team has asked you to fix it without changing a single output row.

**Task.** The current query is in Step 3. Rewrite it so the database can use indexes on the date and the order key, prove the new version returns exactly the same rows, and propose the indexes with the EXPLAIN evidence you would attach to the change request.

**Expected output (as supplied):**

```text
OrderID , OrderDate , CustomerID , Total_Order_Amount : the order header
line_items : number of OrderDetails rows for the order (0 if none)
units : SUM(Quantity) for the order (0 if none)
Sorted by Total_Order_Amount descending, then OrderID
```

**Tables required:** Orders , OrderDetails.

**SQL concepts named in the source:** sargability, functions on indexed columns, NULL semantics of COALESCE in a predicate, correlated subqueries vs a single join, covering indexes, reading EXPLAIN , proving two queries equivalent.

**Starting query supplied for this debugging task:**

```sql
SELECT o.OrderID,

         o.OrderDate,

         o.CustomerID,

         o.Total_Order_Amount,

         (SELECT COUNT(*) FROM OrderDetails AS od

         WHERE od.OrderID = o.OrderID)                       AS line_items,

         COALESCE((SELECT SUM(od.Quantity) FROM OrderDetails AS od

                  WHERE od.OrderID = o.OrderID), 0)          AS units

FROM Orders AS o

WHERE TO_CHAR(o.OrderDate, 'YYYY-MM') = (SELECT TO_CHAR(MAX(OrderDate), 'YYYY-MM') FROM Orders)

   AND COALESCE(o.Total_Order_Amount, 0) >= 2000

ORDER BY o.Total_Order_Amount DESC, o.OrderID;
```
