# PNP Q086. Reconcile order headers with order lines

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EXPERT](<../../_badges/expert.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 86, pp. 166–169. **Difficulty:** Expert.

**Business scenario.** Finance books revenue from order headers ( Orders.Total_Order_Amount ). The category and supplier dashboards are built from order lines ( Quantity * Sale_Price ). The two never quite agree, and every month someone explains the gap as "catalogue price changes". Before month-end close, the finance controller wants one table that shows exactly how header value relates to line value, order by order, with every gap explained or flagged. The data platform team will run it nightly after the order load.

**Task.** Pair every order header with the list-price value of its lines and give each order exactly one status. Rules apply top to bottom; first match wins: 1. Lines with NULL OrderID : line rows that belong to no order. 2. Lines without header : lines whose OrderID has no row in Orders . 3. Header without lines : an order with no rows in OrderDetails . 4. Header zero or NULL : Total_Order_Amount is NULL, zero or negative. 5. Exact match : header equals line value to the cent. 6. Discount 5% , Discount 10% , Discount 12% , Discount 15% : header equals line value times 0.95, 0.90, 0.88 or 0.85, to the cent. 7. Other shortfall : header below line value by any other amount. 8. Header above lines : header above line value. Return one row per status in this order, including statuses with zero orders, with the order count, both values, the total absolute difference and the payment types seen.

**Expected output (as supplied):**

```text
recon_status : one of the eleven statuses above
orders : order keys in the status (0 for the NULL-key status)
header_value : sum of Total_Order_Amount
line_list_value : sum of Quantity * Sale_Price over the lines
abs_difference : sum of per-order |header - line value|, a missing side counted as 0
payment_types : distinct PaymentType values of the orders in the status
```
