# PNP Q065. Longest run of consecutive months with an order

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 65, pp. 116–118. **Difficulty:** Hard.

**Primary topic:** Gaps and islands. **Also covers:** DISTINCT customer-months, ROW_NUMBER difference, Top N with ties.

**Business scenario.** The retention team is launching a "streak" badge in the app that rewards customers for ordering every month. Before deciding the badge tiers, they want to see the longest unbroken monthly streak each customer has ever had, and who the top streakers are. A streak is broken by any calendar month with no order.

**Task.** For each customer, find the longest run of consecutive calendar months in which they placed at least one order. If a customer has two runs of the same length, report the more recent one. Return the ten customers with the longest streaks, keeping everyone tied with tenth place.

**Expected output (as supplied):**

```text
CustomerID
streak_start_month : first month of the customer's longest streak
streak_end_month : last month of that streak
streak_months : number of months in it
```

**Tables required:** Orders.

**SQL concepts named in the source:** reducing to one row per customer-month, the row-number-difference trick for islands, grouping by an island key, picking one island per customer, RANK for top N with ties.

The source is a text-based PDF; no separate question image was supplied.
