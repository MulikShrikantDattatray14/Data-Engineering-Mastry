# PNP Q001. Brand directory

![SOLVED](<../../_badges/solved.svg>) ![EASY](<../../_badges/easy.svg>) · Solved (recorded): 2026-10-26

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 1, pp. 11–12. **Difficulty:** Easy.

**Primary topic:** SELECT DISTINCT. **Also covers:** IS NOT NULL, ORDER BY.

**Business scenario.** The catalogue team is building the "Shop by brand" page in the app. They need one clean list of brand names to load into the brand filter. Products sold without a brand, such as loose staples, should not create an empty entry in that filter.

**Task.** Return each brand name in Products once, in alphabetical order. Leave out products whose Brand is NULL, empty or only spaces.

**Expected output (as supplied):**

```text
Brand : one row per distinct brand name
```

**Tables required:** Products.

**SQL concepts named in the source:** SELECT DISTINCT, filtering NULLs with IS NOT NULL, ORDER BY.

The source is a text-based PDF; no separate question image was supplied.

## My solution — SQLite

```sql
SELECT DISTINCT TRIM(Brand) AS Brand
FROM Products
WHERE TRIM(Brand) IS NOT NULL
  AND LENGTH(TRIM(Brand)) > 0
ORDER BY TRIM(Brand) ASC;
```

### Step-by-step explanation with one example

**Starting data.** This small example uses the question's `Products` table. Only `ProductID` and `Brand` are shown because the other columns do not affect this result. Quotes in the table show where a text value begins and ends; they are not stored in `Brand`.

| ProductID | Brand |
|---:|---|
| 1 | 'Nike' |
| 2 | ' Nike ' |
| 3 | `NULL` |
| 4 | `''` |
| 5 | `'   '` |
| 6 | 'Adidas' |
| 7 | 'Puma' |
| 8 | 'Adidas' |

**1. Clean each brand name.** `TRIM(Brand)` removes spaces from the start and end. It turns `' Nike '` into `'Nike'`, and a value containing only spaces into the empty string. A `NULL` remains `NULL`.

```sql
SELECT ProductID, Brand, TRIM(Brand) AS clean_brand
FROM Products
ORDER BY ProductID;
```

| ProductID | Brand | clean_brand |
|---:|---|---|
| 1 | 'Nike' | 'Nike' |
| 2 | ' Nike ' | 'Nike' |
| 3 | `NULL` | `NULL` |
| 4 | `''` | `''` |
| 5 | `'   '` | `''` |
| 6 | 'Adidas' | 'Adidas' |
| 7 | 'Puma' | 'Puma' |
| 8 | 'Adidas' | 'Adidas' |

**2. Remove unusable brands.** Both conditions in `WHERE` must hold. `TRIM(Brand) IS NOT NULL` excludes product 3. `LENGTH(TRIM(Brand)) > 0` excludes products 4 and 5 because their cleaned value has zero characters. The length condition also rejects `NULL` in a `WHERE` clause, but the explicit null check keeps your reasoning visible.

```sql
SELECT ProductID, TRIM(Brand) AS Brand
FROM Products
WHERE TRIM(Brand) IS NOT NULL
  AND LENGTH(TRIM(Brand)) > 0
ORDER BY ProductID;
```

| ProductID | Brand |
|---:|---|
| 1 | Nike |
| 2 | Nike |
| 6 | Adidas |
| 7 | Puma |
| 8 | Adidas |

**3. Keep one row per cleaned brand.** `DISTINCT` applies to `TRIM(Brand)`, so products 1 and 2 become one `Nike` row, and products 6 and 8 become one `Adidas` row. Without `ORDER BY`, SQL does not promise which brand appears first.

```sql
SELECT DISTINCT TRIM(Brand) AS Brand
FROM Products
WHERE TRIM(Brand) IS NOT NULL
  AND LENGTH(TRIM(Brand)) > 0;
```

The set of values is `Nike`, `Adidas`, and `Puma` (order unspecified).

**4. Sort the final result.** `ORDER BY TRIM(Brand) ASC` sorts the same cleaned names that the query returns. The alias `Brand` gives the required output column name.

```sql
SELECT DISTINCT TRIM(Brand) AS Brand
FROM Products
WHERE TRIM(Brand) IS NOT NULL
  AND LENGTH(TRIM(Brand)) > 0
ORDER BY TRIM(Brand) ASC;
```

| Brand |
|---|
| Adidas |
| Nike |
| Puma |

**Manual check.** Products 3-5 are excluded. The two forms of `Nike` produce one row after trimming, and the two `Adidas` rows produce one row after `DISTINCT`. The three remaining names are in ascending order. These are illustrative rows, not a claim of execution on the full supplied dataset.

## My solution — SQL Server

SQL Server uses `LEN` for the length check. The sort uses the selected alias.

```sql
SELECT DISTINCT TRIM(Brand) AS Brand
FROM Products
WHERE TRIM(Brand) IS NOT NULL
  AND LEN(TRIM(Brand)) > 0
ORDER BY Brand ASC;
```

## Official solution

**Source:** [provided SQL answer key](<../Source Materials/PrepNPlaced_SQL_100_v2/sql/all_100_solutions.sql>), question 1. The source query is:

```sql
SELECT DISTINCT p.Brand
FROM Products AS p
WHERE NULLIF(TRIM(p.Brand), '') IS NOT NULL
ORDER BY p.Brand;
```

**What this tests.** Select distinct brand names, exclude missing or blank values, and sort the result.

**The approach.** `TRIM` removes surrounding spaces for the filter; `NULLIF(..., '')` turns an empty cleaned value into `NULL`; `IS NOT NULL` keeps the remaining rows.

**Why this way.** One predicate handles `NULL`, the empty string, and strings made only of spaces.

**Common mistakes.** `Brand != NULL` does not test for nullness, and `Brand IS NOT NULL` alone still permits blank strings. The source query selects the raw `p.Brand`, so values such as `'Nike'` and `' Nike '` remain separate; your solution trims the selected value and combines them into one clean name.
