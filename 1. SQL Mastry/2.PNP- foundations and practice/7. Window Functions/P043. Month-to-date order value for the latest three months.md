# PNP Q043. Month-to-date order value for the latest three months

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 43, pp. 74–76. **Difficulty:** Medium.

**Primary topic:** Running total with PARTITION BY month. **Also covers:** Daily aggregation first, ROWS vs RANGE frames, Anchored date window.

**Business scenario.** The finance team tracks each month against its target with a month-to-date (MTD) line: on any day, how much order value has come in since the 1st. They want the last three months of data, one row per day that had orders, with that day's order value and the running MTD figure, so they can compare the shape of each month.

**Task.** Take the latest three calendar months in the data, counting the month of the latest order as the third. For each order date in that window, return the day's total order value and the month-to-date total, which restarts on the first day of each month. Sort by date.

**Expected output (as supplied):**

```text
order_date : the calendar date
daily_order_value : sum of Total_Order_Amount for orders placed that day
month_to_date_value : running total of daily_order_value from the start of that month up to and including this date
```

**Tables required:** Orders.

**SQL concepts named in the source:** running SUM as a window, PARTITION BY to restart the total, aggregating to the day before the window, the default frame and why ROWS is stated, anchoring the window to the data.

The source is a text-based PDF; no separate question image was supplied.
