# PNP Q068. Second-highest spender in each state, counting delivered orders only

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![HARD](<../../_badges/hard.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 68, pp. 123–125. **Difficulty:** Hard.

**Primary topic:** Conditional ranking. **Also covers:** DENSE_RANK over an aggregate, SUM with FILTER, LEFT JOIN with Unknown and Unmapped labels.

**Business scenario.** The CRM team runs a state-level loyalty programme. The top spender in each state already gets a personal account manager, so this quarter they want to invite the runner-up in every state to a priority-delivery pilot. Spend must count only orders that actually reached the customer, because an order that never arrived says nothing about loyalty. If two customers tie for second place, both are invited.

**Task.** For each customer state, rank customers by the total Total_Order_Amount of their delivered orders and return everyone at the second-highest spend level. An order counts as delivered when DeliveryDate is present and not before OrderDate . Customers with a NULL or blank State go under Unknown ; orders whose CustomerID has no customer record go under Unmapped customer .

**Expected output (as supplied):**

```text
State : the customer's state, Unknown or Unmapped customer
CustomerID
customer_name : first and last name, or Unknown customer
delivered_spend : sum of Total_Order_Amount over delivered orders
spend_rank : always 2 in the output (ties share it)
```

**Tables required:** Orders , Customers.

**SQL concepts named in the source:** SUM(...) FILTER (WHERE ...) , a window function ordered by an aggregate, DENSE_RANK vs RANK vs ROW_NUMBER for "second", PARTITION BY on a derived label, filtering on a window result in an outer query.
