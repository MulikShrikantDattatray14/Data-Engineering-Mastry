# PNP Q087. Referential integrity audit across all seven relationships

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![UNRATED](<../../_badges/unrated.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 87, pp. 169–171. **Difficulty:** Expert.

**Primary topic:** Referential integrity validation. **Also covers:** UNION ALL of anti-joins, NOT EXISTS, NULL FK vs broken FK, Conditional aggregation with FILTER, Relationship spine with VALUES.

**Business scenario.** The shop's tables arrive as nightly CSV loads with no foreign key constraints. The data platform team wants to add foreign keys to the warehouse copy so bad rows are rejected at load time. Before they switch that on, they need one audit that says, for every relationship, how many child rows would be rejected and which parent keys are missing, so they can send a list to each source owner.

**Task.** Audit all seven documented relationships in one query. For each one, count the child rows, the child rows whose foreign key is NULL, and the child rows whose foreign key is not NULL but has no matching parent (orphans). Show up to five distinct orphan key values as a sample. Return all seven relationships every night, including clean ones, in a fixed order.

**Expected output (as supplied):**

```text
relationship : written as Child.Column -> Parent
child_rows : rows in the child table
null_fk_rows : child rows where the foreign key is NULL
orphan_rows : child rows where the foreign key is not NULL and no parent row has that key
sample_orphan_keys : up to five distinct orphan keys, ascending, comma separated (NULL when there are none)
```

**Tables required:** Products , Category , Orders , Customers , Payments , Shippers , OrderDetails , Suppliers.

**SQL concepts named in the source:** anti-join with NOT EXISTS, why NOT IN fails with NULLs, separating missing keys from broken keys, stacking many checks with UNION ALL, FILTER on aggregates, array slicing for samples.

The source is a text-based PDF; no separate question image was supplied.
