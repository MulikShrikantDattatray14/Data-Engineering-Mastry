# PNP Q090. Column-by-column completeness profile of Orders

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 90, pp. 178–180. **Difficulty:** Expert.

**Primary topic:** NULL and missing-value analysis. **Also covers:** Unpivot with CROSS JOIN LATERAL (VALUES ...), Conditional aggregation with FILTER, COUNT DISTINCT, Anchored recent window.

**Business scenario.** The data platform team is writing a data contract for Orders with the checkout team that owns the source. The contract will say, column by column, which fields may be NULL and how many distinct values are normal. Before negotiating, they need a profile of what the table looks like today, in a shape that can be stored nightly and compared run to run.

**Task.** Profile every column of Orders in one query. Return one row per column, in table order, with the total row count, the number and percentage of NULLs, the NULL percentage among orders from the last 30 days of data, and the number of distinct non-NULL values.

**Expected output (as supplied):**

```text
column_name : the column, in table order
total_rows : rows in Orders (same on every row, a built-in check)
null_rows : rows where the column is NULL
null_pct : null_rows as a percentage of all rows, 2 dp
null_pct_last_30d : the same percentage for orders with OrderDate in the 30 days ending at the latest order date
distinct_values : distinct non-NULL values
```

**Tables required:** Orders.

**SQL concepts named in the source:** unpivoting columns into rows with LATERAL VALUES, casting mixed types to a common type, COUNT(*) vs COUNT(col) , FILTER, COUNT DISTINCT ignoring NULLs, anchoring a recent window to the data.

The source is a text-based PDF; no separate question image was supplied.
