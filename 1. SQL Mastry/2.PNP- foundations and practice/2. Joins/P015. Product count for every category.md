# PNP Q015. Product count for every category

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EASY](<../../_badges/easy.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 15, pp. 29–30. **Difficulty:** Easy.

**Primary topic:** LEFT JOIN with GROUP BY. **Also covers:** COUNT(column) after a LEFT JOIN.

**Business scenario.** The catalogue team is cleaning up the app's category menu. An empty category leads shoppers to a blank page, so they want every category with its product count, empty ones included and listed first.

**Task.** For every row in Category , return the number of products assigned to it. A category with no products must appear with 0. Sort by product count ascending, then CategoryID .

**Expected output (as supplied):**

```text
CategoryID
CategoryName
product_count : products in that category, 0 when none
```

**Tables required:** Category , Products.

**SQL concepts named in the source:** LEFT JOIN, table grain, GROUP BY, COUNT(*) vs COUNT(column).

The source is a text-based PDF; no separate question image was supplied.
