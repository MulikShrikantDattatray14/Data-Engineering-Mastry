## My solution — SQLite

Your final self-join solution:

```sql
SELECT
    e.manager_id,
    COUNT(e.emp_id) AS direct_reports
FROM employees AS e
INNER JOIN employees AS m
    ON e.manager_id = m.emp_id
GROUP BY e.manager_id
HAVING COUNT(e.emp_id) >= 3;
```

Manager 1 has Bela, Chitra, and Dev as direct reports. Manager 2 has Esha.

### Note: `COUNT(*)` versus `COUNT(e.emp_id)`

`COUNT(*)` counts every row in a group. `COUNT(e.emp_id)` counts only rows where the employee ID is not `NULL`. In your inner self join above, every joined employee has an ID, so both expressions return the same count.

The difference appears if we start with every potential manager and use a left self join:

```sql
FROM employees AS m
LEFT JOIN employees AS e
    ON e.manager_id = m.emp_id
```

For the same sample, these are the joined rows for Asha and Dev:

| m.emp_name | e.emp_id |
|---|---:|
| Asha | 2 |
| Asha | 3 |
| Asha | 4 |
| Dev | NULL |

| Manager | `COUNT(*)` | `COUNT(e.emp_id)` |
|---|---:|---:|
| Asha | 3 | 3 |
| Dev | 1 | 0 |

Dev has no direct report, but the left join still produces one row for Dev with `e.emp_id = NULL`. That row contributes to `COUNT(*)` and does not contribute to `COUNT(e.emp_id)`.

## Official solution

**Source:** [Advanced SQL 100 Query Questions, Vol. 1](<../Source Materials/Advanced_SQL_100_Query_Questions_Vol1 (2).pdf>), question 12, PDF p. 4. The source uses MySQL 8.

```sql
SELECT m.emp_id, m.emp_name, COUNT(*) AS direct_reports
FROM employees m
JOIN employees e ON e.manager_id = m.emp_id
GROUP BY m.emp_id, m.emp_name
HAVING COUNT(*) >= 3;
```

**What this tests.** Counting employees who report directly to each manager.

**The approach.** Join each employee `e` to their manager `m`, group by the manager's ID and name, then retain counts of three or more with `HAVING`.

**Why this works.** Each joined row represents one employee reporting to one manager. `COUNT(*)` therefore counts direct reports in each manager's group. Your `COUNT(e.emp_id)` counts the same joined employee rows.

**Output-column difference.** The source answer also returns `m.emp_name`. Your answer returns `manager_id` and `direct_reports`, matching the illustrative output in this practice file.

**Common mistakes.** Using `WHERE` to filter a grouped count; or counting employees two or more levels below a manager when the task asks for direct reports.
