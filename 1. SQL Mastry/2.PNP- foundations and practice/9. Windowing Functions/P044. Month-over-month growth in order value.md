# PNP Q044. Month-over-month growth in order value

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![MEDIUM](<../../_badges/medium.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 44, pp. 76–77. **Difficulty:** Medium.

**Business scenario.** The leadership team opens every monthly business review with one table: order value per month and how much it moved against the month before. The CFO wants it as a query on Orders instead of a spreadsheet. "Growth" means the change against the immediately preceding calendar month, not against whichever earlier month happens to have data.

**Task.** For every month that has orders, return the total order value, the previous calendar month's order value, the absolute change and the percentage change. If the previous calendar month has no orders, or there is no earlier month, the comparison columns must be NULL. Sort by month.

**Expected output (as supplied):**

```text
order_month : first day of the month
order_value : sum of Total_Order_Amount for orders placed that month
prev_month_value : order value of the previous calendar month, NULL if that month has no row
mom_change : order_value - prev_month_value
mom_growth_pct : change as a percentage of prev_month_value , 2 decimals
```

The source is a text-based PDF; no separate question image was supplied.

### Sample input and expected output

*Illustrative example; the source gives output columns but no sample rows. Only the columns needed for this example are shown.*

| OrderID | OrderDate | Total_Order_Amount |
|---|---|---|
| 1 | 2025-01-01 | 100 |
| 2 | 2025-03-01 | 150 |
| 3 | 2025-04-01 | 200 |

**Expected output**

| order_month | order_value | prev_month_value | mom_change | mom_growth_pct |
|---|---|---|---|---|
| 2025-01-01 | 100 | NULL | NULL | NULL |
| 2025-03-01 | 150 | NULL | NULL | NULL |
| 2025-04-01 | 200 | 150 | 50 | 33.33 |

March has no February row, so its previous-calendar-month comparison is NULL.
