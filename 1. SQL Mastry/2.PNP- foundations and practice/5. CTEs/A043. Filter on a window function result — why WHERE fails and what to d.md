**Task.** Filter on a window function result — why WHERE fails and what to do.

Explain why this query fails, then rewrite it so the rank can be filtered:

```sql
SELECT emp_name, RANK() OVER (ORDER BY salary DESC) AS r
FROM employees
WHERE r <= 5;
```
