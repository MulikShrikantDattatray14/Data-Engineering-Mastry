# PNP Q009. Check how Active and Allowed are encoded

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EASY](<../../_badges/easy.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 9, pp. 21–23. **Difficulty:** Easy.

**Primary topic:** GROUP BY profiling. **Also covers:** UNION ALL, CAST to text.

**Business scenario.** The data platform team is publishing shared views that filter on "active categories" and "allowed payment methods". Category.Active and Payments.Allowed came in through CSV loads from two systems, and nobody documented the encoding. The team wants to see every stored value first.

**Task.** In one result, list each distinct raw value of Category.Active and Payments.Allowed with its row count. NULL counts as a value.

**Expected output (as supplied):**

```text
source_table : Category or Payments
flag_column : Active or Allowed
raw_value : the stored value as text, NULL when missing
row_count : rows holding that value
```

**Tables required:** Category , Payments.

**SQL concepts named in the source:** GROUP BY for profiling, UNION ALL, CAST to a common type, NULL as a group.

The source is a text-based PDF; no separate question image was supplied.
