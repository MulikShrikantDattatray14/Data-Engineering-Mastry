# PNP Q022. Orders with more than eight line items

![NOT SOLVED YET](<../../_badges/not-solved-yet.svg>) ![EASY](<../../_badges/easy.svg>)

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 22, pp. 38–39. **Difficulty:** Easy.

**Primary topic:** HAVING on counts. **Also covers:** COUNT vs COUNT DISTINCT, SUM.

**Business scenario.** The fulfilment centre sends orders with more than eight line items to a separate packing station with bigger cartons. The station supervisor wants to see those orders along with how many different products and how many units each one holds, so they can plan staffing for the station.

**Task.** For every order with more than eight rows in OrderDetails , return the number of lines, the number of distinct products and the total units. Sort by line items, highest first, then OrderID .

**Expected output (as supplied):**

```text
OrderID
line_items : rows in OrderDetails for the order
distinct_products : distinct ProductID s in the order
total_units : sum of Quantity
```

**Tables required:** OrderDetails.

**SQL concepts named in the source:** GROUP BY, HAVING, COUNT(*) vs COUNT(DISTINCT), SUM, line grain.

The source is a text-based PDF; no separate question image was supplied.

### Interview follow-up (Step 9)

How would you list the duplicated lines themselves, meaning the same order, product, quantity and supplier appearing more than once?
