# PNP Q085. Win-back customers returning after 180+ days

## Question and image

**Source:** [100 SQL Interview Questions](<../Source Materials/Updated_100_SQL_Interview_Questions.pdf>), question 85, pp. 162–166. **Difficulty:** Hard.

**Primary topic:** LAG gap per customer. **Also covers:** Filter after the window, Anchored 12-month reporting window, Date difference, Deterministic tie-break.

**Business scenario.** The retention team ran reactivation campaigns over the past year and wants to see who actually came back. A win-back is an order placed at least 180 days after the same customer's previous order. They need each win-back event in the last 12 months, with the gap and the size of the return order, to compare against the campaign calendar and to decide whether returning customers spend like new ones or like loyal ones.

**Task.** For every order, find the same customer's previous order date. Return orders whose gap from the previous order is at least 180 days and whose date falls in the 12 months ending on the last order date in the data. The previous order may be older than those 12 months. A customer can appear more than once if they lapsed and returned more than once. Sort by return date.

**Expected output (as supplied):**

```text
CustomerID
previous_order_date : the customer's order immediately before the return order
return_order_date : OrderDate of the return order
gap_days : days between the two
return_order_amount : Total_Order_Amount of the return order
```

**Tables required:** Orders.

**SQL concepts named in the source:** LAG within a customer partition, deterministic ordering with an ID tie-break, filtering on a window result in an outer query, reporting window applied after the window function, anchored dates, date difference.

The source is a text-based PDF; no separate question image was supplied.
