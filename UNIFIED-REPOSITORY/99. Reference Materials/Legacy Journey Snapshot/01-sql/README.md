# SQL — Fundamentals to Data Engineering Interviews

## Topic sequence
1. SELECT, WHERE, ORDER BY, DISTINCT, NULL, CASE
2. Aggregates: COUNT, SUM, AVG, GROUP BY, HAVING
3. Joins, subqueries, EXISTS, UNION, CTEs
4. Window functions: ranks, running totals, LAG/LEAD, frames
5. Advanced patterns: gaps and islands, cohort analysis, deduplication
6. Data Engineering SQL: MERGE, CDC, incremental loads, SCD, quality
7. Query performance: indexes, query plans, partition pruning
8. Timed mixed interview challenges
