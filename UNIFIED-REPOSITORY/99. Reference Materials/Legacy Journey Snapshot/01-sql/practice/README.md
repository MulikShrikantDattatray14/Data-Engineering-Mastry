# SQL Practice

For each exercise record: original problem phrased in your own words, schema, assumptions, expected output, first attempt, review notes, corrected query, improved variant, and takeaways.

Progressively combine earlier SQL concepts into new exercises. Track timed attempts separately.

Do not reproduce paid-platform problems or private employer assessments without permission.

## SQL submission-review standard (from Day 1)

1. User writes **SQLite** SQL independently; retain original version *exactly*.
2. Run against the provided SQLite schema/sample dataset when available. Show side-by-side **expected** and **actually executed** output, including extra/missing rows, duplicates, sort errors, and errors. If no runnable fixture is available, explicitly label actual output **unverified**.
3. Give review and invite a self-correction without overriding the original attempt.
4. After a completed review, archive two distinct reference solutions: **SQLite (assistant-verified)** and **SQL Server/T-SQL (assistant-converted)**. Do not claim SQL Server execution without a SQL Server runtime, and never falsely call an assistant solution an official instructor key.
5. Ask whether the user learned anything new (Yes/No optional); preserve Yes responses verbatim with source and date.
6. Attribute earned completion only with verified evidence. **Do not publish solutions to unattempted practice questions.**
