Job-search strategy

Leverage existing software experience rather than pretending to be a two-year Data Engineer. Position MERN work as production engineering experience; build DE-specific proof through tested ETL projects, SQL optimization, PySpark pipelines, cloud orchestration and architectural explanations. Practice unseen problems and mocks before applications. Aim for strong product-based roles, but compensation and timing depend on the market, location, company, interview results and actual DE experience.

What updates automatically?

Repository pushes

Newest main-branch commit SHA, message and timestamp update on refresh. No code push is automatically credited as a solved problem.

Reviewed progress file

Daily and overall bars derive from Repository 1's tracked JSON. Any valid progress change pushed to main is picked up at refresh.

Repository 2 problem completions

Changes in source files appear as commits. For completion counts, record exact solved question IDs in the central progress file so activity does not become false credit.

Update interval & limitations

Site refreshes approximately every five minutes while open. Public GitHub APIs can rate-limit or delay results; failures show a stale/error label. There is no always-connected server socket.
