## Problem summary (paraphrased)
Given an integer calendar year in the inclusive range **1700 to 9000**, return a Boolean indicating whether it is a leap year.

Examples shared:
- `year = 2000` → `True`
- `year = 2017` → `False`

## Concepts to learn and verify
- Integer remainder using `%`
- Boolean expressions using `and`, `or` and `not`
- Conditional branching versus returning a Boolean expression
- Calendar century exceptions (years divisible by 100) and the 400-year exception
- Boolean `True`/`False` versus string literals
- O(1) runtime and O(1) auxiliary space reasoning
