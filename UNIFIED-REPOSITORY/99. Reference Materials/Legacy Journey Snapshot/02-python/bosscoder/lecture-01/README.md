## What you should be able to explain

- What Python is and what happens when a Python script runs.
- How numbers, booleans, strings, lists, tuples, sets, frozensets, dictionaries and bytes differ.
- Python's name-binding rules, scope and assignment behavior.
- Arithmetic, comparison, augmented assignment, Boolean, bitwise, membership and identity operators.
- Implicit versus explicit conversion and common errors.
- Positive/negative indexing, slicing and step behavior.
- Conditions, nested decisions, loops, `break`, `continue` and loop-`else`.
- How to construct and test programs involving digits, primes, palindrome checks and factorials.

## Corrections and caution

The supplied notes contain small teaching simplifications. Modern Python dictionaries preserve insertion order, `is` is about object identity rather than value equality, variables are names bound to objects rather than literal boxes, and Python is commonly compiled to bytecode before interpreter execution in CPython. These clarifications are labeled as such in the individual chapters.
