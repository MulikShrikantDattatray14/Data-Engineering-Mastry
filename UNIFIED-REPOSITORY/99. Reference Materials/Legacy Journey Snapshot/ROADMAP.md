# Six-Month Data Engineering Roadmap

This is an adjustable plan for technical readiness, not a salary guarantee.

| Month | Focus | Evidence of progress |
|---|---|---|
| 1 | SQL foundations to joins and aggregation; Python basics | Correct SQL solutions and introductory Python scripts |
| 2 | Advanced SQL and Python | Window functions, mixed problems, coding exercises |
| 3 | Modeling and pipelines | Dimensional modeling, incremental ETL, data quality |
| 4 | Spark, cloud, orchestration | PySpark exercises and scheduled pipeline |
| 5 | Production-style projects and system design | End-to-end projects, tests, failure/retry design |
| 6 | Mock interviews, revision, applications | Timed attempts, design walkthroughs, project explanations |

## Recurring habits
- Revisit SQL and Python throughout all six months.
- Practice individual concepts first, then mix concepts progressively.
- Keep an honest daily learning log and a weekly reflection.
- Publish notes only after correctness review.

## Interview readiness
Demonstrate unseen SQL problem solving, Python coding, reliable incremental pipelines, Spark fundamentals, data modeling, query performance reasoning, and clear trade-off explanations.
